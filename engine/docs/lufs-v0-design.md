# 게이트된 라우드니스(LUFS) v0 — 사전 등록

작성 2026-08-26 13:2x. 상속: `judge-bench-v1.2`.
채우는 칸: 08-25부터 "미측정"으로 선언해 둔 `lufs`
(`genesis/audio_probe.py` 정직 조항 — "RMS를 LUFS라고 부르지 않는다").

**의존성 결정(D)을 기다리지 않는다.** `pyloudnorm`을 설치하는 대신 표준
**ITU-R BS.1770-4**를 직접 구현한다. 이유는 셋이다.

1. 그 표준은 공개된 필터 계수와 게이팅 절차로 **전부 적혀 있다** — 추정이나
   휴리스틱이 아니라 옮겨 적으면 되는 계산이다.
2. 우리가 구현하면 **정답을 해석적으로 검증**할 수 있다(§3). 남의 구현을 믿고
   숫자를 받는 것보다 우리 계기판에 맞다.
3. 새 의존성이 없으므로 노트북·데스크톱·서버에서 같은 값이 나온다.

---

## 1. 무엇을 구현하나 (동결)

BS.1770-4의 **적분 라우드니스**(integrated loudness):

1. **K-가중 필터** — 2단 IIR.
   - 1단: 고역 셸빙(f0 = 1681.974450955533 Hz, G = 3.999843853973347 dB,
     Q = 0.7071752369554196)
   - 2단: 고역 통과(f0 = 38.13547087602444 Hz, Q = 0.5003270373238773)
   계수는 표본율마다 아날로그 원형에서 **다시 계산**한다(48 kHz 전용 표를
   박아 넣지 않는다). 48 kHz에서 표준에 실린 표와 일치하는지를 테스트가 잡는다.
2. **블록** — 400 ms, 75% 겹침(100 ms 간격).
3. **채널 합** — `l = -0.691 + 10·log10(Σ G_i · z_i)`,
   z_i는 그 채널 블록의 평균 제곱. 가중치 G: L·R·C = 1.0, 서라운드 = 1.41
   (모노 = 1.0). 우리 자산은 모노/스테레오뿐이라 서라운드는 정의만 둔다.
4. **게이팅** — 절대 게이트 −70 LUFS, 그다음 상대 게이트(남은 블록의
   라우드니스 − 10 LU). 두 관문을 통과한 블록만 최종 평균에 들어간다.

## 2. 무엇을 구현하지 않나 (정직)

- **단기(short-term)·순간(momentary) 라우드니스**, LRA(라우드니스 범위):
  지금 필요한 판정이 없다. 이름만 만들지 않는다.
- **참피크(dBTP)**: 이미 `audio_probe`가 4배 오버샘플로 낸다. 여기서 다시
  만들지 않는다.
- **문턱**: LUFS 목표값을 **정하지 않는다.** 이 문서는 계측기만 등록한다.
  목표(예: −14 LUFS)는 사장님이 동결할 값이고, 그 전까지 음악 심판에 LUFS
  규칙은 **추가되지 않는다**. 미동결 문턱으로 판정하지 않는 규율 그대로다.
  즉 이 작업으로 `lufs`는 **미측정 → 측정됨(미판정)** 으로 한 칸 옮겨간다.

## 3. 정답 검증 (동결 — 값을 보기 전에 적는다)

라이브러리 대조 대신 **해석적으로 아는 값**과 맞춘다. 사인파의 평균 제곱은
A²/2이고, K-가중은 1 kHz에서 이득이 사실상 0 dB이므로:

| 시료 | 기대값 | 근거 |
|---|---|---|
| 1 kHz 사인, 진폭 1.0, 스테레오 양 채널 | **−0.691 LUFS** | −0.691 + 10log10(0.5 + 0.5) |
| 1 kHz 사인, 진폭 1.0, 모노 | **−3.70 LUFS** | −0.691 + 10log10(0.5) |
| 위 시료를 −20 dB로 줄임 | **정확히 −20 LU 이동** | 라우드니스는 로그 척도 |
| 무음 | 값 없음(None) | 절대 게이트를 통과한 블록이 0개 |

허용 오차 **±0.15 LU**(필터의 1 kHz 이득이 정확히 0 dB은 아니므로).
48 kHz 계수는 표준 표와 **1e-6** 이내로 일치해야 한다.

### 3-A. 위 표의 앞 두 줄은 **틀렸다** (2026-08-26 13:3x 정정)

구현 후 나온 값은 스테레오 +0.007, 모노 −3.004로 기대값과 약 **0.69 LU** 어긋
났다. 원인을 찾아보니 **내 산수가 틀렸다**: K-가중은 1 kHz에서 이득이 0 dB이
아니라 **+0.6977 dB**이고(실측), 표준의 상수항 −0.691은 바로 그 이득을
상쇄하려고 있는 값이다. 둘이 지워지므로 1 kHz 사인은 **dBFS 값이 그대로 LUFS로
읽힌다.**

| | 사전 등록(틀림) | 실제 | 정정된 근거 |
|---|---|---|---|
| 스테레오 1 kHz 전체진폭 | −0.691 | **+0.007** | +0.6977(K-가중) − 0.691(상수항) ≈ 0 |
| 모노 1 kHz 전체진폭 | −3.70 | **−3.004** | 위 + 10log10(0.5) |

**구현을 기대값에 맞추지 않고 기대값을 고친 근거는 두 개의 독립 증거다.**

1. 48 kHz 필터 계수가 표준에 실린 표와 **자릿수까지 일치**한다
   (1.53512485958697 / −2.69169618940638 / 1.19839281085285,
   −1.69065929318241 / 0.73248077421585, −1.99004745483398 / 0.99007225036621).
   계수를 표에서 베낀 게 아니라 아날로그 원형에서 계산했는데 같은 값이 나왔다.
2. **EBU Tech 3341 시험 1**(스테레오 1 kHz 사인 −23.0 dBFS → −23.0 LUFS ±0.1)에
   대해 우리 값은 **−22.993**이다. 이 시험은 내가 만든 게 아니라 방송 표준의
   검증 시료다.

즉 여기서 바꾼 것은 **판정 문턱이 아니라 내가 잘못 계산한 정답**이고, 바꾼
근거는 결과가 아니라 외부 표준이다. 문턱을 결과에 맞춰 옮기는 것과 다르며,
그 차이를 흐리지 않으려고 원래 표를 지우지 않고 위에 남겨 둔다.

**정정된 검증표**(테스트가 이대로 고정한다):

| 시료 | 기대값 | 허용 |
|---|---|---|
| 1 kHz 스테레오, X dBFS | X LUFS | ±0.05 |
| 1 kHz 모노, X dBFS | X − 3.01 LUFS | ±0.05 |
| EBU 3341 시험 1(−23 dBFS 스테레오) | −23.0 | ±0.1 |
| 무음 | None + 사유 | — |

게이팅이 실제로 작동하는지도 시험한다: 큰 소리 뒤에 긴 무음을 붙여도 적분값이
거의 변하지 않아야 한다(무음 블록이 게이트에서 빠지므로). 게이팅이 없으면
값이 크게 내려간다 — 그 차이가 이 검사의 이빨이다.

실측(13:3x): 소리 3초 = −22.993, 소리 3초 + 무음 6초 = **−23.216**.
게이팅이 없었다면 −27.8 근처가 나왔을 것이다. 0.22 LU 남는 차이는 소리와 무음이
걸친 경계 블록 때문이고, 표준이 블록을 겹쳐 자르는 방식의 결과다.

## 4. 하지 않는 것

- RMS나 다른 근사를 LUFS라고 부르는 것.
- 표본율별 계수를 하드코딩하고 다른 표본율에서 조용히 틀린 값을 내는 것.
- 문턱을 내가 정해 음악 심판에 규칙을 추가하는 것.
- 게이트를 통과한 블록이 0개일 때 0이나 −70을 값으로 내는 것(그건 미정의다).
