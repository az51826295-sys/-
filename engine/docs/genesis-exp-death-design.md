# 실험 등록: 죽음은 학습에 기여하는가 (Genesis 미로 세계)

등록일 2026-08-06. 상태: **동결 (파일럿 보정 완료, 본실험 전)**.
비용: API 0원 (결정론 세계, 모델 호출 없음).

**동결값 (파일럿 2026-08-06, `data/death_pilot.json`)**:
- 에너지 = **75** (신선 개체 초기 20ep 실패율 35% — 등록 구간
  20~40% 내).
- ε = **0.0** — **등록 구간(상속률 30~70%) 도달 불가, 정직 기록**:
  경험 오차 분포가 0에 극단 집중(중앙값 0.0000)이라 가장 선별적인
  ε=0조차 상속률 74%가 된다. 따라서 C의 상속 정의는 사후적으로
  더 명확해졌다: **"완벽 예측된 경험만 상속"**. 이 정의 변경은
  관측(오차 분포) 때문이지 결과(군 비교) 때문이 아니며, 군 비교
  관측 전에 동결한다.

## 0. 질문과 입장

존재 드라이브 설계는 "왜 성장하는가"(학습 진행도)는 답했으나
"왜 멈추면 안 되는가"는 답하지 않았다. 생물의 답은 죽음이다.
이 실험은 죽음의 **학습 기여**를 분리 실측한다.

시리즈 선행 결과와의 연결: 장기 스터디(100ep)는 무선별 경험
축적이 예측을 **악화**시킴을 보였다(교차오염). 죽음+선택적 상속은
**강제된 선택적 망각**으로 작동할 수 있다 — 이것이 본 실험의
핵심 가설이다. 죽음 그 자체(백지 리셋)는 학습 축적을 파괴하므로
불리할 것으로 예측한다.

## 1. 세 군 (개체 = 세계모델 + 경험 저장소 인스턴스)

- **A (불멸)**: 현행 그대로. 100 에피소드 내내 한 개체가 경험 축적.
- **B (죽음)**: 사망 시 모델·경험 **전량 소멸**, 다음 에피소드는
  백지 개체.
- **C (유산)**: 사망 시 개체는 소멸하되, **검증된 경험만** 다음
  개체가 상속.

**사망 정의 (내생적)**: 에피소드 실패(목표 미도달 — 에너지 소진
또는 최대 스텝). 외부 조작 없음.

**검증된 경험 정의 (기계적)**: 저장 시점의 예측오차 ≤ ε인 경험
레코드. ε은 파일럿에서 상속률이 30~70% 구간에 들도록 보정 후
**동결** (판정 전 확정, 관측 후 변경 금지).

## 2. 프로토콜

- 세계: advanced 난이도, 에이전트 adaptive, 모델 similarity (전부
  기본값). 에피소드 100개, 세계 seed = 에피소드 번호 (매번 다른
  지도) — 장기 스터디와 동일 규약.
- 사망률 보정: 파일럿에서 에너지 상한을 조정해 초기 20 에피소드
  실패율이 20~40% 구간에 들도록 맞춘 뒤 **동결**. (실패가 안
  일어나면 죽음이 무의미 — 천장 효과는 Rookery 실험 1의 R4 교훈.)
- 반복: master seed 20개 (0~19). 군당 20 run × 100 ep.
- 지표: 10-에피소드 창(window)별 (a) 해결률 (b) 평균 예측오차
  (c) C의 상속 경험 수·비율. 원자료 `data/death_report.json`.

## 3. 사전 예측과 판정 (동률 = 충족으로 계산, 전 항목 공통)

- **D1 (죽음 단독은 해롭다)**: 후기 창(ep 51~100) 평균 해결률에서
  A ≥ B가 20 중 ≥15 master seed. — 백지 리셋은 축적을 파괴한다.
- **D2 (유산은 죽음을 구제한다)**: 후기 창 평균 해결률에서 C ≥ B가
  20 중 ≥15.
- **D3 (핵심 — 죽음+상속 = 강제된 선택적 망각)**: 후기 창 평균
  **예측오차**에서 C < A가 20 중 ≥13. — A는 교차오염을 겪고 C는
  죽음이 오염을 걸러낸다는 가설. 이 항목이 기각되면 "죽음의 학습
  기여"는 이 설계에서 근거 없음으로 기록한다.
- **D4 (기제 확인, 판정 아님·기록만)**: C의 상속 경험 비율과
  예측오차의 창별 궤적. D3이 충족되면 상속 필터가 실제로 오염
  경험을 걸렀는지 레코드 수준에서 부검한다.

**판정식 규율 (P10·P16·P30 재발 방지)**: 모든 부등호에 동률 포함
여부를 위에 명시했다. 절대 문턱 없음 — 전 판정이 군 간 상대
비교다. 사망률·ε은 관측 전 동결값만 사용한다.

## 4. 구현 계획

- `genesis/mortality.py`: 개체 생명주기(사망 판정, B 초기화, C
  상속 필터), run 루프, 창별 집계.
- `python -m genesis.mortality --arm A|B|C --master-seed N` +
  전군 일괄 실행기. 테스트: 사망 판정·상속 필터·집계 각 단위
  테스트, 3군 스모크.
- 순서: 구현 → 파일럿(사망률·ε 보정) → **본 문서 동결** → 본실험
  → Findings 기록 (부정 결과 포함, 시리즈 규약).

## 5. 해석 경계 (미리 선언)

- 이 실험은 "죽음의 학습 기여"를 **이 세계·이 학습기·이 상속
  정의**에서만 말한다. 일반화 주장 금지.
- C가 이기더라도 그것은 "죽음" 개념 전체가 아니라 **선별 상속
  메커니즘**의 공일 수 있다 — 대조를 위해 사후 탐색(등록 외)으로
  "죽음 없는 선별 망각"(A + 주기적 ε-필터링)을 1개 arm 돌려 D3
  해석을 보정한다. 이 arm은 판정에 불참, 해석 보조로만 기록.
