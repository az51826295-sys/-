## 2. 남들의 구성 (읽은 것)

| 구성 | 핵심 | 우리와의 차이 |
|---|---|---|
| **ExpeL / ERL / Reflexion** — 궤적에서 규칙·휴리스틱을 뽑아 다음 일에 넣는다 ([ERL](https://arxiv.org/abs/2603.24639), [메모리 개관](https://arxiv.org/abs/2603.07670)) | 새 일마다 **관련도 점수로 상위 몇 개만** 골라 넣는다. 지적된 위험: 한 번 "이 길은 늘 실패"라고 잘못 결론 나면 영영 안 시험해 **스스로 굳는다** | 우리는 검증·재검증이 있어 굳는 위험은 낮다. 대신 규칙을 **전부** 넣는다(상한 16) — 규칙이 늘면 관련 없는 것까지 매번 값을 치른다 |
| **GEPA** — 실행 흔적을 글로 읽고 프롬프트를 **통째로** 고쳐 가며, 학습판으로 반성·검증판으로 점수, 파레토 후보군 유지 ([논문](https://arxiv.org/abs/2507.19457), [DSPy](https://dspy.ai/api/optimizers/GEPA/overview/)) | RL 보다 롤아웃 35배 적게 쓰고 +6~20%. **점수는 실제 과제 성적**이다 | 우리는 규칙 "추가"만 하고 프롬프트 본문은 안 건드린다. 점수도 과제 성적이 아니라 "어긴 사례가 더 실패했나"(상관). 진짜 점수를 내려면 **같은 과제를 다시 돌려야** 한다 |
| **Darwin Gödel Machine** — 에이전트가 **자기 코드**를 고치고, 벤치마크로 실측, 살아남은 판을 보관소에 쌓아 갈래를 친다 ([논문](https://arxiv.org/abs/2505.22954), [Sakana](https://sakana.ai/dgm/)) | SWE-bench 20→50%. 핵심은 **고정 시험판**과 **보관소** | 우리는 코드 고정, 규칙만. 고정 시험판이 없어서 어떤 변경도 "전보다 나아졌다"를 실측 못 한다 |
| **Voyager** — 실행 가능한 **스킬 라이브러리**(코드) + 자동 커리큘럼 + 자기 검증 ([논문](https://arxiv.org/abs/2305.16291)) | 성공한 코드를 저장하고 다음 일에 상위 5개를 꺼내 쓴다 | 우리 씬 빌더 스크립트가 사실상 스킬인데 **색인·재사용이 없다**. 자기 검증은 우리가 더 세다(LLM 비평이 아니라 기계 검사) |
| **Red Queen GM** — 평가자도 같이 진화 ([논문](https://arxiv.org/pdf/2606.26294)) | 고정 검사에 과적합(굿하트) 막기 | 우리 검사는 고정. 아직은 규칙이 1개라 위험 낮음. 표시만 |

## 3. 빠진 칸, 값·비용 순 (내 판단)

1. **고정 시험판(benchmark)** — 대표 과제 8~12개(유니티 씬·분석·영상, 검사 붙은 것)를 얼려 두고, 규칙/모델/프롬프트를 **켜고 끄며 같은 과제를 돌려** 성적을 비교한다.
   - 푸는 것: 106회차 "규칙이 진짜 먹히나"(인과), 105회차 "모델 비교"(라우팅 착시 제거), 나중의 프롬프트 진화(GEPA-lite)까지 전부 이 위에서만 가능하다.
   - 비용: 과제당 $0.1~0.25 → 한 번 재는 데 $2~3. 매일은 아니고 **변경이 생겼을 때만**. 사장님 승인 필요.
   - 함정: 시험판에 과적합. 과제를 가끔 바꾸고, 실서비스 실패율을 같이 본다.
2. **규칙 관련성 검색** — 새 일마다 규칙을 관련도로 골라 상위 N 만 넣기(ERL 방식). 비용 0에 가깝고 규칙이 늘어도 프롬프트가 안 찬다. 지금은 규칙 1개라 급하지 않다 → 규칙 5개 넘으면.
3. **스킬 라이브러리** — 유니티 검사 통과한 씬 빌더 조각을 이름·설명으로 색인해 다음 판이 꺼내 쓰게. 되풀이 판이 전체를 다시 내는 것(107회차 기준선 17개 파일)도 여기서 줄어들 수 있다. 중간 비용.
4. **프롬프트 통째 진화(GEPA-lite)** — 1 이 있어야 한다. 그 전엔 하지 않는다.
5. **사람 판정** — 예측 진화는 코드가 아니라 사용에 막혀 있다. 시험판이 생기면 사람 판정 없이도 "검사 통과"로 절반은 대신할 수 있지만, "마지막 칸은 사람"이라는 우리 원칙과는 별개로 둔다.

## 4. 결론

우리 구성은 **관측 → 제안 → 블라인드 검증 → 채택 → 재검증 → 보임**까지는 닫혀 있고, 남들(ExpeL 계열)이 못 막은 "스스로 굳기"도 막고 있다.
빠진 것은 하나로 모인다: **같은 과제를 다시 돌려 재는 고정 시험판.** 오늘 잡힌 함정 셋이 전부 "관측만으로 인과를 말했다"에서 나왔고, DGM·GEPA 가 잘 되는 이유도 그 시험판이다.
