# 거짓말의 온도 — 엔진 v0 (228회차 2026-10-01)

사장님 기획을 받아 **심리 엔진 속**부터 지었다. 화면은 아직 없다 — 속이 맞는지부터 재고 붙인다.

## 무엇을 지었나

| 파일 | 하는 일 |
|---|---|
| `src/lib/lie/case.ts` | **진실 데이터베이스.** 사건·증거·용의자 셋(A 한선호 · B 윤미래 · C 박태수)과 **약점표**(어느 증거가 어느 진술을 깨나) |
| `src/lib/lie/stress.ts` | **수치 시스템 + 모순 감지.** 압박·당황·분노·경계를 **코드가** 센다 |
| `src/lib/lie/turn.ts` | 한 턴: 셈 → 프롬프트 → 모델 → **누설 자** |

등장인물·사건은 사장님이 적은 표 그대로다. 숫자(당황 값·문턱)는 내가 정했고 표만 고치면 바뀐다.

## 설계에서 못 박은 세 가지

**① 수치는 모델이 안 정한다.** 압박이 얼마나 올랐는지를 모델에게 맡기면 같은 증거를 들이대도
어떤 판은 무너지고 어떤 판은 안 무너진다 — 그건 추리가 아니라 운이다. 전부 셈이다.
모델이 하는 일은 *"이 수치에 맞는 사람처럼 말하기"* 하나뿐이다(두근도트 친밀도와 같은 구조).

**② 자백은 코드가 연다.** 프롬프트에 "압박 100 이면 자백해" 라고 적으면 두 턴 만에 분다.
`무너짐` 이 참이 되기 **전까지는 자백할 내용을 프롬프트에 아예 안 넣는다.**

**③ 새면 다시 짓는다.** 그래도 샐 수 있다. 답을 낸 뒤 **누설 자**(`누설검사`)로 훑고,
자백 낱말이 보이면 그 답을 버리고 다시 받는다. 두 번 다 새면 **표에 적힌 둘러대기**로 바꾼다 —
모델이 뭐라 하든 게임은 안 망가진다. (*"막을 거면 코드로 막아야 한다"* — 09-16 에 배운 것.)

## 수치 규칙 (전부 숫자)

| 무엇 | 압박 | 당황 | 분노 | 경계 |
|---|---|---|---|---|
| 그냥 질문 | +2 | | | +1 |
| **날카로운 말**(거짓말·자백하라·범인) | **+2** | | +5 | **+12** |
| 부드러운 말(라포) | | | −10 | −8 |
| 같은 질문 반복 | | | +8 | +6 |
| **맞는 증거** | +(30+당황/2)×깎임 | +약점값×깎임 | | |
| **안 맞는 증거(헛다리)** | **−5** | | | **+10** |
| 턴마다 | −1 | ×0.55 | −2 | |

- **깎임 = 1 − 경계/120** (최저 0.15). **경계가 높으면 증거가 덜 먹힌다** — 눈치채고 말을 맞춘 것이다.
- **멘탈 브레이크**: 압박 ≥ `35 + 20×필요한약점` **그리고** 약점이 다 깨졌고 **그리고** 분노 < 70.

**왜 분노·경계가 따로 있나**: 압박 하나면 *아무 말이나 세게 하면 이기는 게임*이 된다.
고함은 압박을 거의 안 올리고 **경계를 크게** 올린다 — 그 뒤에 내민 증거가 덜 먹힌다.
**라포로 경계를 내려 두고 증거를 꽂는 것**이 제일 빠른 길이 되게 맞췄다.

## 교차 검증 (10-01 붙임) — **이 게임의 알맹이**

증거는 형사가 **가지고 들어오는** 것이지만, 증언은 **취조로 만들어 내는** 것이다.
한선호가 *"윤미래 씨와 카페에 있었다"* 고 하면 → **윤미래에게 가서 묻고** → 그 반박이 **새 증거**가 되어
→ **한선호에게 돌아가 들이댄다.** 표 세 줄(`사건1.교차`)이 이 고리를 만든다.

- 증언은 **사건 전체로 들고 다닌다**(방이 달라도 남는다). 화면에서도 방마다 공유한다.
- 같은 교차는 **한 번만** 생긴다. 이번 턴에 얻은 증언은 **이번 턴에 못 내민다**(자기 자신에게 들이대는 꼴이 된다).
- **손에 든 증거가 하나도 없어도** 증언 둘만으로 한선호를 무너뜨릴 수 있다 — 취조로 뚫는 길.

## 화면에서 잡은 것 (10-01)

- 증거 낱말 `"카페"` 가 너무 헐거워, 알리바이를 묻는 보통 말에도 **CCTV 를 내민 것**으로 세어졌다 → `"카페 영상"` 등으로 좁혔다.
