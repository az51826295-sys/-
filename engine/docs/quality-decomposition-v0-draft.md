## 0. 먼저 — 이 문서가 하지 않는 약속

**여기 있는 것을 다 통과해도 갓오브워가 되지 않는다.**

이 목록은 "고퀄이면 참인 것들"이지 "참이면 고퀄인 것들"이 아니다. 필요조건이고
충분조건이 아니다. 그 구분을 안 적어 두면 다음이 벌어진다: 체크리스트를
만족시키려고 최적화하면 **체크리스트만 만족하는 물건**이 나온다. 우리가 이미
이름을 붙여 둔 병이다(Goodhart).

그래서 이 목록의 쓸모는 **합격을 주는 것이 아니라 불합격을 주는 것**이다.
여기서 떨어지면 볼 것도 없이 아니고, 여기를 통과하면 그때 사람이 본다.

| **모동숲** | **게임의 종류** — 무엇을 하는 게임인가 | 갓오브워와 장르가 정반대라, 둘 다 품질 바로 읽으면 서로 모순된다 |

이 읽기가 틀리면 아래 분해를 통째로 다시 해야 한다. **먼저 확인받는다.**

### 큰 간극 하나: 둘 다 3D 다

지금 우리 고리는 2D 스프라이트다. 3D 로 가면 그림 생성이 **메시 생성**이 되고,
그건 유니티 AI 생성기가 필요하고, **그건 지금 막혀 있다**(패키지가 Unity 6.5 에서
컴파일되지 않는다). 6000.0 에디터를 깔면 열린다.

그래서 두 길이 있다: 2D 로 모동숲의 **구조**만 가져오거나(스타듀밸리 쪽), 3D 를
열고 가거나. 이것도 사장님이 정하실 일이다.

## 2. 기계가 재는 것

### 지금 도구로 되는 것 (오늘 넷이 실제로 돌았다)

| 항목 | 어떻게 재나 | 어느 축 |
|---|---|---|
| 씬이 열리고 예외가 없다 | PlayMode, 40프레임 로그 감시 | 공통 |
| 카메라와 보이는 것이 있다 | 켜진 Camera·Renderer 수 | 공통 |
| 그림이 코드가 아니라 파일에서 온다 | 텍스처에 이름이 있는가 | 공통 |
| 입력을 주면 무언가 움직인다 | 입력 후 Transform 변화 | 공통 |

### 조금 더 만들면 되는 것 (같은 PlayMode 자리에 붙는다)

| 항목 | 어떻게 재나 | 어느 축 |
|---|---|---|
| **프레임이 안정한가** | 프레임타임 p99 < 문턱 | 갓오브워 |
| **입력 반응이 빠른가** | 입력 → 상태 변화까지 프레임 수 | 갓오브워 |
| **소리가 층을 이루는가** | 동시에 도는 AudioSource 의 종류 수(BGM·환경·효과) | 갓오브워 |
| **애니메이션이 끊기지 않는가** | Animator 전이의 블렌드 시간이 0 이 아닌가, T-pose 프레임이 없는가 | 갓오브워 |
| **빛과 그림자가 있는가** | Light 존재, 그림자 켜짐, 포스트 볼륨 존재 | 갓오브워 |
| **카메라가 연출을 하는가** | 카메라가 고정이 아닌가(추적·전환 횟수) | 갓오브워 |
| **저장이 남는가** | 저장 → 씬 재로드 → 상태 복원 | 모동숲 |
| **시간이 흐르는가** | 시간을 든 상태값이 프레임에 따라 변하는가 | 모동숲 |
| **루프가 닫히는가** | 주울 것이 있고 → 보관 상태가 변하고 → 그 상태를 쓰는 곳이 있는가 | 모동숲 |
| **NPC 가 반응하는가** | 상호작용 시 상태 변화가 있는가 | 모동숲 |
| **벌이 없는가** | 게임오버·사망 상태가 없는가 | 모동숲 |

**"조금 더"의 크기**: 위 열한 개는 전부 오늘 만든 PlayMode 자리에 붙는다. 새
계측기를 만드는 것이 아니라 같은 시험지에 항목을 더하는 일이다.

### 이미 있는 계측기가 재는 것

자산 일관성(채도·명암·바닥 대비·팔레트)은 판정 엔진이 이미 잰다. **다만 지금
못 닿는다** — 판정기가 `*.up.railway.app` 이고 그 이름이 이 기계에서 막혀 있다.

## 4. 얼리기 전에 사장님이 정하실 것

1. **읽기가 맞는가** — 갓오브워 = 품질 바, 모동숲 = 게임의 종류.
2. **2D 로 갈 것인가, 3D 를 열 것인가.** 3D 면 유니티 6000.0 에디터 설치가 앞에 온다.
3. **문턱을 어디에 둘 것인가.** 프레임 p99 몇 ms, 입력 반응 몇 프레임, 소리 몇 층.
   숫자를 보고 정하면 그건 판정이 아니므로 **재기 전에** 정해야 한다.
4. **몇 개를 필수로 할 것인가.** 전부 통과를 요구하면 아무것도 못 나오고, 하나만
   요구하면 재는 뜻이 없다.
