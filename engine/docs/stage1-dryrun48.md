## 무엇을

①~③을 합친 상주 파이프라인을 **지출 0**으로 48시간 무인 운전한다:
- 서비스 다중 모드(7 저장소: boltons·toolz·tinydb·marshmallow·dateutil·
  more-itertools·sortedcontainers), 저장소별 엔진·원장
  `data/stage1_dry48/<repo>/engine.db`.
- 모델 호출 전부 가짜(`ROOKERY_MOCK=1`: 읽기 1회 후 done → 오라클 기각),
  인테이크도 목(`--mock`: B형 유도 가짜, A형 동봉 테스트는 헤드에서
  실제 실행). 수용된 일감은 enqueue되고 가짜 에이전트가 기각한다.
- 주기 인테이크 1시간(무인증 GitHub API, 저장소당 1페이지), 하트비트
  5분, 48h 뒤 자진 종료(`ROOKERY_STOP_AFTER_S=172800`).
- 런처: `wscript tools\stage1_dryrun_launch.vbs` (무창). 로그:
  `data/rookery.log`(서비스), `data/stage1_dryrun_console.log`/`_err.log`.

## 보는 것 (판정 — 숫자 보기 전 동결)

판정 도구 `python tools/stage1_dryrun_judge.py`가 로그·원장에서 계산:

1. **연속 운전**: 첫 하트비트~마지막 하트비트 ≥ 47.5h **이고** 하트비트
   최대 간격 ≤ 15분(틱 5분의 3배). 서비스 시작 로그("워커 N개 시작") 1회
   = 재시작 0. (08-22 중간 점검: 판정 도구가 저장소별 "시작 복구" 줄을
   세어 7로 오산 → 도구만 수정, 기준 의미 불변.)
2. **지출 0**: 전 원장 reservations usd 합 = 0, `budget_reserved` 이벤트의
   실비 0.
3. **인테이크 주기 작동**: 실행 ≥ 40회, rc≠0 비율 ≤ 10%, 2회차 이후
   같은 이슈 재검증 0(레지스트리 멱등).
4. **엔진 무결**: `worker_exception` 0, `isolation_halt` 0. 감사 정지는
   허용(기록만 — 목 기각은 정지를 내지 않아야 정상이므로 발생 시 부검).
5. **큐 건전성**: 48h 뒤 leased 0(임대 누수 없음), pr_ready는 0건이어야
   정상(가짜는 채택 못 함 — 1건이라도 있으면 오채택 부검).

**전부 충족 → ④ 통과**: 스테이지 1 인프라 완성 → 실 가동(일일 상한
하)은 운영자 결정. **하나라도 미달 → 부검·수리 후 재시도** (48h 재주행,
unattended-ops-rules.md 절차 준용: 개입 = 시도 종료).
