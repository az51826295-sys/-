# 무인 운영 규칙 (4개월차 1주차 동결)

## 2. 게이트 — 사전 등록, 실행 시점 판단 없음

- **비가역 행동 목록** (`routing.IRREVERSIBLE`, 동결): force
  push / 브랜치 강제 삭제 / reset --hard / 작업공간 밖 clean /
  PR merge. 자동 실행 불가 — 승인 큐 전용. 실행 시점에 모델이
  판정하지 않고 목록 대조만 한다.
- **rollback_target 게이트**: 장부 v0 그대로 — 롤백 대상 없는
  차단·확정은 승인 큐로 강등. 엔진 과제는 격리 워크트리 + 검토
  브랜치 위에서만 동작하므로 **모든 채택의 롤백 대상은 base
  브랜치로 존재**한다 — 예외가 생기면 그 자체가 격리 위반이다.
- **예산 상한은 사람이 하나만 설정한다**: 일일 KRW 상한
  (`ROOKERY_DAILY_KRW`). 나머지 단계(warn/restrict/stop)는 그
  값에서 기계 유도되는 기존 원장 정책.

## 3. 장부 ≠ 기각된 기억 기능 (경계 재명시)

P36·P38·P39b에서 세 번 기각된 것은 **탐색 프롬프트에의 이력
주입**이다. 상태 장부는 운영 상태(확정 사실·차단 목록·롤백
대상)이며 **선택·게이트에만 작용하고 어떤 제안 프롬프트에도
들어가지 않는다** (출처 계약 8항). 무인 운영을 붙이면서 이 선이
흐려지기 쉽다 — 코드 리뷰 시 이 문서와 대조하라.
