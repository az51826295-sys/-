# 캐릭터 시스템을 처음부터 짜 주세요 — 논의거리

(2026-10-03. 이 글 하나만 읽고도 답할 수 있게 적었습니다. 앞뒤 맥락 없습니다.)

## 만들고 있는 것

모바일 세로 화면의 **길드 경영 + 방치형 RPG** 입니다. 두 쪽으로 되어 있어요.

- **본부** — 숙소·선술집·저장소·시장·작업장·보호소. 건물마다 수용량/속도를 올립니다.
- **던전** — **1층부터 100층까지** 올라갑니다. **10층 단위로 구간**이 나뉘어 맵과 몬스터가 통째로 바뀌고, **10·20·30… 층마다 보스**가 있습니다.

전투는 **자동**입니다. 내 모험가가 왼쪽에서 오른쪽으로 스스로 전진하고, 적은 반대로 옵니다. 만나면 알아서 싸웁니다.
플레이어가 전투 중에 하는 조작은 **스킬 단추 한두 개(쿨타임)** 뿐입니다. 이동·공격은 못 시킵니다.

## 이미 정해진 것 (바꾸지 말아 주세요)

1. **환생(프레스티지)은 없습니다.** 초기화하고 다시 올라가는 구조를 안 씁니다.
2. 100층이 **끝**입니다. 무한 층 올리기가 아닙니다.
3. **시스템 먼저, 그림은 나중.** 지금은 네모와 글자로만 돌립니다.
4. 자동 전투입니다. "플레이어가 유닛을 조작한다" 는 답은 못 씁니다.
5. 방치형입니다. 앱을 꺼 두거나 다른 화면을 보고 있어도 던전은 계속 돕니다.

## 이미 돌아가는 것 (실제로 측정됨)

HTML 한 장짜리 시제품이 돕니다.

- 본부 건물 6개, 누르면 팝업, 올리기 단추가 숫자를 바꿈
- 아래 탭 넷(본부·모험가·던전·전투)
- 자동 전투가 돌아 **한 층에 약 30초**씩 층이 오름
- 모험가 목록(이름·레벨·특성 2개·장비 3칸)이 **보이기만** 함

## 지금 가장 큰 구멍

**전투가 본부와 아무 상관이 없습니다.**

전장에 나가는 유닛이 내 모험가가 아닙니다. 레벨도, 장비도, 특성도 전투 숫자에 한 글자도 안 들어갑니다.
그래서 **선술집에서 누구를 고용하든 결과가 똑같습니다.** 캐릭터 시스템을 새로 짜려는 이유가 이것입니다.

## 참고한 게임에서 **관찰된** 것 (베낄 의무 없음, 재료로만)

같은 장르 게임의 화면을 보고 적은 것입니다. 해석이 아니라 **본 것**만 적습니다.

- 모험가 카드 = 그림 + 이름 + **레벨 숫자** + **특성 2개** + **장비 3칸**
- 이름이 등급처럼 보임: 견습생 · 도적 · 궁수 → 천사 · 이단심문관 · 발로그 · 대천사
  (레벨 1짜리는 견습생/도적, 레벨 30대는 화려한 이름)
- 특성 목록: `야생` `집중` `거구` `공감` `무자비` `축복받음` `경계` `재능` `책벌레` `저주` `야행성`
- 선술집에 **"견습생 신규!"** 로 새 사람이 들어옴. 특성이 0개인 사람도, 2개인 사람도 있음
- 선술집 수용량 10, 일정 시간마다 새 방문객
- 숙소 수용량 16 = 모험가 보유 한도
- 상점에는 특성에 **+** 가 붙은 사람이 있음 (예: `거구+`, `책벌레+`)

**못 본 것**: 특성이 실제로 무슨 효과인지, 레벨이 어떻게 오르는지, 승급이 있는지, 전투에서 뭐가 어떻게 계산되는지 — 숫자는 하나도 못 봤습니다.

## 물어보고 싶은 것

아래에 제 생각을 안 적었습니다. **백지에서** 짜 주세요.

1. **캐릭터를 뽑는 게임인가, 키우는 게임인가?**
   계속 새로 뽑아 갈아 끼우는 쪽과, 몇 명을 오래 키우는 쪽 중 어디가 이 게임에 맞나요? 섞는다면 어떻게?

2. **특성(`거구` `야생` 같은 것)이 무슨 일을 해야 하나?**
   뽑을 때 정해지고 못 바꾸는 게 좋은가요, 바꿀 수 있어야 하나요? 그 선택이 무엇을 바꾸나요?

3. **직업/역할을 어떻게 나눌까?**
   몇 개가 적당한가요? 플레이어가 "지금 우리 파티에 뭐가 없다"를 **한눈에** 알 수 있어야 하는데, 그러려면 어떻게 보여 줘야 하나요?

4. **성장은 무엇으로 하나?**
   레벨이 저절로 오르면, 막혔을 때 **기다리기만 해도 뚫립니다.** 그러면 본부(건물·장비·고용)를 볼 이유가 없어집니다.
   이 문제를 어떻게 푸나요? 레벨을 안 쓰는 답도 괜찮습니다.

5. **10층마다 오는 보스가 캐릭터 시스템과 어떻게 엮여야 하나?**
   자동 전투라 보스를 "체력 큰 몹"으로 만들면 플레이어는 구경만 하다 집니다.
   보스가 **파티 구성을 묻는 시험**이 되려면 캐릭터 쪽에 무엇이 있어야 하나요?

6. **모험가가 죽나요?**
   방치형이라 자고 일어났더니 전멸해 있을 수 있습니다. 죽는 쪽/안 죽는 쪽, 각각 무엇을 얻고 잃나요?

7. **동시에 몇 명이 출전하나?**
   그 숫자가 역할 설계에 어떤 영향을 주나요?

8. 제가 **안 물어본 것 중에** 먼저 정해야 하는 게 있으면 그것부터 말해 주세요.

## 답 형식 부탁

- "~하면 ~된다" 꼴로 적어 주시면 그대로 검사 기준이 됩니다. (예: *보스 앞에서 마법 역할이 없으면 → 적 체력이 안 깎인다*)
- 추측과 확신을 갈라 적어 주세요.
