# 소크 중단 원인 분류 규칙 — 사전 등록 (2026-08-15, 판정 전 동결)

> 처방이 정반대인 세 분류(인프라 / 게이트 과보수 / 판단 실패)를
> 결과를 본 뒤 고르면 P10·P16과 같은 사고다. 규칙과 모서리를
> 지금 박는다. 이 문서 이후의 개정은 기준 개정 프로토콜을 따른다
> (개정 시 해당 판정은 탐색적 강등).

## 분류의 단위

분류 대상은 **중단 사건**(시도가 168h를 못 채우게 만든 사슬)
하나다. 사슬 안의 여러 관측은 부수 기록으로 남기되, **1차 원인은
인과 사슬의 최초 사건** 하나로 정한다.

## 기계 서명 (원장 이벤트 기준)

| 분류 | 서명 | 처방 방향 |
|---|---|---|
| **인프라 장애** | 프로세스 소멸(외부 원인), Kernel-Power 이벤트, INFRA_MARKERS(10055·urlopen·getaddrinfo 등) 계열 worker_exception, 전원·디스크 | 환경을 고친다 (엔진 아님) |
| **게이트 과보수** | 엔진이 스스로 세운 정지가 진행을 막음: infra_backoff 무한 반복, 승인 큐 적체로 처리량 0, halt 플래그 오발동 | 게이트 문턱을 푼다 |
| **판단 실패** | validator/auditor가 기각한 산출물의 누적, 라우팅 오선택(routed_smart 오발동/미발동), 채택된 작업의 회귀 | 라우팅·오라클을 고친다 |

## 모서리 (지금 정한다)

1. **두 원인이 동시에 관측되면**: 1차 원인 = **원장 타임스탬프
   기준 인과 사슬의 최초 사건**. 예: 인프라 오류 → 백오프 연발 →
   처리량 0으로 중단이면, 1차 = 인프라 (백오프는 부수 기록).
   반대로 인프라 회복 후에도 백오프가 안 풀려 멈췄다면 최초
   사건은 게이트 결함이다 — 판별 질문: *"그 사건이 없었어도
   중단됐는가"*를 최초 사건부터 순서대로 적용한다.
2. **판정 불가면**: `미정의` 분기가 존재한다 (정상 반환값).
   조건: 원장에 위 서명 중 어느 것도 없거나, 최초 사건의
   타임스탬프를 특정할 수 없을 때. 미정의는 사람 검토 큐로
   가며, 재시도는 미정의 해소 전 금지 — "원인 분류 없이 다시
   돌리면 같은 곳에서 멈춘다".

## 완주 시

중단이 없으면 이 문서는 발동하지 않는다. 소크 판정은
`criteria/soak7d.yaml`(동결본)로 judge.py가 하며, 판정표에
**행사된 층**(eligibility·operationalize·threshold — margin 층은
안 돎)을 명시한다.
