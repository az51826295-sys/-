## 1. 조회 키

`(state_signature, phase, action)` — failure_archetype은 **사후
분석 전용, 조회 키에 넣지 않는다** (동결).

- **phase**: 라운드 3분위 — early(1~4) / mid(5~8) / late(9~12).
  n_rounds=12 기준, 다른 설정에서는 균등 3분할.
- **action**: 이벤트 kind × 대상 유형 —
  `PROPOSE`, `MODIFY_own`, `MODIFY_other`, `CRITIQUE`, `SIMULATE`.

## 2. 세 해상도 (state_signature)

재실행으로 복원한 시도 시점 보드에서 계산한다.

| 해상도 | 정의 |
|---|---|
| **full** (전체 보드) | 존재하는 전 제안의 (spec 정규화 JSON sha1-12, objective 1e-6 반올림)를 정렬한 목록 + phase의 sha1-12 |
| **local** (착수점 국소) | 행동 대상 제안의 (spec 해시, objective 반올림, 부모 spec 해시, 미해소 비판 수) — PROPOSE는 대상이 없으므로 (보드 최고 objective 버킷, 제안 수 버킷) |
| **stat** (요약 통계) | (phase, 제안 수 5단 버킷, 최고 objective 0.05 버킷, 평균 objective 0.05 버킷) |

`signature_equal` 인터페이스: 해상도별 서명 문자열의 완전 일치.
근사 매칭 없음 (v0).

## 3. disposition 규칙 (동결)

키별 상태는 넷 중 하나. 전이는 기계 판정만.

- **BLOCK (금지)**: 같은 키의 검증된 실패가 **3회 이상** 누적.
  단, `rollback_target`(되돌릴 확정 상태)이 없으면 BLOCK 불가 —
  승인 큐로 보낸다.
- **PENALIZE (감점)**: 검증된 실패 **2회** — 선택 단계 우선순위
  감점, 실행은 허용.
- **CONDITIONAL (조건부 허용)**: 실패 1회 — 기록만, 개입 없음.
- **RELEASE (해제)**: 키의 state_signature 구성 요소가 실질
  변경되면(국소 해시 변화) BLOCK/PENALIZE 해제. 시간 경과로는
  해제하지 않는다.

"차단?" 판정에 사람 판단 없음 — 표의 앞 열들에서 규칙이 기계
산출한다 (2주차 표 작성 규칙).

## 4. U_saved · U_calls 산정 관례 (동결)

- 조회 키 기준으로만 집계한다. **원형(archetype) 기준 집계 금지.**
- `U_saved = Σ_k max(0, n_k − 1)` — 같은 키의 반복 등장 횟수.
- `U_calls = Σ_k (n_k − 1) · c_k`, **c_k = 8호출** (한 라운드 —
  LLM 조건이 그 상황에서 지출했을 낙관 상한). 이 관례는 보수적
  이 아니라 **낙관적**임을 명시한다 — 장부에 유리한 상한이며,
  이 상한조차 실험 비용을 못 넘으면 실험은 이길 수 없는 판이다.
- unresolved(대상 소실·복원 불가 이벤트)는 분류별 분리 보고,
  일부 무작위 강제 확인.

## 5. 3개월차 진입 임계값 (숫자 보기 전 동결)

- 조건 실험 계획치: **T_exp = 2,560호출** = 조건 2(요약만 vs
  장부) × 20런 × 8라운드 × 8호출. 조건 축소 우선순위(2 → 2.5 →
  3 → 1)를 이미 반영해 월 3,000 내로 접었다 — 런 수는 줄이지
  않는다 (실험 1의 σ 교훈).
- **취소 규칙: U_calls(낙관 상한) < 2,560이면 조건 실험을
  취소한다.** 3개월차는 코드 레인 원로그 확보·방법 이식으로
  대체된다. 이 판정에 재량 없음.
- 진입 3조건: ① U_calls ≥ 2,560 ② 재매칭 되는 해상도 ≥ 1
  (재매칭 0이면 서명 정의 재검토가 선행) ③ T_exp ≤ 3,000 (구성상
  충족).

## 5.1 진입 판정 (2026-08-08, 공식 대조 — 4주차)

1주차에 동결한 임계값과 3주차 실측의 대조. 재량 없음.

| 조건 | 기준 | 실측 | 판정 |
|---|---|---|---|
| ① U_calls ≥ T_exp | 2,560 | full 24,392 / local 30,552 / stat 60,176 | **충족 (전 해상도)** |
| ② 재매칭 해상도 ≥ 1 | > 0 | 0.333 / 0.417 / 0.821 | **충족 (셋 다)** |
| ③ 조건 실험 ≤ 월 예산 | 3,000 | 계획 T_exp = 2,560 | **충족 (구성상)** |

**판정: 3개월차 조건 실험 진입 확정.** 균형점 후보 해상도 =
local (재매칭 0.417, 오차단률 0.155). 조건 실험의 세부(조건 2종
확정, 사례·런·라운드)는 3개월차 1주차 사전 등록에서 동결하며,
그 등록의 총호출이 3,000을 넘으면 ③이 소급 위반된다 — 등록서가
이 표를 인용해야 한다.

낙관 상한 주의(재확인): 통과는 "장부가 이길 수도 있는 판"까지만
말한다. 이득 입증은 조건 실험의 몫이다.

## 6. 2주차 표 스키마 (동결)

`시도 / 서명(3열: full·local·stat) / 국면 / 선택 수 / 결과 /
원형 / 조회 키 일치? / 규칙상 차단?` — 마지막 두 열은 앞 열에서
기계 산출. 중복률·고유 서명 수는 같은 표에서 뽑는다.
