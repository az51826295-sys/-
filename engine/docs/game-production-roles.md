# FUNCTION — 직업 12개와 담당 (사장님 지시, 2026-08-27 00:2x)

사장님이 새벽에 주신 생산 계획을 옮긴다. 게임 이름(FUNCTION), 주인공(Box),
수치(Potential·Resonance), 서사 축(Origin·Error·End)은 이 저장소에 처음 들어오는
이름이라 여기 앉힌다.

**초판 정정(00:3x)**: 원문의 "내가 함"을 사장님으로 옮겼는데, 사장님이 바로
잡아주셨다 — **그 "내가"는 클로드**다. 즉 12개 중 아홉이 내 몫이다. 아래 표는
고친 것이다. 잘못 옮긴 채로 두면 아침에 서로 다른 지도를 들고 시작하게 된다.

**외부 생성 AI는 셋뿐**: PixelLab(4·5), Retro Diffusion(6), ElevenLabs+Suno(9·10).
나머지 아홉은 내 몫이고, 그중 넷(1·2·3·12)은 **판단이 들어가는 자리**라 사장님
확인이 붙는다. 코드 넷(7·8·11 + 12의 계측)은 내가 바로 민다.

### 1-1. 시나리오는 짚고 넘어가야 한다 (내가 확인받을 것)

원문 요지: *"스토리는 세계관 일관성이 생명이라 매번 프롬프트로 뽑으면 톤이
무너진다. 이미 짜둔 흑백/색·가능성 철학 위에 직접 쓴다."*

여기서 "직접"이 **클로드가 직접**이라는 뜻이라면, 사장님이 08-2x에 세워둔 규율
하나와 부딪힌다: **창작 방향은 사장님 것이고, 나는 내 상상으로 캐릭터·세계를
지어내지 않는다.** 톤·철학(흑백/색, 가능성)은 이미 사장님 것이므로, 내가 쓰는
것은 그 위의 **초안**이어야 하고 채택은 사장님이 한다.

그래서 아침에 한 줄만 확인받는다:

> 시나리오를 **내가 초안 → 사장님이 채택/수정**으로 갈까요, 아니면 세계관 문서를
> 먼저 사장님이 쓰고 내가 그 아래 대사만 채울까요?

둘 다 "외부 생성 AI는 안 쓴다"는 지킨다. 다른 건 **누가 톤을 정하느냐**다.

## 2. 지금 저장소에 이미 있는 것 (2026-08-27 00:2x 확인)

사장님이 "Box 스프라이트 먼저 뽑고 움직이는 걸 보자"고 하셨는데,
**이동은 이미 굴러간다.** 새로 뽑기 전에 이것부터 보시는 게 빠르다.

| 있는 것 | 어디 |
|---|---|
| Godot 4.7 프로젝트(640×360, 최근접 필터, 2배 창) | `game/project.godot` — 헤들리스 적재 확인 완료(오류 0) |
| 4방향 걷기 + 정지 자세 주인공 | `game/scripts/player.gd`, `game/assets/characters/hero` |
| 순찰하고 인사하는 상인 NPC | `game/scripts/merchant.gd`, `.../merchant` |
| 타일 아틀라스·마을 맵 | `game/assets/tiles/atlas.png`, `game/scripts/village_map.gd` |
| PixelLab 발주 도구 | `tools/artgen/audition_pixellab.py` (키: `.secrets/pixellab.key`) |

즉 4·5번(캐릭터·애니메이터)의 **파이프라인은 이미 한 번 돌아본 것**이고,
08-07 오디션 산출물이 그대로 게임 안에서 걷고 있다.

## 3. 내가 밤에 하지 않은 것과 이유

- **PixelLab 신규 발주(Box 스프라이트)**: 하지 않았다. 이유 둘 —
  (a) Box의 생김새 규격이 아직 없다. 내가 상상해서 주문하면 그건 사장님 창작
  방향을 내가 정하는 것이다. (b) PixelLab은 우리 원장 밖 서비스라 지출 상한도
  기록도 없다. 아침에 규격과 승인을 받고 건다.
- **Retro Diffusion / ElevenLabs / Suno**: 키도 절차도 아직 없다. 붙이려면
  각각 반입 오라클(규격 심판)부터 세워야 한다 — 픽셀 스프라이트에 한 것처럼.

## 4. 다음 한 걸음 (내 추천)

**Box를 뽑기 전에 이동 감각을 먼저 재자.** 지금 있는 주인공으로 30분이면 된다.
"감각"을 통째로 사람 눈에 맡기지 않고 둘로 가른다:

| 기계가 재는 것 | 사람이 보는 것 |
|---|---|
| 입력 → 첫 이동 프레임 수, 가·감속 프레임, 초당 이동 픽셀, 걷기 프레임 타이밍(9fps), 대각선 속도 보정, 카메라 추종 지연 | "맛있는가" |

앞칸은 수치로 동결하고, 뒤칸은 사람 눈 게이트로 선언한다. 그래야 Box가 나온
뒤에 "전보다 나아졌나"를 말할 수 있다. 설계는 `docs/game-feel-v0-design.md`.
