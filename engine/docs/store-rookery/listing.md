## 구글 플레이

**앱 이름 (30자):** Rookery

**간단한 설명 (80자):**
여러 AI를 지휘해 조사·문서·앱·그림·영상을 만들고, 결과를 판정하는 AI 사무실.

**자세한 설명 (4000자):**

Rookery(로키)는 혼자 답하는 AI가 아니라, 여러 생성 AI를 지휘하는 AI 사무실이에요.
하고 싶은 일을 말하면 찾아볼 것은 찾아보고, 시간이 드는 일은 AI 직원에게 업무로 맡겨요.

■ 이런 일을 해요
· 자료·유튜브 영상 분석 — 요약, 핵심 주장, 숫자 뽑기
· 경쟁사 분석, 시장 조사
· 게임·앱 만들기, 웹 도구
· 2D 픽셀 그림, 3D 모델
· 약 60초 설명 영상 (대본·음성·자막)

■ 결과 옆에 늘 미리보기
돌아온 결과는 대화 옆 미리보기에 버전별로 쌓여요. 지난 버전으로 언제든 복원할 수 있어요.

■ 승인할수록 나아져요
결과를 승인하거나 수정 요청을 누르면, 직원은 일을 시작하기 전에 적어 둔 예측과 실제 판정을 비교해 스스로 기준을 고쳐요. 수정 요청을 누르면 적은 이유대로 바로 다시 고쳐요.

■ 컴퓨터와 폰을 이어서
컴퓨터 로키의 메뉴에서 "폰으로 이어하기"를 누르고 QR을 찍으면, 비밀번호 없이 같은 계정으로 폰에서 이어서 볼 수 있어요.

■ 비용이 보여요
이번 달 사용액이 늘 보이고, 회사마다 한도가 있어요.

로그인 없이 몇 번 써 볼 수 있어요. 대화와 결과물을 저장하려면 로그인하세요.
AI가 만든 답이나 결과물이 부적절하면 앱 안의 "신고"로 알려 주세요.
계정과 모든 데이터는 메뉴의 "계정 삭제"로 언제든 지울 수 있어요.
