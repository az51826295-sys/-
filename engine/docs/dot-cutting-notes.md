## 1. "자르기 잘 안 됐다"의 정체

사장님이 집은 것은 **린·유나의 머리 옆에 붙은 밝은 티끌**이다. 시트에서 캐릭터를 떼어낼 때
**배경이 머리카락 가장자리에서 덜 떨어진 것**이고, 그 조각이 머리에 **붙어 있다.**

붙어 있다는 게 핵심이다. 그래서 처음 만든 자가 못 봤다.

| 자 | 무엇을 세나 | 결과 |
|---|---|---|
| `dot_cut_check.mts` | 떨어진 조각 · 캔버스 가장자리에 닿은 잉크 | 66칸 전부 0 — **못 봤다** |
| `dot_fringe.mts` | 실루엣 테두리에서 **이웃과 색이 다른 도트** | 도윤 1등, 린 꼴찌 — **말과 어긋났다** |
| `dot_fringe.mts` (지금) | 위 + **그 그림 가운데 밝기보다 25 밝을 것** | 유나 5.5 · 도윤 4.6 · 린 1.7% — **맞는다** |

`dot_cut_check` 가 침묵한 것은 고장이 아니다. 심은 고장(떨어진 조각 · 가장자리 잉크)은 둘 다
잡았다. **다른 것을 재고 있었을 뿐이다** — 티끌이 머리에 붙어서 덩어리가 하나로 세어졌다.

### 자를 사장님이 골랐다

후보 넷(튀어나온 도트 / 둘레÷잉크 / 밝은 티끌 / 가로 1칸 선)을 전부 돌려 **순위표를 보여 드리고**
고르게 했다(`dot_ragged_probe.mts`). 넷 다 도윤을 1등으로 올려서 내 눈으로는 고를 수 없었다.
**사람 눈으로 판정되는 불평은, 후보 자를 여러 개 돌려 놓고 사장님이 고르게 하는 게 제일 빠르다.**

## 3. 자르기 자를 만들 때 지킬 것

- **격자를 먼저 재고 그 위에서 센다.** 화소로 세면 티끌 하나가 64개로 부풀고, 지울 때 멀쩡한
  데를 긁는다. `texel_judge` 로 도트 크기를 받아 `findFringe(png, texel)` 에 넣는다.
- **지우기는 칸 단위 · 투명으로.** 크기도 자리도 안 바뀌므로 도트 크기가 그대로여야 하고,
  `dot_fringe.mts` 가 지운 뒤 도트를 다시 재서 밀렸으면 **올리지 않는다.**
- **심은 고장을 늘 같이 돌린다.** `--sabotage` 는 실루엣 **옆 배경 칸**을 밝게 칠한다(덩어리는
  그대로 — 앞 자가 못 보던 바로 그 모양). 밝은 칸 12개를 심으면 티끌이 정확히 12 늘어야 한다.
- **0 은 "깨끗하다"가 아닐 수 있다.** `dot_cut_check` 가 66칸 0 을 냈을 때 그건 깨끗함이 아니라
  **안 보임**이었다.

## 4. 가지 말 것 — 색표 묶기 (대조군이 뒤집었다)

"캐릭터 21쌍 전부 색 겹침 0% 라서 제각각으로 보인다"고 적고 고치는 코드까지 만들었다.
겹침 0% → 65% 로 올렸고 도트 크기도 안 밀렸다. **그런데 사장님이 *한 결*이라고 한 피드도
겹침 0.0% 였다**(`dot_palette_control.mts`). 좋은 쪽과 나쁜 쪽의 값이 같으면 그 값은 원인이 아니다.

눈으로도 틀렸다 — 피드에서 뽑힌 16색이 거의 살구·갈색이라 **나비의 분홍·민트가 흰색**이 되고
**유나의 빨간 리본이 갈색**이 됐다. 그래서 `--palette` 로만 남겼다. 다시 켜지 말 것.

## 5. 같이 알아 둘 것 — 퀄리티가 제각각인 진짜 까닭

| | 원인인가 | 근거 |
|---|---|---|
| **밀도** | ✅ | 격자 64 = 4,096점 vs 피드 5만점. **12배.** `pixelize` 기본값을 **256**(도트 2)으로 올렸다 — **새로 그리는 것부터** 적용된다. 이미 깎인 42장은 되돌아오지 않는다. |
| 색표 따로 | ❌ | 4번 |
| 유나 멘헤라 격자 깨짐 | ✅ (6칸만) | 도트 못 잼 · 순도 0.27~0.32 |
| 크기 제각각 | ⚠️ 못 고침 | 잉크 폭 344(도윤)~480(나비). 키우거나 줄이면 격자가 깨지므로 **그리는 쪽에서 맞춰야 한다.** |

**격자 값은 아무 수나 못 쓴다.** `512 ÷ 격자`가 정수여야 도트가 정사각으로 떨어진다 —
**64·128·256·512만** 성립한다. 96 은 5.33, 160 은 3.2 라 격자가 깨지고 도트 자가 "못 잼"을 낸다.
