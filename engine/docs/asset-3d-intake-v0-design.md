# 3D 자산 반입 규격 v0 — 오디션 전에 얼린다

2026-09-05 14:55. 사장님 결정: 진짜 게임은 3D, 메시는 **Meshy-6**(15:00 "오디션 안 하고
그냥 이거 쓰자"). 이 문서는 **첫 메시를 보기 전에** 쓴다. 숫자를 보고 문턱을 정하면 그것은
통과시키고 싶은 값을 고른 것이지 판정이 아니다([[pick-session-judge]]).

## 0. 무엇을 재고 무엇을 안 재나

| 재는 것 | 안 재는 것 |
|---|---|
| 삼각형 수 · 메시 수 · 닫힘(매니폴드) · 법선 일관 · UV 유무 · 텍스처 유무 · 크기(높이) · 위 축 · 본 수·이름 | **닮았나**(레퍼런스와) · 예쁜가 · 리깅이 자연스러운가 |

오른쪽은 사람 눈이다. 기계가 재는 척하면 판정이 판정이 아니게 된다
([[rookery-north-star-fresh-machine]] C 의 원칙 그대로).

## 1. 규칙 — 세 값(PASS / FAIL / UNDEFINED)

대상은 glTF 바이너리(`.glb`) 한 파일. 둘 다 GLB 를 낸다.

| # | 규칙 | PASS | FAIL | UNDEFINED |
|---|---|---|---|---|
| T1 | 삼각형 수 (캐릭터) | 2,000 ≤ n ≤ 40,000 | 그 밖 | 삼각형이 아닌 프리미티브만 있음 |
| T2 | 메시(프리미티브) 수 | ≤ 8 | > 8 | — |
| M1 | 닫힘 | 모든 메시가 watertight | 하나라도 아님 | 파서가 판단 못 함 |
| M2 | 법선 일관 | winding 일관 | 뒤집힌 면 있음 | 법선 없음 |
| U1 | UV | 모든 메시에 UV 있음 | 없는 메시 있음 | — |
| X1 | 텍스처 | baseColor 텍스처 ≥ 1 | 없음 | 재질 없음 |
| S1 | 크기 | 높이 0.5 m ≤ h ≤ 3.0 m (1 단위 = 1 m) | 그 밖 | 바운딩 박스 0 |
| A1 | 위 축 | 가장 긴 축이 Y | 다른 축 | 세 축이 비슷(±10%) |
| B1 | 본 | **요청했을 때만**: 본 ≥ 10, 이름 있음 | 요청했는데 없음 | 요청 안 함 |

- 종합: FAIL 하나라도 있으면 FAIL. FAIL 없고 UNDEFINED 있으면 UNDEFINED. 다 PASS 면 PASS.
- **UNDEFINED 는 통과가 아니다.** 못 잰 것을 통과로 세면 못 잴수록 잘 통과한다.

## 2. 숫자의 근거 (정한 이유, 잰 값 아님)

- T1 하한 2,000: 그 아래면 "형태"가 아니라 프리미티브다. 상한 40,000: 브라우저
  3D(Three.js) 캐릭터 하나의 상식적 예산. 소품은 v1 에서 따로 둔다.
- S1: glTF 규약이 1 단위 = 1 m. 사람 크기 캐릭터 기준. Box 처럼 작은 캐릭터면
  사장님이 크기를 정하신 뒤 v1 에서 바꾼다 — 바꾸는 것은 문서에 적고 바꾼다.
- A1: glTF 는 Y-up 이 규약이다. 생성기가 Z-up 을 내면 엔진에서 눕는다.

## 3. 반입 절차

1. 사장님이 준 이미지 한 장 → Meshy-6 이미지→3D(쿼드 리메시) → GLB.
2. 이 규격으로 잰다 → 표. FAIL 이면 그 줄과 함께 대화로 돌려주고 다시 만들지
   않는다 — 다시 만들지는 사람이 정한다(크레딧이 나간다).
3. 결과(GLB 링크·썸네일·표)를 대화(`/ask`)로 돌려준다. **쓸지는 사장님**이 정한다.

## 4. 바꾸지 않는 것

- 이 표의 숫자는 첫 메시를 본 **뒤에** 안 바꾼다. 바꿔야 하면 v1 문서로, 이유와 함께.
- 판정기는 거르기만 한다. 순위를 매기지 않는다.
