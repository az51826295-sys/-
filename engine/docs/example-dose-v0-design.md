# 예시 용량-반응 사전 등록 v0 (실지출)

작성 2026-08-26 23:2x. 사장님 야간 포괄 승인. **숫자 보기 전 등록.**
예상 지출 **$0.15 이하**(상한 `--max-usd 0.25`).

## 1. 왜 이걸 등록하나

오늘 밤 **사고로** 같은 개념·모델·온도에서 예시만 다른 두 회차가 생겼다:
예시 없음 통과율 **0.15**(20/132), 예시 셋 **0.99**(120/121). 프롬프트 통제도
같은 곳을 가리켰다(`with_spec` 0.385 / `no_spec` 0.0 — 둘 다 예시 없음).

**이건 제품 설명을 바꿀 만한 주장이다**: 우리 파이프라인의 순응은 스펙 문장이
아니라 **이미 통과한 자산의 되먹임**에서 나온다. 그런데 근거가 사고의 부산물이라
등록된 실험이 없다. 여기서 등록한다.

그리고 이분법으로 묻지 않는다. 실무에서 중요한 질문은 **"몇 개부터 듣는가"** 다 —
세트의 첫 아이콘은 예시가 0개이고, 둘째는 1개다.

## 2. 팔 셋 (동결)

프롬프트에서 **예시 개수만** 다르다. 스펙 블록·시스템 프롬프트는 세 팔 모두 현행.

| 팔 | 예시 | 대응하는 실제 상황 |
|---|---|---|
| `ex0` | 0개 | 세트의 **첫** 아이콘 |
| `ex1` | 1개 | 둘째 아이콘 |
| `ex3` | 3개 | 넷째 이후(현행 상한이 3개다) |

- 예시 자산은 `out/icons/pick-v2/candidates/{01_attack,02_defend,03_shop}`의
  첫 후보로 **고정**한다(순서도 고정).
- **시험 개념은 예시로 쓰인 개념을 제외한다** — attack·defend·shop을 시험 개념에
  넣으면 예시가 곧 정답이라 순환이다. 시험 개념 9개:
  `quest, equipment, stats, dialogue, exit`(rpg-ui-v2 세트) +
  `save, inventory, map, settings`(rpg-ui-v1 세트).
- 팔마다 개념당 1회 호출, 후보 6개, **라운드 1만**, 중복 제거 없음, 재시도 없음.
  (오늘 프롬프트 통제와 같은 규율 — 분모를 팔마다 다르게 만들지 않는다.)

## 3. 판정식 (동결 — 숫자 보기 전)

**부트스트랩은 개념 단위(군집)로 잡는다.** 오늘 프롬프트 통제에서 후보 단위로
잡아 구간이 좁게 나왔고, 통과가 개념·호출 단위로 뭉친다는 것을 그 뒤에 확인했다.
같은 실수를 반복하지 않는다. 10000회, 시드 12345.

`D = rate(ex3) − rate(ex0)`:

| 조건 | 판정 |
|---|---|
| `D`의 95% 하한 > **0.20** | **examples_carry_compliance** |
| `|D|`의 95% 구간이 **±0.05** 안 | **examples_irrelevant** |
| 그 외 | **undefined** |

**표본 관문(동결)**: 개념 ≥ 8, 팔당 후보 ≥ 40. 미달이면 undefined이고 관문을
낮추지 않는다.

## 4. 판정이 아닌, 함께 남길 것

- `d01 = rate(ex1) − rate(ex0)` 과 `d13 = rate(ex3) − rate(ex1)`.
  **"하나면 충분한가"** 가 여기서 읽힌다. 판정 문턱은 걸지 않는다(기술 통계).
- 팔별 위반 규칙 분포 — 예시가 **무엇을** 가르치는지(격자? 끝모양? 굵기?).
  오늘 프롬프트 통제에서 스펙 텍스트는 `stroke-width`를 가르치고 격자·끝모양은
  못 가르쳤다. 예시가 그 빈칸을 메우는지 본다.
- 개념별 통과율 — 뭉침(clustering)의 크기를 눈으로 볼 수 있게.

## 5. 미리 적어두는 한계

- 예시 자산이 특정 세트(rpg-ui) 스타일이다. "예시 일반"이 아니라 **"같은 세트의
  통과 자산"** 의 효과를 재는 것이다.
- 개념 9개, 팔당 54후보는 군집 부트스트랩에서 넉넉하지 않다. `undefined`가 나올
  수 있고, 그때 결론은 "모른다"이지 "효과 없다"가 아니다.
- 통과율은 **하드 스펙 순응**이지 그림의 좋음이 아니다. 예시가 순응을 올리면서
  다양성을 깎을 수 있다 — 그건 §4의 구조 서명으로 따로 본다(판정 아님).
