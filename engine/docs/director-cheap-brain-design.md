# 싼 판단자로도 판단이 서나 (사전 등록, 2026-11-20 23:2x)

1단계 끝: 판단자(gpt-5) 한 번 ≈ $0.02, 일 한 번 ≈ $0.003 — **판단이 일의 일곱 배.** 새 종류마다 다섯 번 이 세금을 낸다.
사장님 "해 2단계". 판단자를 싼 AI 로 바꿔도 되는지 **숫자를 보기 전에** 판정식을 여기 잠근다.

## 후보

## 시험 둘

**A. 다시 판단하기 (결과를 아는 판)** — gpt-5 가 실제로 판단자를 불러 정했던 판 15개를, 그때의 장부 그대로 다시 준다.
- 11-20 실제 일 5개(자리: 클로드 하위 에이전트 넷) + 11-20 첫 실험의 켬 팔 10판(자리: OpenAI 여섯).
- 장부가 답한 여섯째 판은 판단자를 안 불렀으니 뺀다.
- 잰다: gpt-5 와 같은 자리를 골랐나 · 같은 자리를 고른 판에서 예측 오차(Brier, 결과를 아니까) · 판단 한 번 값.

**B. 올려야 하는 판 (정답이 규칙으로 정해진 판)** — A 는 전부 쉬운 일이라 "제일 싼 걸 고르면 맞는" 판뿐이다.
위로 올려야 할 때 올리는지는 A 로 못 잰다. 그래서 장부를 지어 세 판을 둔다:
1. 장부: haiku 가 "게임" 0/5 실패. 새 게임 일 → **haiku 가 아니면 맞음.**
2. 장부: luna "고침" 1/6(최근 둘 실패), gpt-5 "고침" 5/5. 새 고침 일 → **luna 가 아니면 맞음.**
3. 자리: 제일 싼 `cheap-blind`(그림 못 봄) · `mid`(그림 봄). 일: "이 스크린샷의 단추 줄맞춤이 틀렸다, 고쳐" → **mid 면 맞음.**
gpt-5 도 B 를 같이 돈다(기준도 틀릴 수 있다).

## 판정 (잠금)

후보 하나가 **선다** = 아래 넷 다:
1. B 세 판 **전부** 맞음
2. A 에서 gpt-5 와 같은 자리 **12/15 이상**
3. A 에서 같은 자리를 고른 판의 Brier 가 같은 판들에서 gpt-5 의 Brier **+0.05 이하**
4. 판단 한 번 평균 값이 gpt-5 의 **1/4 이하**

둘 다 서면 **싼 쪽**을 기본 판단자로 바꾼다. 하나도 못 서면 gpt-5 를 두고 그렇게 적는다.
gpt-5 가 B 에서 틀리면 그것도 적는다(판정은 후보 기준 그대로).

## 이 판이 못 재는 것

- A 의 일은 전부 쉽다 — "갈리는 일" 은 3단계(그림)에서 잰다.
- 판이 적다(15+3). 후보마다 **한 번씩** 돈다 — 흔들림은 안 잰다.
- 값: 어림 $0.2. 넘어도 끝까지 돈다.
