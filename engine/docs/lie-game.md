# 거짓말의 온도 — 게임 설명서 (2026-10-01 현재)

사장님 기획을 받아 만든 **AI 취조 추리 게임**. 지금 `/lie` 에서 돌아간다.
이 문서는 **지금 실제로 되는 것**만 적는다. 안 된 것은 맨 아래 따로 적는다.

---

## 1. 한 줄로

> **정해진 선택지를 누르는 추리 게임이 아니다.**
> 형사가 되어 용의자 셋을 **직접 말로** 취조한다. 용의자는 AI 고, 거짓말을 하고, 몰리면 무너진다.

플레이어가 치는 말이 그대로 질문이 된다. 고를 수 있는 보기가 없다.

---

## 2. 플레이어가 하는 일 (한 판의 흐름)

```
① 용의자를 고른다 (한선호 · 윤미래 · 박태수 — 방마다 대화와 온도가 따로 간다)
        ↓
② 말을 건다 — 라포를 쌓거나, 떠보거나, 몰아붙인다
        ↓
③ 용의자가 거짓 알리바이를 꺼낸다 ("22시에는 윤미래 씨와 카페에 있었습니다")
        ↓
④ **다른 용의자에게 가서 확인한다** → 반박이 **새 증거**가 된다 (교차 검증)
        ↓
⑤ 증거를 눌러 고르고 들이댄다 → **진술이 깨진다**
        ↓
⑥ 압박이 문턱을 넘으면 **무너진다** → 실토
        ↓
⑦ 범인을 **지목한다** — 맞음 / 모자람 / 틀림
```

---

## 3. 네 가지 온도 — **왜 넷인가**

압박 하나만 두면 **아무 말이나 세게 하면 이기는 게임**이 된다. 그건 취조가 아니다.
그래서 넷이고, 서로 당긴다.

| 수치 | 무엇 | 높으면 |
|---|---|---|
| **압박** | 몰린 정도 | 문턱을 넘으면 무너진다 |
| **당황** | 방금 한 방 맞았나 | 말문이 막힌다("어… 그게…"). 빨리 오르고 빨리 식는다 |
| **분노** | 함부로 다뤘나 | **70 이상이면 입을 닫는다** — 압박이 100 이어도 안 분다 |
| **경계** | 떠보는 걸 눈치챘나 | **증거가 덜 먹힌다**(최대 85% 깎임) |

**고함은 증거가 아니다.** 날카로운 말은 압박을 +2 밖에 안 올리고 **경계를 +12** 올린다.
소리치면 상대가 말을 맞추고, 그 뒤에 내민 증거가 안 먹힌다.

**그래서 가장 빠른 길은 라포다.** 부드러운 말로 경계를 내려 두고 결정적인 증거를 꽂는 것.
자로 재 봤다 — **같은 증거 둘**인데 라포를 쌓은 쪽은 압박 100 으로 무너지고, 다짜고짜 민 쪽은 69 에서 멈춘다.

---

## 4. 증거는 두 종류다

| | 어디서 오나 | 보기 |
|---|---|---|
| **물증** | 형사가 **가지고 들어온다** (처음부터 6개) | 카페 CCTV · 기지국 기록 · 회사 장부 · 보험 서류 · 피 묻은 외투 · 흉기 감정서 |
| **증언** | **취조로 만들어 낸다** (교차 검증, 3개) | 윤미래의 진술 · 피해자가 아내에게 한 말 · 박태수의 목격 진술 |

**증언이 이 게임의 알맹이다.** 한선호가 "윤미래 씨와 카페에" 라고 하면 →
윤미래에게 가서 묻고 → *"한선호 씨요? 그날 저는 집에 있었어요"* → 그 말이 **증거가 되어** →
한선호에게 돌아가 들이댄다.

**물증 없이 증언 둘만으로도 범인을 무너뜨릴 수 있다.** 취조로 뚫는 길이 따로 있다.

**헛다리를 짚으면 손해다.** 상관없는 증거를 들이대면 압박이 **내려가고**(−5) 경계가 오른다(+10).
"다 들이대 보기" 가 안 통한다.

---

## 5. 무너뜨리기 — 세 조건을 **동시에**

```
압박 ≥ 문턱        (한선호 75 · 윤미래 55 — 약점 수에 따라 다르다)
    그리고
약점이 다 깨짐      (한선호 2개 · 윤미래 1개)
    그리고
분노 < 70          (화나 있으면 입을 닫는다)
```

**자백은 코드가 연다.** 이 셋이 맞기 전에는 **자백할 내용을 AI 프롬프트에 아예 넣지 않는다.**
그래도 새면 답을 버리고 다시 받고, 두 번 다 새면 표에 적힌 둘러대기로 바꾼다.
→ 실제로 재 보니 **자백 누설 0건**.

**무고한 사람은 몰려도 살인을 자백하지 않는다.** 윤미래는 무너져도 보험 이야기만 털어놓는다 —
*"제가 왜 사람을 죽여요? 안 죽였어요."* 거짓 자백이 나오면 추리 게임이 망가진다.

## 6. 끝맺음 — 지목

| 판정 | 언제 | 무슨 일이 |
|---|---|---|
| **맞음** | 범인 + 알리바이를 깬 증거를 갖췄다 | 구속. 진실이 밝혀진다 |
| **모자람** | 범인은 맞는데 증거가 없다 | *"검사가 돌려보냈다. 이걸로는 못 넘깁니다."* 다시 취조실로 |
| **틀림** | 무고한 사람을 댔다 | **진범은 출국하고 사건은 미제로 남는다. 되돌릴 수 없다.** |

용의자가 셋이라 찍으면 3분의 1 이다. 그래서 **이름만으로는 안 선다.**

## 7. 사건과 사람 (사장님이 적은 표 그대로)

**사건**: 정우진(42세, 무역회사 대표) · 22:00 · 회사 사무실

| | 겉모습 | 숨긴 것 | 깨지는 자리 |
|---|---|---|---|
| **한선호** 동업자 | 정중하고 협조적. 눈가가 붉다 | **회사 자금을 빼돌렸다. 그가 범인이다** | 카페 CCTV · 기지국 기록 · 회사 장부 |
| **윤미래** 배우자 | 부은 눈. 신경질적 | 남편 몰래 상해 보험을 들었다 (**빚 때문** — 돈을 노린 게 아니다) | 보험 서류 |
| **박태수** 노숙 | 손이 떨린다. 눈을 못 마주친다 | **현장을 봤다.** 범인으로 몰릴까 봐 숨긴다 | 피 묻은 외투 |

윤미래는 **레드 헤링**이고, 박태수는 **목격자**다. 둘 다 무죄다.

## 8. 화면

- **온도계** — 세로 유리관이 차오르고 파랑→노랑→주황→빨강. **숫자는 안 보여 준다**(보이면 숫자를 보고 게임하게 된다)
- **얼굴** — 압박이 오르면 점점 붉고 거칠어진다. 화면 가장자리도 붉어진다
- **답이 한 글자씩 찍힌다** — 압박이 높을수록 느리게
- **증거는 서류철 카드** — 눌러서 고른 뒤 함께 묻는다
- **확인할 것** — 다른 사람에게 물어야 할 주장 목록. **답은 안 알려 준다**
- **방금 무슨 일이 있었나** — *"압박 +44 · 당황 +33 (경계 8 로 7% 깎임)"*. 이게 없으면 플레이어가 못 배운다

**진실은 화면으로 안 내려온다.** 개발자 도구를 열어도 범인이 누군지 안 보인다.

## 9. 어떻게 만들었나 — **수치는 코드, 대사는 AI**

```
플레이어 말(+증거)
      ↓
[코드] 모순 검증 · 교차 검증 · 수치 계산      ← **여기서 다 끝난다**
      ↓
[AI]  "이 수치에 맞는 사람처럼 말하기" 만      ← 모델이 하는 일은 이것뿐
      ↓
[코드] 누설 검사 — 자백이 샜으면 다시 받는다
      ↓
답
```

**왜 이렇게 했나**: 압박이 얼마나 올랐는지를 AI 가 정하면, 같은 증거를 들이대도
어떤 판은 무너지고 어떤 판은 안 무너진다. 그건 추리가 아니라 운이다.
(두근도트 친밀도에서 같은 구조가 먹혔다 — 점수는 규칙이 세고 AI 는 말투만 바꾼다.)

**파일**: `src/lib/lie/{case,stress,turn,verdict}.ts` · 화면 `src/app/lie/` · 길 `src/app/api/lie/`

## 10. 숫자표 (전부)

| 플레이어가 한 일 | 압박 | 당황 | 분노 | 경계 |
|---|---|---|---|---|
| 그냥 질문 | +2 | | | +1 |
| 날카로운 말 (거짓말·자백하라·범인) | +2~4 | | +5~10 | **+12** |
| 부드러운 말 (라포) | | | −10 | −8 |
| 같은 질문 반복 | | | +8 | +6 |
| **맞는 증거** | +(30+당황값÷2)×깎임 | +약점값×깎임 | | |
| **헛다리 증거** | **−5** | | | **+10** |
| 이미 깬 증거를 또 | +4 | | | |
| 교차 검증으로 증언 얻기 | | | | +5 |
| *턴마다 저절로* | −1 | ×0.55 | −2 | |

- **깎임** = max(0.15, 1 − 경계÷120) — 경계 60 이면 증거가 **절반만** 먹힌다
- **문턱** = 35 + 20×(필요한 약점 수)

## 12. 아직 없는 것 (정직하게)

- **세계관이 안 정해졌다.** 셋을 제안했고(`lie-world-proposal.md`) 로키에게 물었더니 **③ 2번 · ② 1번 으로 갈렸다.** 사장님이 고르실 몫.
- **증거 수집 단계**(기획 1단계: 현장 조사·부검)가 통째로 비어 있다. 지금은 증거 6개가 처음부터 다 있다.
- **용의자 C**(박태수)는 표에만 있고 **실제로 취조해 본 적이 없다.**
- **사건이 코드 안에 있다.** 표로 빼야 사건을 여러 개 넣는다.
- **저장이 없다.** 새로고침하면 처음부터다(상태를 화면이 들고 있다).
- 지금 `/lie` 는 **목(mock)** 으로 돌아 대사가 밍밍하다. 진짜 AI 로 보려면 `.env.local` 의 `AI_PROVIDER=mock` 을 지운다.
