# 취향 심판 v0 — 사람의 선택으로 심판을 짓는다 (사전 등록)

**상태: 사전 등록 완료(09:28) → 1회차 결과 기록(09:31, §7).**
등록 시점에는 어떤 선택도 보지 않았다.
2026-08-26 09:28 작성. 사장님 지시: *"인간한테 중간에 결과물을 주고, 인간이
선택하는 대로 심판자 구성."* 상속: `judge-bench-v1.2`.

이 문서는 **먼저** 판정식을 얼어붙이기 위한 것이다. 선택을 본 뒤에 기준을 만들면
그건 심판이 아니라 사후 설명이다(원칙 ①).

## 1. 무엇을 바꾸나

지금까지: `생성 → 기계 심판 → **기계가 첫 통과분 채택**`.
앞으로: `생성 → 기계 심판(하드 스펙) → **사람이 고름** → 그 선택으로 취향 문턱
유도 → holdout 통과 시에만 자동 심판으로 승격`.

기계는 **거를 뿐이고, 고르지 않는다**(`--defer-pick`). 사람이 고른 것은
`data/picks/*.json`에 남고, **고르지 않은 것도 같이 남는다** — 사람이 실제로
보고 안 고른 후보는 합성 변이보다 훨씬 좋은 반례다.

이게 동시에 세 구멍을 메운다:
1. 골든 positive의 순환(우리 심판이 통과시킨 것을 positive로 쓰던 문제).
2. 세트 문턱 미동결(근거가 될 표본이 없던 문제).
3. `art_mood_fit`처럼 "기계 심판 없음"으로 선언해 둔 칸.

## 2. 특징 목록 (동결 — 선택을 보기 전에 고정)

전부 SVG에서 결정적으로 재는 값이다. 모델 호출 0.

| # | 특징 | 정의 |
|---|---|---|
| f1 | `path_count` | `<path>` 개수 |
| f2 | `shape_count` | path·circle·rect·line·polyline 총합 |
| f3 | `command_count` | 경로 명령 총수 |
| f4 | `bytes` | 파일 크기 |
| f5 | `min_padding` | 가장자리 최소 여백(볼록껍질) |
| f6 | `bbox_fill_ratio` | 도형 bbox 면적 / viewBox 면적 |
| f7 | `curve_ratio` | 곡선 명령(C·S·Q·T·A) / 전체 명령 |
| f8 | `symmetry_x` | 좌우 반전 후 좌표 집합 일치율 |
| f9 | `distinct_elements` | 서로 다른 요소 종류 수 |
| f10 | `ink_length` | 경로 꼭짓점 간 거리 합(획 길이 근사) |

**여기 없는 것은 이번 판에서 쓰지 않는다.** 선택을 본 뒤 특징을 추가하면
그것이 곧 과적합이다.

## 3. 판정식 (동결)

- **규칙 꼴은 단일 특징 문턱 하나뿐이다**: `f_k >= t` 또는 `f_k <= t`.
  조합·가중합·학습 모델 금지 (P30 합산 금지 규율의 연장).
- 문턱 후보는 훈련 분할에서 관측된 값들의 중간점만 쓴다.
- 선택 기준: 훈련 분할에서 **채택본을 고르고 비채택본을 떨어뜨리는 정확도**가
  가장 높은 규칙 하나. 동률이면 특징 번호가 작은 것(f1 우선), 그래도 동률이면
  문턱이 작은 것 — 무작위성 없이 결정적으로.
- **분할은 개념 단위(leave-one-concept-out)**다. 같은 개념의 후보가 훈련과
  시험에 나뉘어 들어가면 새는 것이다.
- 평가 지표: LOCO **top-1 적중률** = 남겨둔 개념에서 규칙이 최고점으로 뽑은
  후보가 실제 채택본인 비율. (동점 후보가 여럿이면 그 개념은 실패로 센다 —
  후하게 세지 않는다.)

## 4. 수용 기준 (동결) — 미달이면 승격 없음

| 관문 | 기준 |
|---|---|
| 표본 | 개념 ≥ **8**, 채점된 후보 ≥ **40**, 개념당 후보 ≥ 3 |
| 성능 | LOCO top-1 적중률 ≥ **0.75** |
| 우연 배제 | 라벨 순열 검정 200회에서 p < **0.05** |
| 무의미 배제 | 무작위 선택 기준선(개념당 1/후보수 평균)보다 높을 것 |

넷을 **전부** 통과하면 `taste_fit_icon`을 `real` 원자로 승격한다(반례 = 그
개념에서 실제로 안 고른 후보들). 하나라도 미달이면 **`human_gate` 유지** —
"취향은 아직 기계 심판이 없다"를 그대로 선언한다. 미달을 보고 기준을 낮추는 것은
재등록 절차 없이는 금지다.

## 5. 지금 표본으로는 승격이 불가능하다 (미리 적는다)

오늘 만든 선별 세션 `pick-v1`은 **개념 4개 / 후보 21개**다. §4의 표본 관문
(개념 ≥ 8)에 미달이므로, 사장님이 고르시더라도 **이번 회차는 예비 측정이고
승격은 없다.** 숫자는 기록하되 "미달"로 표기한다. 승격하려면 개념 4개짜리
세션을 최소 한 번 더 돌려야 한다(약 $0.025).

## 6. 하지 않는 것

- 선택을 본 뒤 특징·규칙 꼴·문턱·수용 기준을 바꾸는 것.
- 채택본만 저장하고 비채택본을 버리는 것(그러면 반례가 사라진다).
- 취향 규칙을 하드 스펙에 섞는 것 — 하드 스펙은 사장님이 정한 설계도이고,
  취향 문턱은 사장님의 **선택에서 유도된 추정**이다. 두 층을 섞지 않는다.
- 사람이 고른 이유를 모델에게 묻고 그걸 근거로 쓰는 것(그건 `observed.*`이고
  별도 null 통제가 필요하다).

## 7. 1회차 결과 (2026-08-26 09:31) — **NO-PROMOTE**

선별 `data/picks/pick-v1.json` (사장님, 09:30): 개념 4 / 보여준 후보 21 /
고른 것 4 / 안 고른 것 17. 결과 `data/picks/pick-v1.taste.json`.

| 관문 | 값 | 기준 | 결과 |
|---|---|---|---|
| 표본 | 개념 4, 후보 21 | 개념≥8, 후보≥40 | **미달** |
| LOCO top-1 적중률 | **0.25** (4개념 중 1) | ≥0.75 | **미달** |
| 순열 검정 | p = **0.323** (200회) | <0.05 | **미달** |
| 무작위 기준선 | 0.211 | 적중률이 이보다 높을 것 | OK(0.25 > 0.211) |

**판정: 승격 없음. `human_gate` 유지 — 취향은 아직 기계 심판이 없다.**

절차가 훈련 분할에서 고른 규칙은 매번 `command_count >= 11.5` 계열이었다
(훈련 정확도 0.79~0.89). 그런데 남겨둔 개념에서는 4번 중 1번만 맞혔다.
훈련에서 높고 시험에서 무너지는 것은 **과적합의 표준 그림**이고, 순열 검정
p=0.32는 "이 정도는 라벨을 섞어도 나온다"는 뜻이다.

정직하게: 이 결과는 "사장님 취향에 규칙이 없다"는 뜻이 **아니다**. 개념 4개는
LOCO 분모가 4라서 적중률이 0.25 단위로만 움직인다 — 표본이 관문에 한참 못
미친다. §5에 미리 적어둔 대로 이번 회차는 **예비 측정**이다.

다음 회차 조건(바꾸지 않는다): 개념 8개 이상 세션을 한 번 더 돌려
누적 개념 ≥8, 후보 ≥40을 채운 뒤 같은 절차를 그대로 재실행한다.

## 8. 2회차 결과 (2026-08-26 16:5x) — **NO-PROMOTE**, 그리고 이유가 우리 쪽이다

선별 `data/picks/pick-v2.json`(사장님, 16:4x): 8자리 중 **7자리 선택, 1자리 보류**
(`05_equipment`). 고른 것 7 / 반례 36 / 미판정 5 / 보여준 것 48.
누적 표본 = pick-v1(개념 4) + pick-v2(개념 7) → **개념 11 / 후보 64.**
§5에 적어둔 "다음 회차 조건"(누적 개념 ≥8, 후보 ≥40)을 **처음으로 채웠다.**

| 관문 | 값 | 기준 | 결과 |
|---|---|---|---|
| 표본 | 개념 11, 후보 64 | 개념≥8, 후보≥40 | **처음으로 OK** |
| LOCO top-1 적중률 | **0.0** (11개념 중 0) | ≥0.75 | 미달 |
| 순열 검정 | p = **1.0** | <0.05 | 미달 |
| 무작위 기준선 | 0.1805 | 적중률이 이보다 높을 것 | 미달 |

1회차는 0.25였는데 2회차가 0.0이다. 표본을 세 배로 늘렸더니 더 나빠졌다.
그래서 **왜 그런지를 먼저 재봤다**(진단 원자료 `data/picks/taste-v2-diagnosis.json`).

### 진단 — 훈련 목적함수가 퇴화했다

| 폴드 | 훈련 정확도 | 규칙이 훈련에서 통과시킨 후보 | "전부 거절"이 얻는 점수 |
|---|---|---|---|
| 11개 전부 | 0.810 ~ 0.845 | **0~4 / 58** | 0.825 ~ 0.836 |

**훈련 정확도가 '전부 거절' 점수와 사실상 같다.** 당연하다 — 한 자리에 채택본은
1개, 비채택본은 5~6개다. 채택본을 하나도 못 맞혀도 **전부 거절하면 0.83**이 된다.
11개 폴드 중 **5개는 규칙이 훈련에서 아무것도 통과시키지 않았다.**

더 나쁜 사실 하나: 우리 점수는 `값 − 문턱`(또는 그 반대)이라 **문턱은 순위를
바꾸지 못한다.** 같은 특징·같은 방향이면 문턱이 무엇이든 top-1은 동일하다.
즉 훈련이 고르는 것은 사실상 **특징과 방향뿐인데**, 그 선택을 퇴화한 목적함수가
하고 있었다. 채택본의 순위는 중앙값 **5위/6후보** — 무작위보다 체계적으로 나쁘다.

### 그래서 무엇이 결론인가

- **판정은 NO-PROMOTE로 확정.** `human_gate` 유지. 관문을 낮추지 않는다.
- 그러나 이 결과는 *"사장님 취향에 규칙이 없다"* 는 뜻이 **아니다.** 우리가 얼린
  훈련 목적함수(불균형 분류 정확도)가 **고르기를 표현하지 못한다**는 뜻이다.
  1회차의 0.25도 이제는 운으로 봐야 한다.
- **절차를 지금 바꾸지 않았다.** 결과를 본 뒤 목적함수를 바꾸는 것은 원칙 ①
  위반이다. 바꾸려면 재등록이 먼저다.

### 재등록 후보 (사장님 결정 — 값이 아니라 **절차**의 변경)

같은 특징 10개·같은 규칙 꼴을 두고, **훈련에서 고르는 기준만** 바꾼다:
"채택/비채택 분류 정확도" → **"훈련 분할의 top-1 적중률"**. 재는 것과 훈련하는
것을 같은 자로 맞추는 것이고, 새 특징도 새 문턱도 도입하지 않는다.

재등록 전에 그 결과를 미리 계산해 보지 않았다 — **먼저 계산하고 나중에 등록하면
그게 사후 기준**이다. 승인하시면 등록 문서를 먼저 커밋하고 그 다음에 돌린다.
