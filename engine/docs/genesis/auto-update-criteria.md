# 자동 업데이트 v1 — **되면 된 것** (짓기 **전에** 잠금, 2026-09-22)

사장님이 범위와 문을 정하셨다. **㉮(새 모델·도구가 나오면 알아서 갈아탄다)만 한다.**

## 범위 — **모델 교체만**

| | |
|---|---|
| **한다** | 새 모델 찾기 · 옛 모델과 새 모델을 **같은 과제로 나란히 돌려 견주기** |
| **안 한다** | **코드 자동 배포**(㉯). 지금도 배포는 사람이 한다 |

**㉯ 를 왜 빼는가**: 스스로 배포하면 **로키가 자기를 망가뜨려도 아무도 안 막는다.**
09-22 아침에 배포를 안 해서 새 칸이 안 찍힌 일이 있었는데, 반대였다면 **틀린 것이 그대로 돌았을 것**이다.
되돌리기와 사람 문을 먼저 만들고 그다음이다.

## 기계가 하는 것 / 사람이 하는 것

| | 누가 |
|---|---|
| 새 모델 찾기 (**눈이 보는 곳을 넓히는 것 포함**) | 기계 |
| 정해진 과제로 **옛 모델 vs 새 모델** 나란히 돌리기 | 기계 |
| **갈아타기** | **사장님 탭 한 번. 탭 없이는 절대 안 바꾼다** |
| 갈아탄 뒤 숫자가 나빠지면 **되돌리기** | 기계 (자동) |

**"탭 없이는 절대 안 바꾼다" 가 이 판의 난간이다.** 기계가 아무리 좋다고 해도 혼자 못 바꾼다.

## 되돌리기 — **"나빠짐" 을 지금 적는다**

되돌리는 기준을 나중에 정하면, 나빠진 걸 보고 나서 기준을 고르게 된다(09-21·09-22 에 겪은 그것).

> **갈아탄 뒤 첫 10판에서, 아래 중 하나라도면 자동으로 옛 모델로 되돌린다.**
>
> 1. **통과율**이 옛 모델의 10판보다 **낮다**
> 2. **판당 값**이 옛 모델의 10판보다 **1.5배를 넘는다**
> 3. **기계 고장**(형식 어긋남·잘림·저장 실패)이 옛 모델보다 **많다**
>
> 되돌린 뒤에는 **사장님 탭 없이 다시 안 갈아탄다.**

*(10판·1.5배는 내가 고른 값이다. 사장님이 바꾸실 수 있다 — 바꾸시면 **짓기 전에** 바꾼다.)*

## 되면 된 것

| | 조건 | 어떻게 재나 |
|---|---|---|
| 1 | **새 모델을 스스로 찾는다** | 눈이 보는 목록에 없던 모델이 하나라도 올라온다 |
| 2 | **나란히 돌린 결과가 숫자로 남는다** | 같은 과제 · 같은 판 수 · 통과율/값/고장 세 칸 |
| 3 | **탭 없이는 안 바뀐다** | 시험: 기계가 "갈아타자" 고 해도 설정이 그대로다 |
| 4 | **나빠지면 되돌아간다** | 시험: 가짜로 나쁜 10판을 먹여 되돌아가는지 본다 |
| 5 | 사장님이 **무엇을 보고 탭 하는지 안다** | 사람 칸. 화면에 근거가 보이나 |

**1~4 는 기계가 잰다. 5 는 사람이 본다.**
잠그기 전에 **가짜 기록으로 3·4 를 끝까지 판정해 보고** 값이 나오는지 확인한다(09-21 규칙).

## 판 8 이 도는 동안은 **그 판이 쓰는 모델을 안 바꾼다** (사장님)

> *"판 도중에 조건이 바뀌면 그 판이 무엇을 쟀는지 흐려진다."*

판 5→6 에서 바퀴 수 하나만 바꿔 원인을 갈랐던 것과 같은 규율이다.
**판이 닫힌 뒤에 갈아탄다.** 이 문장도 v1 에 넣어 기계가 지키게 한다.
