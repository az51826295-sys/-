# 도구 꽂기 v1 — **되면 된 것** (초안, 잠그기 전)

사장님 09-22: **"다 가능하게 하고 ㉠ 먼저."**
그래서 ㉠(로키가 도구를 꽂아 쓴다)부터 하되, **㉡·㉢ 이 나중에 같은 규격 위에 올라가게** 짓는다.

| | 나중에 어떻게 되나 |
|---|---|
| ㉠ 로키가 도구를 골라 쓴다 | **지금 만드는 것** |
| ㉡ 로키를 도구로 내놓는다 | 같은 설명서를 **밖으로** 내보내면 된다 |
| ㉢ 직원·기술을 꽂고 빼게 | 같은 규격의 **다른 종류**가 된다 |

## 첫 조각은 **자(재는 도구)** 다

오늘(4단계) 로키가 자를 제안할 때 **있는 칸 중에서만** 골랐다. 착지 여유 칸이 없어 판 6 의 고장을 못 봤고,
그 칸은 내가 코드를 써서 만들었다. **로키에게 모자랐던 것은 바깥 도구가 아니라 재는 도구였다.**
그래서 첫 손님은 오늘 만든 자 아홉 개다. 바깥 서버·인증·네트워크 없이 우리 안에서 끝난다.

## 되면 된 것 (전부 만족해야 한다)

| | 조건 | 어떻게 재나 |
|---|---|---|
| 1 | **자가 목록으로 읽힌다** | 코드 안에 박힌 것이 아니라 등록된 설명서로. 로키가 받는 목록과 실제 도는 자가 **같은 곳에서 나온다** |
| 2 | **새 자를 꽂을 때 한 곳만 건드린다** | 자 하나를 더해도 `run.ts`·`loop.ts`·주문 도구를 안 고친다. 시험: 가짜 자 하나를 꽂아 본다 |
| 3 | **못 잴 때 '통과' 가 아니라 '못 잼'** | 오늘 규칙 그대로. 시험: 못 재는 판을 넣으면 난간이 '못 잼' 으로 걸린다 |
| 4 | **권한이 자마다 적혀 있고, 적힌 것 밖은 못 본다** | **선언만으로는 안 된다 — 기계가 막아야 한다.** 시험: 권한 없는 자가 몰래 보려 하면 막힌다 |
| 5 | **모자란 자를 이름과 함께 말한다** | 로키가 *"이 말을 담으려면 무엇을 재야 하는데 그 자가 없다"* 고 낼 수 있다 |

**1~4 는 기계가 잰다. 5 는 사람이 본다** — 로키가 낸 말이 쓸모 있는지는 사장님 칸이다.

## 이것이 **아닌** 것

- **"도구를 꽂았다" 와 "도구를 잘 골랐다" 는 다르다**(09-22 아침에 적어 둔 것). v1 은 **앞만** 한다.
- 바깥 MCP 서버에 붙는 것이 아니다. 규격을 우리 안에 세우는 것까지다.
- 로키가 **자를 코드로 새로 짓는 것**이 아니다. 그건 다음 조각이다.
