# 무인 운영 — 주말 맡기기 (200회차 시작, 2026-09-20)

> 사장님: ㉠ 찬성. **"사장님 시간이 제일 귀한 자원"** · 수능까지 두 달.
> 목표 한 줄: **금요일 밤에 맡기고 일요일 밤에 본다.**

지금 로키의 고리는 **몇 분**이다 — 사장님이 보고 있을 때만 일이 진행된다. 이걸 며칠로 늘리는 판.

## 사장님이 건 제약 셋 (09-20)

### 1. 48시간 판은 `agent-days` 칸의 실측이 **아니다**
잠긴 조건은 **72시간**이다(`rules/20260920-baseline-and-conditions.json`). 48시간 판은 **신뢰성 연습**으로만 센다.
나중에 "48시간이면 사실상 열림" 으로 고치면 **오늘 막은 사후 기준을 스스로 여는 것**이다.
→ 판 기록마다 `칸 실측 아님: true` 를 **미리** 적는다. 72시간 판에서만 `칸 실측` 으로 올린다.

### 2. 이 판은 **사람 판정 병목을 키운다** — 그래서 상한을 둔다
48시간 동안 산출물이 쌓이면 일요일 밤 2~3시간이 **검토에 다 들어간다**. 지금도 결과물 200개 중 판정된 건 35개다.
그러면 시간을 아끼려던 일이 시간을 먹는다(사장님).
→ **"검증된 산출물" 은 심판이 기계로 판정한 것만 센다.**
→ **사장님이 봐야 할 산출물은 한 판에 최대 3개.** 넘으면 로키가 스스로 멈추고 기다린다.

### 3. 한 판에 **한 가지만** 바꾼다
"안 죽고 버티기" 와 "할 일을 스스로 잇기" 를 같이 시험하면 실패했을 때 **어느 쪽인지 못 가른다**(사장님).
→ 1판: **미리 채운 과제 대기열**로 신뢰성만. 스스로 잇기는 **그다음 판**.

## 예산 문지기 — 로키 **바깥**에 둔다

로키가 자기 지출을 세면 **로키가 죽거나 꼬일 때 문지기도 같이 죽는다**(사장님).
- 세고 정하는 것은 **바깥 프로세스**(사장님 PC). 로키는 **깃발에 복종만** 한다.
- 상한은 **하루 단위로 쪼갠다** — 한 번에 다 태우지 못하게.
- **같은 실패가 N번 연속이면 정지** — 소켓 고갈 같은 고장에 돈을 태우며 도는 것을 막는다.
- 무인 판 동안 **바깥으로 나가는 행동 금지**: PR·push·배포. (지금 워커는 PR 을 안 하지만, **내가 배포하지 않는 것**이 이 규칙의 실제 내용이다.)

## 순서 (사장님이 정한 대로)

1. **예산 문지기(바깥)** ← 여기부터
2. **미리 채운 과제 대기열**
3. **6시간 판** — 신뢰성만
4. **48시간 판** — 신뢰성만 (칸 실측 아님)
5. **72시간 판** — `agent-days` 칸의 **우리 쪽 실측**(`길잡이`, 예측력 아님)

## 옛 게이트에서 가져온 규율
- **개입하면 그 회차는 끝난다.** 도는 중에 설정·코드·프롬프트를 바꾸지 않는다.
- 계측이 틀린 걸 발견해도 **끄지 않는다** — 끝까지 돌리고 그 회차를 무효로 기록하고 새 회차를 등록한다.
- 중단은 사장님 말에만. 예산 상한에 걸려 스스로 멈추는 것은 중단이 아니다(안전장치가 일한 것).
