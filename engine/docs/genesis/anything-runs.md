## 4. 재는 자를 예측자로 (사장님 09-25 05:2x "재는 자를 예측자로 강화시켜줘")

해석: **재기 전에 로키가 값을 예측해 잠그고, 잰 값과 대 본다.** 맞아 가면 코드를 읽고 결과를 아는 것, 아니면 감으로 고치는 것 — "똑똑한가" 의 자.
- `predictMeasures.ts`: 고치는 자리가 바퀴마다 난간 칸의 값·통과확률·근거를 낸다 → 실행 행 `metrics_json.predictions` 에 **재기 전에** 적음(잠금 v1, 트리거 없음) → 잰 뒤 Brier·칸별 |오차| 채점을 덧붙임. 고리 기록(`rounds[].예측`)에도 실림. 예측 실패는 고리를 막지 않는다.
- `predict_score` 자: 최근 N일 채점된 예측의 Brier 평균·칸별 오차 평균 + **머리 견적**("약 $X · Y분") vs 실제.
- 시험 `predict_probe` 7/7(가짜 AI). **첫 실측**(loop_probe, 4회차 파일, luna): 통과확률 0.97 → 통과(brier 0.001), 높이 예측 오차 **1.8px**(100.2 실측), 착지여유 오차 3, 나머지 0 — 코드를 읽고 셈했다.
- 첫 시도는 `maxTokens 1500` 이 luna 생각 토큰에 잘렸다(TRUNCATED) → 6000.
- 머리 견적 14일 118건: **값 오차 평균 $0.075 · 시간 오차 평균 10.4분**(시간은 대기열 기다림이 섞인 값).
- 서버 반영: c704075 → 869985e 배포. 다음 웹 고리부터 쌓인다.
