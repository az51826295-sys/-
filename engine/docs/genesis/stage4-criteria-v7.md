# 4단계 본판 기준 — **개정판 7** (판 3 을 열기 **전에** 잠금, 2026-09-22)

앞 여섯 판은 그대로 둔다. 판 1(무효)과 판 2(실패)는 개정판 6 으로 판정했고 **소급해서 바꾸지 않는다.**

## ⑪ **결과물 0 개인 기계 고장은 회차를 다시 도는 것이 아니다**

판 2 의 1회차에서 첫 시도가 이렇게 죽었다:

```
MODEL_OUTPUT_OFF_SCHEMA: edits.2.why: Invalid input: expected string, received undefined
```

파일은 손도 안 댔고 **결과물이 0 개**였다. 나는 이걸 "다시 한 회차" 로 안 세고 다시 주문했다.
경계는 뜻에 맞았지만 **판 도중에 내가 정한 규칙**이었다(사장님 09-22).
그래서 다음 판을 열기 전에 잠근다 — 다음에 같은 일이 생겼을 때 그 자리에서 고르지 않도록.

### 정한 것

> **결과물이 0 개이면 그 시도는 회차가 아니다.** 같은 회차를 아직 못 돈 것이고, 다시 주문해도 무효가 아니다.
> **결과물이 1 개라도 나왔으면** 그것은 회차다. 다시 하면 규칙 ① 대로 **판 전체가 무효**다.

가르는 자리는 **결과물의 유무 하나**다. "고장이 기계적인가" 로 가르지 않는다 —
그건 볼 때마다 다르게 읽히고, 결국 안 된 회차를 기계 고장이라 부르는 길이 열린다.

**대신 시도를 전부 적는다.** 결과물 0 인 시도도 장부에 남는다(무슨 고장이었는지까지).
지우지 않는 것이 규칙 ① 을 지키는 방법이다.

| | 결과물 | 다시 주문하면 |
|---|---|---|
| 형식 어긋남·잘림·저장 실패로 죽음 | 0 개 | 회차 아님 → **무효 아님** |
| 결과가 나왔는데 나쁨 | 1 개 이상 | 회차임 → **판 전체 무효** |

*(엔진이 이 고장을 스스로 다시 안 하고 일을 취소했다. "형식 고장은 조용히 한 번 다시" 는 이미 있는 규칙인데
이 길에는 안 걸려 있다. **기록만 하고 안 고친다** — 사장님 09-22.)*

## ⑫ **자를 만드는 일은 판 바깥이다**

판 3 을 열기 전에 **점프를 숫자로 재는 자를 고리 안에 심는다**(사장님이 ㉮를 고르심).
그 엔진 작업은 **로키의 기능**이지 이 게임의 고침이 아니다. 그러므로:

> **엔진·자 코드는 회차의 diff 에 안 들어간다.** 회차 비율의 분자는 **게임 파일**만이다.

판 2 까지도 그랬다(자는 `engine/tools/` 에 있었다). 판 3 부터는 자가 `src/` 로 들어가므로
헷갈리기 쉬워 여기 적어 둔다.

## 나머지는 1~6 판 그대로

연속된 다섯 번 · 회차와 누적 모두 절반 미만(분모는 원본의 두 배) · 되던 것 = 처음부터 클리어까지 한 번 ·
2·3번은 사람 칸 · 요청 원문을 회차마다 · 못 잼 회차가 있는 판은 통과 불가 ·
연 판을 전부 "N판 중 M판 통과" 로 · 원본 = 판을 여는 시점의 파일.
