## 1. 무엇을 재는가 (그리고 무엇을 안 재는가)

재는 것: 사장님이 **같은 자리에 놓인 후보들 중** 고른 것과 안 고른 것을,
PNG에서 결정적으로 잰 값 하나가 가르는가.

안 재는 것: 그림이 좋은가. 그건 심판이 없다(`art_mood_fit`과 같은 자리).
하드 스펙(`pixel-sprite-v1.yaml` 반입 오라클)과도 섞지 않는다 — 하드 스펙은
사장님이 동결한 규격이고, 취향 문턱은 **선택에서 유도된 추정**이다.

## 2. 특징 목록 (동결 — 선택을 보기 전에 고정)

전부 Pillow만으로 재는 결정적 값이다. **모델 호출 0.**

**정규화(동결)**: 논리 격자로 먼저 내린 뒤 잰다. 파일이 논리 크기의 정수배
(예: 16×16을 512×512로 확대)면 블록 최빈색으로 나눠 내린다(nearest). 정수배가
아니면 **측정하지 않는다**(그 후보는 `undefined`, fail 아님). 확대본과 원본이
다른 값을 내면 특징이 파일 저장 방식을 재는 셈이라 그걸 막는다.
투명 픽셀은 i2를 빼고 모든 통계에서 제외한다.

| # | 특징 | 정의 |
|---|---|---|
| i1 | `color_count` | 불투명 픽셀의 서로 다른 RGB 수 |
| i2 | `opaque_ratio` | 불투명 픽셀 / 전체 픽셀 |
| i3 | `bbox_fill_ratio` | 불투명 bbox 면적 / 캔버스 면적 |
| i4 | `mean_saturation` | HSV S 평균(0~1) |
| i5 | `mean_value` | HSV V 평균(0~1) |
| i6 | `value_spread` | V의 p90 − p10 (명암 폭) |
| i7 | `edge_density` | 이웃한 불투명 쌍 중 RGB 맨해튼 거리 > 30 인 비율 |
| i8 | `symmetry_x` | bbox를 좌우 반전했을 때 같은 픽셀 비율 |
| i9 | `dominant_color_share` | 최빈 색 픽셀 / 불투명 픽셀 |
| i10 | `outline_ratio` | 투명(또는 캔버스 밖)과 맞닿은 불투명 픽셀 / 불투명 픽셀 |

**여기 없는 것은 이번 판에서 쓰지 않는다.** 30은 i7에만 쓰는 고정 상수이고
지금 정한다 — 결과를 보고 옮기지 않는다.

## 3. 판정식 (동결) — 다중 선택을 재는 법

규칙 꼴은 형제 문서와 같다: **단일 특징 문턱 하나**(`i_k >= t` 또는 `i_k <= t`),
조합·가중합·학습 모델 금지. 문턱 후보는 훈련 분할 관측값의 중간점만.

**다른 점은 지표다.** 다중 선택에서는 "최고점 하나가 채택본인가"(top-1)를 물을
수 없다. 대신 **쌍 비교**를 쓴다:

- 한 그룹에서 (채택본 a, 비채택본 b) 모든 쌍을 만든다.
- 규칙이 a를 b보다 높게 놓으면 그 쌍은 적중. **동점은 실패로 센다**(후하게 세지
  않는다 — 형제 문서 §3의 동점 규율과 같다).
- 적중률 = 적중 쌍 / 유효 쌍. 무작위 기준선은 **0.5**다.
- 분할은 그대로 **개념(그룹) 단위 LOCO**. 규칙 선택도 훈련 분할의 쌍 적중률로.

**유효 쌍이 0인 그룹**(전부 채택 / 전부 비채택)은 훈련·시험 **양쪽에서 뺀다.**
빼되 결과표에 개수를 적는다 — 조용히 버리면 표본이 부풀어 보인다.
`undecided_items`(애초에 고르는 자리가 아니었던 참고용)는 **후보로 세지 않는다**
(08-26 기록 버그 수정과 같은 이유: 거절과 미판정을 섞으면 반례가 거짓말이 된다).

## 4. 수용 기준 (동결) — 미달이면 승격 없음

| 관문 | 기준 |
|---|---|
| 표본 | 유효 그룹 ≥ **8**, 채점된 후보 ≥ **40**, 유효 쌍 ≥ **60** |
| 성능 | LOCO 쌍 적중률 ≥ **0.75** |
| 우연 배제 | 순열 검정 200회(그룹 안에서 채택 라벨만 섞음) p < **0.05** |
| 무의미 배제 | 0.5 초과 |

넷을 **전부** 통과하면 `taste_fit_image`를 `real` 원자로 승격한다(반례 = 그
그룹에서 실제로 안 고른 후보). 하나라도 미달이면 **`human_gate` 유지**.
미달을 보고 기준을 낮추는 것은 재등록 없이는 금지.

## 5. 지금 표본으로는 승격이 불가능하다 (미리 적는다)

`data/picks/pixellab-v1.json`: 그룹 4개 중 **유효 그룹은 1개**(01_cat: 채택 2 /
비채택 3 → 유효 쌍 6). 02_tileset은 전부 채택이라 0쌍, merchant·icon은 미판정.
§4의 표본 관문에 한참 미달이므로 이번 회차는 **예비 측정도 아니고 NOT-MEASURED**
이며, 그대로 표기한다. 승격하려면 유효 그룹 8개짜리 세션이 필요하다
(계획서 S3: 타일 자리별 8자리, 약 $0.19 — 사장님 승인 사항).

## 6. 하지 않는 것

형제 문서 §6에 더해:
- 확대본을 그대로 재는 것(§2 정규화 위반 → `undefined`).
- 하드 스펙에서 이미 떨어진 후보를 취향 표본에 넣는 것 — 취향은 **통과분 안에서**
  갈리는 것이고, 규격 미달을 취향으로 설명하면 두 층이 섞인다.
- `pixelize` 같은 후처리본과 원본을 같은 표본에 섞는 것(raw_verdict 분리 규율).
