## 1. 사전 등록 — 숫자 보기 전에 박는다
**가설 H**: 자기 저장소에 결정권이 있는 사람은 "이슈를 재현하는 실패 테스트"에
지불 의사가 있다.
**표본**: 5건. 적격 = 저장소 결정권 또는 예산 권한 보유. 둘 다 없으면 표본 제외.
**1차 지표**: 가격을 꺼낸 뒤 상대가 **되묻는** 건수 (`engaged`)
- 되묻기 = "얼마인데", "어떻게 붙이는데", "우리 저장소도 되나"
- 예의 반응("좋네요", "재밌네요")은 0점
**2차 지표**: 파일럿 수락 수 / 거절 사유(가격·신뢰·필요없음·절차)

**판정 규칙 (동결, 09-05까지 수정 금지)**

| 결과 | 판정 | 다음 |
|---|---|---|
| engaged ≥ 3 | 수요 존재 | A(수리 구독) 파일럿 개시 |
| engaged 1–2 | **미정의** | 표본 5건 추가. 기준 변경 금지 |
| engaged 0 | 수요 미발견 | 확장이 아니라 도메인 재선택 |

**모서리 사전 처리**
- "무료면 써보겠다" → engaged 아님 (0점)
- "회사 절차상 내가 못 정한다" → 거절 아님. **부적격**으로 제외, 새 1건 충원
- 상대가 ②·③를 **먼저** 언급 → 받아 적되 `spontaneous_demand`로 별도 기록.
  engaged 점수에는 포함
- 5건 못 채움 → 채운 만큼으로 판정 금지, **미정의**

## 4. 통화 15분 골격
**0–5분 · 문제 채취 (여기가 본론)**
> "지난달에 저장소에서 뭐 때문에 제일 시간 썼습니까?"
> "그 중에 '이게 진짜 버그인지부터 확인하느라' 쓴 시간은 얼마나 됩니까?"
- 상대가 말한 문제를 **그대로** 받아 적는다. 우리 능력 목록으로 유도 금지.
- 이 5분이 확장 순서를 정하는 유일한 입력이다.

**5–10분 · 물건 보여주기**
- 실제 PR 하나(toolz #496 등)를 화면으로. 슬라이드 금지.
- 말할 것 3개: ①재현 명령 한 줄 ②실패→통과 테스트 ③감사 로그 링크
- 말하지 말 것: 재현율 숫자. **방어 가능한 단일값이 없다.** "몇 %냐" 오면 →
  *"저장소마다 달라서 단일 숫자를 못 드립니다. 대신 귀사 저장소 10건으로 무료로
  측정해서 그 숫자를 드리겠습니다."* (이게 파일럿 제안이 된다)

**10–15분 · 가격 꺼내기 (반드시 꺼낸다)**
> "해결 1건당 5만원이면 쓰시겠습니까?"
- 숫자를 먼저 던진다. "얼마면 쓰시겠어요?"는 측정이 안 된다.
- 상대 반응만 기록. **설득하면 그 표본은 버려진다.**
