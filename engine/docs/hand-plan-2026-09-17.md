# 로키 손 — 기계를 판단하고 환경을 조성한다 (2026-09-17, 159회차)

사장님: **"일단 말할 게 있는데 가장 중요한 거야. 로키가 노트북이나 폰의 사양을 판단하고 환경을 조성할 수 있어야 돼."**
그리고: **"로키가 godot 엔진이나 유니티나 언리얼 엔진을 설치할 수 있어야 해, 노트북을 조종해서."**

되짚어 확인한 뜻(사장님 "맞아 그거야"): 결과물을 주는 걸로 끝나면 안 되고, **그게 돌아갈 기계를 로키가 스스로 알아내고 거기에 맞게 차려 줘야 한다** — 사람 손이 안 가게. 그리고 이건 표가 아니라 **판단**이어야 한다.

## 2. 모양 — 손·눈·판단, 셋으로 갈린다

```
[노트북]  rookery-hand.ps1  ── 잰다(사양·깔린 것) ──▶  /api/hand/spec  ──▶  저장
                 ▲                                                        │
                 │ 한다(깔기·설정·실행)                                     ▼
                 └────────── /api/hand/tasks ◀── 로키가 판단 ◀── 사장님이 대화에서 누름
```

- **눈(v0, 오늘)**: 손이 기계를 **잰다.** 아무것도 안 바꾼다. 관리자 필요 없음. 잰 것을 로키에 보낸다.
- **판단(v0, 오늘)**: 로키가 잰 값과 **하려는 일**을 보고 자기 말로 답한다 — *"이 기계로 이 일이 되겠나, 뭐가 필요한가, 뭐가 위험한가."* 칸 없이. 잰 값은 기계가 대고 판단은 AI 가 한다(어제 하루의 원칙 그대로).
- **손(v1, 다음)**: 판단이 낸 "필요한 것" 옆에 단추. **사장님이 누르면** 손이 한다 — 내려받기·풀기·사용자 폴더에 깔기·설정·실행. 자동으로 잇지 않는다(문이 된다).

## 3. 엔진마다 다르다 (사실)

| 엔진 | 관리자 없이 되나 | 어떻게 |
|---|---|---|
| **Godot** | ○ 제일 쉽다 | 공식 zip 한 개, 풀면 끝. 설치기 자체가 없다 |
| **Unity** | ○ 09-02 에 해 봤다 | 공개 API 가 설치본 주소를 준다 → `~\UnityEditors` 에 `RunAsInvoker` 로 |
| **Unreal** | △ | Epic 런처가 **Epic 계정 로그인**을 요구한다. 계정·로그인은 사장님 몫이라 손이 대신 못 한다. 런처 뒤의 설치는 가능 |

순서는 **Godot → Unity → Unreal**. 사장님 게임이 Godot 이기도 하다.

## 4. 판단이 하는 것 / 자가 하는 것

- **판단**: 이 사양에 이 일이 되겠나 · 뭘 깔아야 하나 · 어떤 판(버전)을 고를까 · 설정을 어느 쪽으로(가볍게/무겁게) · 위험은 뭔가.
- **난간(자)**: 사용자 폴더 밖에 안 쓴다 · 승격을 안 요구한다 · 디스크가 모자라면 안 깐다(깨지는 것) · 사장님이 누르지 않은 것은 안 한다.
- **안 하는 것**: "램 8GB 미만이면 저사양" 같은 표를 박지 않는다. 그건 어제 하루 종일 걷어낸 상수다.

## 5. 정직하게

- 폰은 아직 아니다. 안드로이드 앱(TWA) 안에서는 사양을 잴 길이 브라우저 API 로 좁다. 노트북부터.
- 손을 처음 붙이는 한 번(스크립트 실행)은 사장님 손이다. 그 뒤로는 손이 로키를 본다.
- 첫 판에 내 실수 둘: 매개변수 이름을 `$args` 로 지어 `node --version` 이 REPL 로 서 버렸고, 없는 경로에 `-Recurse` 를 줘 PS 5.1 이 100초 넘게 섰다. 둘 다 잡았다(10초).
