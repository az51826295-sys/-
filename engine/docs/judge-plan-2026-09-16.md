# 심판자를 뭘로 만들 것인가 (2026-09-16, 150회차)

사장님: **"심판자 만들 계획 시행착오 학습"**

감으로 짜지 않고 **지금 상태를 먼저 쟀다.**

## 잰 것

| | |
|---|---|
| 결과물 152건 중 심판자 판정이 붙은 것 | **2건** |
| 그중 "고쳐야 한다 · 치명 1" | 1건 |
| 그래서 다시 만든 판 | **0건** |
| `shouldRedo()` 를 부르는 곳 | **없음 (죽은 코드)** |
| 칸 없는 심판자(`judgeAppeal`) 가 제품에 붙은 곳 | **없음 — 연장통에만 있다** |

**심판자는 지금까지 아무것도 바꾼 적이 없다.** 한 번 "치명" 이라고 말했고, 아무 일도 안 일어났다.

그리고 오늘 하루의 결론이 이것과 정면으로 맞는다:

- 칸 있는 심판자(`judgeWork`)는 제품에 붙어 있는데 **그 칸을 읽는 곳이 하나도 없다.** `verdict` 도 `severity` 도 소비자가 없다. **칸이 아무 일도 안 하고 있다.**
- 칸 없는 심판자(`judgeAppeal`)는 셋을 찾았다 — 우리가 정직함이라 여긴 "완료가 만점은 아니니까" 가 처음 보는 사람에겐 "주문대로 못 만드는구나" 로 읽힌다는 것, **"사람 붙이는 중" 이라는 제품 문구가 헷갈린다는 것**, 그리고 "왜 하필 기후변화 예시인지 모르겠다" 는 것. 셋 다 칸으로는 못 나왔을 말이다.

## 정한 것

### 1. 칸을 없앤다 — 쓰는 곳이 없으니까

`judgeWork` 의 enum(통과/고쳐야 한다/못 봤다, 치명/거슬림/사소)과 1~10 점수는 **아무도 안 읽는다.**
읽는 곳이 생기기 전까지 칸은 값어치가 아니라 손해다 — 판단을 뭉개기만 한다.

**제품에 붙는 것은 `judgeAppeal` 쪽**(자기 말로 답하는 것)으로 간다.
`judgeWork` 는 지우지 않고 남긴다 — **기계 판단이 필요한 자리가 생기면** 그때 쓴다(지금은 없다).

### 2. **막지 않는다.** 이건 확정이고 근거가 있다

09-16 조사: 화면 보는 AI 를 문으로 쓰면 40.7% · 45.2% · 정밀도 0.50 이고, **애매하면 통과 쪽으로 기운다**(생각을 더 시켜도 안 없어진다). 즉 **열린 채로 고장 난다** — 문이 없는 것보다 나쁘다.
그러니 심판자는 영원히 문이 아니다. **말하는 자리**다.

### 3. 그런데 말한 것이 **닿아야** 한다 — 여기가 지금 비어 있다

심판자가 말하고 아무 일도 안 나는 이유는 **받는 쪽이 없어서**다. 셋 중에서 고른다:

| 누가 받나 | 되나 | 판단 |
|---|---|---|
| 기계가 자동으로 다시 만든다 | 문이 되어 버린다. 위의 근거로 **안 된다** | ✗ |
| **사람이 읽고 누른다** | 심판자 말 옆에 "이 말대로 고쳐 줘" 단추 하나. 사람이 결정권을 쥔 채로 심판자가 일을 한다 | **○** |
| 아무도 안 받는다 (지금) | 오늘까지의 상태 | ✗ |

**가운데로 간다.** 심판자의 말이 결과물에 붙고, 그 옆에 단추가 있고, 누르면 **그 말이 그대로 다음 판의 주문**이 된다.
사람이 한 번 누르는 것이 문보다 낫다 — 조사가 말한 실패 방식(애매할 때 통과)을 사람이 메운다.

### 4. 심판자가 **좋은지**는 어떻게 아나 — 정답은 사장님뿐이다

`judge_teeth`·`judge_style_probe` 는 "고장난 화면을 잡나" 를 잰다(둘 다 통과). 그건 **이빨**이다.
그런데 **"끌리는가" 에는 정답이 없다.** 잴 자가 없고, 만들어서도 안 된다 — 그게 오늘 배운 것이다.

유일한 정답은 **사람의 반응**이다. 09-08 에 사장님이 "투구 크기 개판" 이라고 친 그 말이 정답이었던 것처럼.
그래서 쌓는다: **심판자가 뭐라 했나 · 사람이 뭐라 했나** 를 나란히. 어긋나는 판이 모이면 그때 심판자를 손본다.
**판이 쌓이기 전에는 심판자를 고치지 않는다** — 한 판 보고 고치면 그건 그 판에 맞춘 것이다.

### 5. 안 할 것

- **점수를 다시 붙이지 않는다.** 134회차에 쟀다 — 점수는 판정보다 더 흔들린다(폭 1.3 대 0.3).
- **잰 값을 먼저 물려주지 않는다.** "끌리는가" 를 물을 때는. 명암비를 먼저 주면 거기 묶인다.
  (다만 "글자가 잘렸나" 처럼 **사실이 답인 물음**에는 계속 대 준다 — 133회차에 그게 먹혔다.)
- **자동 재시도를 붙이지 않는다.** 문이 되는 순간 조사가 말한 실패 방식이 그대로 들어온다.
- **심판자를 더 만들지 않는다.** 이미 둘이고 하나는 안 쓰인다.

## 순서

1. `judgeAppeal` 을 **영상 결과물에 붙인다** — 지금 `judgeWork` 가 있는 자리에.
2. 그 말을 결과물 본문과 미리보기에 **사람이 읽게** 띄운다.
3. 그 옆에 **"이 말대로 고쳐 줘"** 단추. 누르면 심판자의 말이 다음 판의 주문이 된다.
4. 심판자 말과 사람 판정을 **나란히 쌓는다**(`judge_routing.mts` 를 그 모양으로 넓힌다).
5. 여덟 판쯤 쌓이면 어긋난 것만 모아 본다. 그때 고친다.
