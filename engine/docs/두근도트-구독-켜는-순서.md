## **선톡이 0명이던 까닭 둘** (구독의 값어치가 여기 걸려 있다)

1. **알림 켜는 단추가 한도 화면에만 있었다.** 한도에 닿은 날이 3%였으니 아무도 그 단추를 못 봤다.
   → 무료가 10회가 되면 **11%** 가 보게 된다.
2. **빌드에 알림 위임이 꺼져 있었다.** `twa-manifest.json` 은 true 였지만 실제로 쓰이는 건
   `app/build.gradle` 이다([[twa-build-source-of-truth]]). 10-25 에 true 로 바꿨다.

둘 다 고쳤으니 **구독을 팔기 전에 알림 수락이 실제로 오르는지 먼저 봐야 한다.** 못 주는 걸 팔면 안 된다.

### ④ 서비스 계정 열쇠 꽂기 (구매 검증)
1. Google Cloud → 서비스 계정 만들기 → JSON 열쇠 내려받기
2. Play Console → 사용자 및 권한 → 그 서비스 계정 초대 → **재무 데이터 보기** 권한
3. Railway `dot-web` 환경변수에 **한 줄 JSON** 으로:
   - `PLAY_VERIFY_KEY` = 그 JSON 통째로
   - `BILLING_OPEN` = `1`
   - (패키지가 바뀌면 `DOT_PACKAGE` 도)

**이 열쇠가 없으면 `/api/dot/buy` 는 503 으로 막는다.** 일부러 그렇게 만들었다 —
10-24 에 이 자리는 `BILLING_OPEN=1` 만 켜면 **아무나 POST 해서 크레딧을 받아 가는** 구멍이었다.

### ⑤ 재기
- `dot_take_turn` 이 10회에서 0 을 돌려주나 (계정이 생긴 뒤에야 잴 수 있다)
- 구독자가 11번째 턴에 안 막히나
- 가짜 토큰으로 `/api/dot/buy` 를 때려 400 이 오나
- **알림 켠 사람 수가 0에서 오르나** ← 이게 구독의 값어치다
