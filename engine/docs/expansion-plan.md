# 확장 계획표 — 검증 가능한 일들의 공장 (2026-08-24)

**정직한 게이트 (지우지 않는다)**: 레인을 *만드는* 건 지금 가능. 레인을 *고객에게
파는* 건 09-05 수요 판정 뒤. 이 표는 "만들기" 계획이지 "팔기" 계획이 아니다.

## 핵심 구조 — 확장 = 레인의 반복
모든 확장은 **같은 골격**이다 (아이콘 레인 v1에서 사장님이 이미 잡음):
```
레인 = spec.yaml(public/hidden) + Proposer 프롬프트 + Validator J(순수함수) + 재시도 정책
```
- **Proposer**: 외부 LLM (교체 가능). 우리 자산 아님.
- **Validator J**: 우리 순수 함수. 모델 호출 0. **이게 자산.**
- 이미 있는 것 그대로 씀: 웹훅 수신·검토 큐·대시보드·감사 로그.
