# 완주 시도 사전 등록 v0 (게이트 ⑤)

작성 2026-08-27 12:0x. **숫자 보기 전 등록.** 목 파일럿은 지출 0.

## 1. 무엇을 재나

게이트 ⑤는 *"위 넷을 개입 0으로 유지한 채 세트 하나를 끝까지 굴린다"*이다.
지금까지 이 층은 **0%**였다 — 시도한 적이 없기 때문이다.

이 실험은 **성공을 목표로 하지 않는다.** 목표는 **어디서 멈추는지 찾는 것**이다.
그러므로 "완주 실패"는 결과이지 실패가 아니다.

## 2. 완주의 정의 (동결)

요청 문장 하나에서 게임까지 **여덟 칸**을 지난다:

| # | 칸 | 도구 | 사람이 필요한가 |
|---|---|---|---|
| 1 | 요청 → 능력 원자 분해 | `blueprint_engine.intake` | 아니오 |
| 2 | 재구성 + 되묻기 | `blueprint_engine.reconstruct/ask_back` | **되묻는다** = 개입 지점 후보 |
| 3 | 설계도 + 견적 | `blueprint_engine.blueprint/estimate` | 승인이 필요한가? |
| 4 | 자산 생성 | `icon_lane_run` | 지출 승인 |

| 6 | 세트 심판 | `icon_judge.judge_set` | 아니오 |
| 7 | 선별 | `pick_session` | **사람이 고른다**(규율) |
| 8 | 조립 + 게임 확인 | `assemble_game` + `game_smoke` | 아니오 |

## 3. 개입을 세는 법 (동결)

**개입 = 사람이 손대지 않으면 다음 칸으로 못 가는 지점.**

- 세 종류로 나눠 센다: `approval`(승인만 하면 됨) · `choice`(사람이 골라야 함) ·
  `fix`(사람이 고쳐야 함).
- 각 지점마다 **무엇을 물어야 하는지**를 기록한다.
- 자동으로 지난 칸은 `auto`로 센다.

## 4. 판정 (동결)

| 조건 | 판정 |
|---|---|
| 여덟 칸을 `choice`·`fix` 개입 0으로 통과 | **complete** |
| `approval`만으로 통과 | **approval_only** |
| `choice`나 `fix`에서 멈춤 | **stopped** + 멈춘 칸과 이유 |
| 도구가 없거나 못 잰 칸 | **undefined** |

**표본**: 세트 하나(개념 3개 이상). 이번 회차는 **1회**이고 일반화하지 않는다.

## 5. 이번 회차의 제약 (미리 적는다)

- **생성(4번)은 목(mock)으로 돈다.** 목 후보는 스펙을 일부러 어기므로 5번 심판에서
  전부 떨어진다. 그러면 6~8번은 **자산 없이** 도달 여부만 본다.
  즉 이번 회차는 **배관 검사**이지 품질 검사가 아니다. 실 생성은 승인 사항이다.
- **선별(7번)은 취향 라인이 중단됐으므로** 사람 눈 게이트다. 여기서 멈추는 것이
  **예상된 결과**이고, 그 사실이 이 실험의 요점이다.
- 그러므로 이번 판정은 `stopped`가 유력하다. **그 예상을 결과보다 먼저 적어 둔다.**

## 6. 안 하는 것

- 멈춘 지점을 우회하려고 기계가 대신 고르는 것(선별 규율 위반).
- "개입 0"을 만들기 위해 칸을 빼는 것 — 여덟 칸은 제품이 실제로 지나야 하는 길이다.
- 이 한 회차로 "한 달 자율작업"을 말하는 것.
