## 기준 (지켜야 하는 것)

| 칸 | 기준 | 왜 이 숫자인가 |
|---|---|---|
| 캔버스 | **512×512 · 알파 0/255** | 지금 전부 그렇다. 반투명이 있으면 도트가 흐려진다 |
| **도트 크기** | **4** (격자 128) | 11-09 사장님 *"화질도 잘 나오게 하자"*. 점 수가 네 배다. **열 명을 같은 판에** 다시 뽑아 올렸다 — 한 명씩 올리면 또 갈린다 |
| 잉크 높이 | **110~128칸** | 다시 뽑은 열 명의 실제 범위. 키가 들쭉날쭉하면 말풍선 옆 얼굴 크기가 흔들린다 |
| 잉크 폭 | **85~128칸** | 머리 모양 때문에 넓어지는 것은 받아들인다(나비 트윈테일·하루 곱슬) |
| 색 수 | **14~24** | `pixelize` 가 24색으로 줄인다. 40을 넘으면 뭉개기가 안 먹은 것 |
| **흰 테두리** | **바깥 잉크 칸의 90% 이상** | `outlineShare`. 캔버스 끝에 닿은 칸은 안 센다(거기는 칠할 자리가 없다) |
| 얼굴 크롭 가운데 | **59~75%** | 일곱의 실제 범위. 절대 기준(35~65%)은 **쓰고 있는 일곱도 떨어진다** — 그 자는 문이 아니다 |
| 표정 구별 | **42px 에서 6% 이상** | 일곱은 10.5~25.8%. 그 아래면 말풍선 옆에서 표정이 안 보인다 |
| 말투 사다리 | polite · tsundere · blunt · bright 중 하나 | 비면 `formal_start` 만 보고 메워져 성격이 깨진다 |
| 사진 | **8장** | 1~4장이면 피드가 같아 보인다(11-09 실측 사진 반복 87~94%) |

## 게시물 사진 기준 (11-09)

사진에도 기준이 없었다. 재 보니 **200×250 · 도트 1 · 16색**인데, 피드 폭이 390 이라
**1.9배로 늘려** 쓰고 있었다 — 도트가 뭉개져 보이는 까닭이다.

| 칸 | 기준 | 왜 |
|---|---|---|
| 크기 | **400×500** (논리 도트 200×250, **1도트 = 2화소**) | 피드 폭 390 에서 거의 1:1 이라 안 뭉개진다 |
| 도트 | **2** | 스프라이트(도트 4)와 같은 결. 1 이면 사진만 매끈해 보인다 |
| 색 수 | **≤ 32** | 지금 16. 32 까지 열어 두되 그 위는 뭉개기가 안 먹은 것 |
| 본 | **그 사람의 지금 스프라이트** | 얼굴·머리·옷이 유지된다. 옛 그림을 본으로 쓰면 다시 뽑을 때마다 사람이 달라진다 |
| 장수 | **8장** | 1~4장이면 피드가 같아 보인다(11-09 실측 반복 87~94%) |
| 장면 | 계절·시간을 흩고, 사람은 혼자, 글자 없음 | 연우가 10월에 "첫눈" 을 열세 번 올린 적이 있다 |
| 같은 사람인가 | 머리 색이 스프라이트 팔레트와 **ΔE ≤ 25** 안에 있을 것 | 다시 뽑을 때 슬쩍 다른 사람이 되는 것을 막는다 |

## 지키게 하는 곳 (사람이 기억하지 않는다)

1. `dot_new_character.mts` — 뭉개기 → **테두리 자동** → 자 아홉 개. 하나라도 떨어지면 **안 올린다.**
2. `dot_character_open.mts` — 켜는 문. 스프라이트·얼굴·사진·사다리·인사·**테두리**를 다시 재고,
   사진 주소를 **두드려 본다.**
3. `dot_character_spec.mts --check` — **열 명을 한 판에** 재고 하나라도 벗어나면 1 로 끝난다.
   켜는 문이 이걸 부른다 — 새 사람을 켜는 순간이 곧 줄 전체가 어긋나는 순간이다.
   심은 고장(린 발밑 8화소 띄우기)으로 **잡는 것을 확인했다**(`dot_spec_sabotage.mts`).
   **11-10: 게시물 사진 80장도 같은 판에서 잰다** — 크기 400×500 · 도트 2 · 색 8~32 · 8장.
   그 전까지 사진은 "4장 이상 · 주소가 열리나" 만 봤다. 기준은 문서에만 있었고 **재는 곳이 없었다** —
   200×250 으로 되돌아가도 통과했을 것이다. 심은 고장(린 사진 한 장을 200×250 으로)으로
   `❌ rin: 사진 크기 200x250(1장) · 사진 도트 1(1장)` 이 뜨는 것을 확인했고, 되돌리니 0/10 이다.
4. `dot_regrid.mts` / `dot_standardize.mts` — 벗어났을 때 맞추는 손. 둘 다 그림은 안 바꾸고
   **칸 단위로만** 옮긴다(잉크 칸 수·도트 크기가 달라지면 멈춘다).

## 11-09 저녁 — **열 명을 같은 판에서 다시 뽑았다**

사장님: *"지금 처음부터 다시 뽑아야 할 거 같아, 지금 너무 달라"* → *"화질도 잘 나오게 하자"*.

- 본은 **하루** 한 장. 취향이 아니라 해상도로 골랐다 — 머리 작은 그림체는 얼굴에 점이 10개밖에
  안 가서 눈이 1~2점이 된다. 친밀도가 표정을 바꾸는 제품이라 표정이 안 읽히면 기능이 죽는다.
- `restylePrompt` 로 *"그림체는 그대로, 사람만 바꿔"*. 열 명 전부(본 포함) 한 판에서 뽑았다.
- 격자 **64 → 128**, 품질 medium → **high**. 토큰 1,372/장.
- 마무리는 길 안에서 한다: 뭉개기(격자 128) → 흰 테두리 → 발밑 0.
- **자는 내보낼 그림에 댄다.** 전에는 자른 직후(뭉개기 전)에 재서 "도트다" 가 늘 떨어졌다 —
  아무도 안 쓰는 그림을 재고 있었다.

## 바꿀 때의 규칙

- **도트 크기를 올리려면 열 명 전부**다. 격자 256 이 더 촘촘한 건 맞지만(사장님 11-08
  *"격자는 많을 수록 좋아"*), 한 명씩 올리면 지금처럼 결이 갈린다. 올린다면 스프라이트 84칸 +
  멘헤라 24칸 + 얼굴 84개를 **같은 판에** 올려야 하고, 옛 일곱은 시트가 셋 없어서
  (doyun·rin·seoha) 그 셋은 다시 그려야 한다.
- 기준을 고칠 때는 **좋은 쪽을 먼저 같은 자로 잰다.** 오늘 두 번 걸렸다 —
  얼굴 크롭 절대 기준과 테두리의 캔버스 끝 칸. 둘 다 쓰고 있는 그림이 떨어졌다.
