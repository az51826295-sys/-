# 그림 판정: 싼 AI · 비싼 AI · 올리기 · 기계+AI — 공개 정답지로 (사전 등록, 2026-11-23 10:0x)

**"AI 처리와 기계식 처리를 같이 하면 효율이 오른다"** → 기계 팔(D)을 같이 잰다. 숫자 보기 전에 잠근다.

## 시험 둘
- **T1 같은 화가인가** — WikiArt 풍경 350장(모네·피사로·부댕·하삼·르누아르·반 고흐·세잔, 각 50).
  화가마다 앞 15장 = 개발(기계 문턱만 맞춤), 뒤 35장 = 시험. 시험 쌍 **120**(같음 60 / 다름 60, 씨앗 고정).
  다름은 전부 같은 시대 풍경이라 쉬운 쌍이 아니다. 정답 = 작가 이름표.
- **T2 어느 그림이 나은가** — HPDv2 test(사람 여럿이 순위). 한 주문의 그림 둘을 뽑되 **판정자 다수가 같은 쪽을 고른 쌍만**
  (평균 순위 차 ≥ 3). 시험 쌍 **120**. 정답 = 사람 다수.
- 쌍의 순서(1번/2번)는 씨앗으로 섞는다(앞자리 편들기 방지).

## 팔
- **A** `gpt-5.6-luna` 혼자 · **B** `gpt-5` 혼자 (둘 다 답 + 자신감 0~1)
- **C 올리기**: A 의 자신감 < **0.8** 이면 B 의 답으로 바꾼다(값 = A + 올린 B).
- **D 기계 먼저 (T1 만)**: 색·채도·명도 분포 + 붓질 결(경사 세기)로 두 그림 거리를 기계가 센다(모델 0, 값 0).
  개발 쌍에서 "기계만으로 90% 이상 맞는" 아래·위 문턱을 정하고 **잠근 뒤** 시험에 쓴다.
  문턱 밖이면 기계가 끝내고, 안쪽(애매)이면 C 로 넘긴다. T2 는 기계로 잴 좋은 특징이 없어 D 를 안 둔다(정직하게 비움).

## 판정 (잠금)
과제마다:
1. **올릴 거리 확인**: A 정확도 ≥ B − 3%p 면 "싼 AI 로 충분 — 판단할 거리 없음"(C·D 판정 안 냄).
2. **C 선다** = C 정확도 ≥ B − 3%p **그리고** C 값 ≤ B 값의 50%.
3. **D 선다(T1)** = D 정확도 ≥ C − 2%p **그리고** D 값 ≤ C 값의 70%. (사장님 관점의 검증)
4. B 정확도 ≤ 60% 면 "누구도 못 하는 과제" 로 기록하고 판정 안 냄.
