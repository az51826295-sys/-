# 실험 3 설계 — 선택 지능의 일반화·붕괴 조건 (사전 등록)

작성일: 2026-07-30. 상태: 사전 등록 완료, 구현 진행.
전제: 실험 2에서 서열 D(0.434) < C(0.917) < E(1.000) 확립.
법의학: C의 실패 중 하나(seed 14)는 순서 운이 아니라 **근시안 고착**
(대안 순서 8/30만 회복) — 로컬 탐욕이 조합적 가치 단서를 체계적으로
미룬다. 실험 3은 이 관찰을 정면으로 겨눈다.

핵심 질문 (사용자 확정):
> E의 성능은 중앙화 자체 때문인가, 정확한 정보 이득 계산 때문인가?
> 그리고 중앙 코디네이터 없이도 개체들이 그 기능을 스스로 만들어낼 수
> 있는가?

## 1. 비교군

| 군 | 정의 |
|---|---|
| C | 자유 소통 (실험 2 그대로 — 분산·정확 로컬 탐욕) |
| E | 중앙·정확 정보 이득 선택 (실험 2 그대로) |
| F(σ) | 중앙·**노이즈 보고** — 개체가 보고하는 생존 수에 로그정규 노이즈 ×exp(N(0,σ)), σ ∈ {0.2, 0.5, 1.0}. 코디네이터는 보고값만 봄 |
| G | 중앙·**전략적 왜곡** — 개체 절반은 자기 가치 과장(보고 ×0.5), 절반은 축소(×2.0) |
| H | 무중앙·**평판 투표** — 각 개체가 지금까지 실현 감소량이 가장 큰 개체에게 투표, 최다 득표자가 자기 로컬 최선을 공유 |
| I | 무중앙·**학습 우선순위** — 정확한 계산 대신 과거 에피소드의 사후 기여(최종 보드에서 leave-one-out 필요성)로 학습한 단서 특징별 가치로 선택. 훈련 30 에피소드(seed 1001~1030), 시험은 미학습 seed 1~20 |
| E-decap | E로 예산 절반 진행 후 **코디네이터 제거** → 나머지는 C로. 하락폭 = 중앙 시스템의 취약성 측정 |

공유 예산·판정(전수 CSP)·평가기 v2는 실험 2와 동일. F·G의 왜곡은
"어느 개체가 발언하는가"에만 작용한다 (개체가 실제 공유하는 단서는
자신의 진짜 로컬 최선 — 보고만 왜곡되고 행동은 정직).

## 2. 난이도 3단계 (생성기 단서 팔레트)

| 단계 | 팔레트 | 성질 |
|---|---|---|
| easy | NOT, IS_ONE_OF | 핵심 단서가 명확 — 개별 감소량 큼 |
| medium | 전체 혼합 (실험 2와 동일) | |
| hard | PAIR_NOT, IMPLIES | 개별 감소량 작고 **조합해야만 가치** — 근시안 탐욕의 함정 |

유효성 게이트는 실험 2와 동일 (전체=유일해, 개체별 잔여 ≥ 20).

## 3. 사전 등록 가설 (실행 전 고정)

- **P6**: 정확한 E는 easy·medium에서 최고 성능 (전 군 대비 ≥, 18/20 이상).
- **P7**: F의 성능은 σ에 단조 감소 — mean(F₀.₂) ≥ mean(F₀.₅) ≥ mean(F₁.₀),
  전부 E 이하.
- **P8**: hard에서는 E가 반드시 최선이 아니다 — E의 유일해 도달률이
  easy 대비 하락하거나, E를 넘는 군이 존재.
- **P9**: I는 훈련 전 C보다 낮지만, 훈련 후 **hard에서** C를 추월
  (13/20 이상). easy에서는 추월을 예측하지 않음 (정확 계산이 이기는 게
  정상).
- **P10**: 단순 평판 투표 H는 E보다 낮다 (18/20 이상).
- **P11 (E-decap)**: 코디네이터 제거 시 하락폭이 (E−C) 격차의 절반 이상
  이면 "강력하지만 취약한 중앙 시스템"으로 판정.

## 4. 측정값

최종 기대 정확도 / 유일해 도달 공유 수 / 공유당 실제 감소량 /
보고값-실제 오차 (F·G) / **핵심 단서 미룸** — 전체 집합에서 leave-one-out
시 유일성이 깨지는 단서(critical) 중 종료 시 보드에 없는 수 (미해결
run에서만 0 초과 가능 — 해결된 보드는 critical을 반드시 포함함을 증명
가능) / E-decap 하락폭 / I의 에피소드별 학습 곡선.

## 5. 실행 순서 (사용자 지정)

F·G로 E의 취약성 확인 → H로 단순 합의 한계 확인 → I로 조정 지능의
학습 가능성 검증. **성공의 정의는 E의 완벽함 재확인이 아니라, 중앙
선택이 어떤 조건에서 무너지고 분산 시스템이 그 기능을 스스로 대체할
수 있는지의 지도를 얻는 것이다.**
