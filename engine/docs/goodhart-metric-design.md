# Goodhart 계측 — 정의 (2026-08-22 초안 → **같은 날 사용자 승인으로 동결**)

판별 제도 백로그의 마지막 항목. 진행도 절에 "Goodhart 계측"이라는 이름만
있고 정의가 없어, 여기서 **무엇을 재는 것인지**부터 정했다. 2026-08-22
사용자 승인으로 동결, 같은 날 구현 (`tools/goodhart.py`, 테스트 4건).

## 동결 시 확정한 세부 정의 (구현과 일치)

- **G-a 분모 = 사람이 검토를 끝낸 채택**(submitted + dismissed). 검토
  대기(new/pushed)는 제외 — 아직 판정이 없다. dismissed는 "오라클은
  통과시켰지만 사람이 거른 것"이라 G-a를 낮춘다.
- **G-b 분모 = 결말이 난 제출**(merged + closed-unmerged). open은 제외하되
  수는 보고.
- **G-c의 "손질"(fixup) = 채택 산출물(코드)을 사람이 고친 것** — 스크래치
  제거, 코드 변경, 범위 축소. 회귀 테스트 추가·PR 본문 작성은 제출 절차지
  손질이 아니다. 표시는 PR 큐에서 `pr_queue.py mark <task> submitted <url>
  --fixup`로 사람이 한다(기계가 추정하지 않는다).
- 알람: 직전 14일(오늘 제외) 이동평균 대비 **절대 0.2p 하락**. 이력 없으면
  알람 없음. 날짜당 1행(`data/goodhart/history.jsonl`).
- 산출 주기: 사람이 돌리거나 일일 보고에 편입(엔진 코드 변경이라 48h
  드라이런 종료 후). 모델·프롬프트에는 절대 노출하지 않는다.

## 문제

루키의 성과 지표는 전부 **대리 지표**다: "재현 테스트 fail→pass + 감사
통과 = 채택". 이 대리가 진짜 목표("남이 받아들이는 올바른 수정")와
벌어지는 순간이 Goodhart다. 징후는 이미 있었다 — 능력 실험 4의 스크래치
파일 혼입(대리는 통과, 산출물은 불결), 재검증 A팔의 정규식 마커 삽입
시도(테스트를 통과시키려는 국소 조작). 지금은 사람 검토가 이 간극을
메우지만, 상주·무인(스테이지 1)으로 가면 **간극을 수치로 상시 감시**해야
한다.

## 제안: 세 쌍의 "대리 vs 실제" 비율을 상시 산출

| 이름 | 대리 (엔진이 보는 것) | 실제 (바깥이 보는 것) | 지표 |
|---|---|---|---|
| G-a 채택 대 제출 | 채택(adopted) 수 | 사람 검토를 통과해 실제 제출된 PR 수 | 제출/채택. 낮아지면 오라클이 헐거워진 것 |
| G-b 제출 대 수용 | 제출 PR 수 | 머지(또는 메인테이너 긍정 반응) 수 | 수용/제출. 바깥 기준과의 간극 — 가장 느리지만 가장 진짜 |
| G-c 통과 대 무결 | 재현 테스트 통과 | 위생·감사·사람 검토에서 **추가 수정 없이** 통과 | 무결/통과. 스크래치 혼입·국소 조작·범위 초과를 잡는 비율 |

각 비율은 날짜별·저장소별로 원장(events: agent_outcome, pr_ready,
audit_*)과 PR 큐 상태(data/pr_queue_state.json: submitted/dismissed)에서
기계 산출한다. **G-b만 외부 사실(GitHub PR 상태)** 이 필요하고, 나머지는
이미 있는 기록으로 계산된다.

## 알람 규칙 (제안)

- 어느 비율이든 직전 14일 이동평균 대비 **절대 0.2p 하락**하면 알람
  이벤트(조용한 악화 금지 — unattended-ops-rules의 적체 알람과 같은 꼴).
- G-c가 1.0 미만으로 **두 번 연속** 나오면(= 대리는 통과했는데 손질이
  필요했던 채택이 연속) 해당 종류의 일에서 채택 문턱을 높이는 대신 **감사
  불변식 추가를 안건으로 등록**한다 (문턱 조정은 대리를 더 대리답게 할
  뿐이다 — 다른 불변식이 답).

## 하지 않을 것

- 비율을 모델에게 보여주거나 프롬프트에 넣지 않는다 (출처 계약 8항:
  장부는 운영 상태이지 컨텍스트가 아니다). Goodhart 계측은 **사람과
  라우팅**만 읽는다.
- 비율을 높이려는 어떤 자동 조정도 넣지 않는다 — 이 지표 자체가 다음
  Goodhart가 되는 길이다. 알람과 안건 등록까지.
