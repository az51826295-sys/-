## 1. 무엇을 왜 재나

`docs/brief-icon-ai-20260826.md` §Q1: 심판이 작동하면 통과분은 순응도에서
동등하므로, 생성기는 **(수율, 비용, 다양성)** 에서만 다르다. 수율 0.98,

물어야 할 것을 판정 가능한 명제로 바꾸면:

> **같은 개념에 후보를 계속 뽑을 때, n번째 "새로운" 통과 아이콘 하나를 얻는 데
> 드는 생성 후보 수가 늘어나는가(포화), 그대로인가(평평)?**

- **평평** = 생성기가 아직 자기를 반복하지 않는다 → 다양성 축에서 **교체할 이유 없음**.
- **포화** = 더 뽑아도 같은 것만 나온다 → 생성기 교체가 실익이 있는 축이 된다.

## 4. 통계 — Good–Turing (파라미터 0개)

개념 하나 안에서, **통과한 후보**의 서명 목록을 본다.

- `N` = 그 개념의 통과 후보 수
- `f1` = 딱 한 번만 나타난 서명의 수
- **새것 비율** `u = f1 / N` = "다음 후보가 새 서명일 확률"의 Good–Turing 추정값
- **한계비용** `m = 1 / u` (새 통과 아이콘 하나당 통과 후보 수)
  → 생성 후보 기준 한계비용 `m_gen = m / (그 회차 통과율)`

개념별 `u`를 구하고, **개념을 표본 단위로** 평균과 부트스트랩 구간을 낸다
(개념끼리는 독립이지만 개념 안의 후보는 아니다).

## 5. 판정식 (동결 — 숫자 보기 전)

**분해능 검사가 먼저다.** 어떤 층위에서 중복이 하나도 없으면(`f1 == N`, 즉 `u == 1`)
그 층위는 이 표본 크기에서 **아무것도 못 가른다.** 그건 "평평"이 아니라
**분해능 없음**이다.

1. T1 → T2 → T3 순으로 내려가며 **`u < 1`인 첫 층위**를 판정 층위로 삼는다.
2. 세 층위 모두 `u == 1`이면 → **undefined (분해능 없음)**.
3. 판정 층위에서, 개념 평균 `ū`의 부트스트랩 95% 하한/상한으로:

| 조건 | 판정 |
|---|---|
| `ū`의 95% 하한 ≥ 0.80 | **flat** — 다양성 축에서 생성기 교체 불필요 |
| `ū`의 95% 상한 ≤ 0.50 | **saturating** — 교체가 실익 있는 축 |
| 그 사이 / 표본 미달 | **undefined** |

**표본 관문(동결)**: 개념 ≥ 8, 통과 후보 ≥ 40, **개념당 통과 후보 ≥ 6**.
미달이면 판정은 **undefined**이고, **관문을 낮추지 않는다.**

## 6. 미리 적어두는 한계 (결과와 무관하게 참)

우리 로그는 개념당 후보가 **최대 6개**이고 전부 1라운드·temp 1.0이다.
N=6에서 Good–Turing은 매우 거칠다. 그러므로 **이 측정이 "undefined"로 끝날
가능성이 높고, 그것도 결과다** — 그때의 결론은 "다양성은 모른다"이지
"다양성은 괜찮다"가 아니다.

undefined가 나오면 답을 낼 수 있는 최소 실행은 다음과 같다(사장님 승인 사항):

> 개념 1~2개 × 후보 60개(라운드 1, temp 고정) ≈ **$0.06~0.12**.
> 한 개념 안에서 곡선의 기울기를 직접 볼 수 있는 최소 표본이다.
