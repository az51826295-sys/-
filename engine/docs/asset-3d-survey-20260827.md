## 1. 조사 원문 요지

### 되는 것

- **Meshy**: 생성 → PBR 텍스처 → **자동 리깅** → 엔진 익스포트를 브라우저 하나로.
  휴머노이드·사족보행 자동 리깅 후 모션 프리셋 600+(무료 20+). FBX/GLB/OBJ/BLEND
  내보내기, Unity·Unreal·Godot·Blender 플러그인.
  Tripo·Rodin·Luma는 **자동 리깅이 없어** 캐릭터를 Blender에서 따로 리깅해야 한다.
- **가격/라이선스**: 무료 월 100크레딧, 출력물 **CC BY 4.0**(출처 표기 시 상업
  이용). 무료 플랜 에셋은 **공개**되고 출처 표기 필요. Pro $20/월 1,000크레딧에
  비공개 에셋 + API.

### 안 되는 것

- **Mixamo**: 2025-06-16부터 백엔드 인증 장애로 간헐 고장, 유지보수 모드.
  업로드·다운로드·오토리거·계정이 전부 그 인증 계층에 물려 있다. 파이프라인
  중간에 터지면 답이 없다.

### 배치안

| 대상 | 툴 | 이유 |
|---|---|---|
| Box 본체 | Meshy (이미지→3D) | 레퍼런스 시트 → 생성 → 자동 리깅 → 걷기/공격 |
| 몬스터·보스 | Meshy | 리깅이 필요하니 선택지 없음 |
| 무기 12종·소품 | Tripo | 평균 8초, 엔진용 토폴로지 자동 최적화(정적 오브젝트) |
| 대량 프로토타입 | Rodin 최저 티어 | 20크레딧 30초로 검증 후 통과분만 고품질 재생성 |

⚠️ 조사의 핵심 경고: Meshy 토폴로지는 프로덕션 수준으로 깨끗하지 않아 **히어로
에셋은 Blender 수동 리토폴로지가 보통 필요**하다.

### 조사가 붙인 조건

- 엔진은 Unity가 아니라 **Three.js/R3F**로 가야 AI가 끝까지 만든다.
- 무료 100크레딧으로 **Box 하나만** 먼저 → 쓸 만하면 3D 확정, 아니면 도트로 회귀.
- 출시하려면 Meshy Pro $20/월은 결국 필요.

## 2. 내 판단 (조사와 갈리는 곳 둘)

### 2-1. 엔진을 바꿀 이유가 없다 — Godot이면 내가 끝까지 간다

조사는 "Unity면 사람이 에디터를 직접 다뤄야 하니 Three.js/R3F로 가라"고 한다.
**우리는 Unity가 아니라 Godot이다.** 그리고 Godot 씬(`.tscn`)과 스크립트(`.gd`)는
**텍스트 파일**이라 에디터 없이 내가 편집한다. 오늘 밤 헤들리스로 프로젝트를
적재해 오류 0을 확인했다:

```
Godot_v4.7.1 --headless --path game --quit   # 오류 없음
```

즉 "엔진 때문에 내가 못 만든다"는 제약은 우리 경우엔 성립하지 않는다.
엔진을 바꾸면 **이미 걷고 있는 프로토타입**(주인공·상인·타일맵)을 버린다.

### 2-2. 3D의 진짜 문제는 툴이 아니라 **심판이 없다**는 것

2D 픽셀에서 우리가 가진 것: 규격 스펙(`pixel-sprite-v1`), 반입 오라클, 후처리,
이미지 특징 10개, 선별 기록. **3D에는 이 중 아무것도 없다.**

3D 자산을 사려면 먼저 "쓸 만한가"를 눈이 아니라 규격으로 갈라야 한다. 최소한:

| 재는 것 | 왜 |
|---|---|
| 삼각형 수 · 메시 수 | 성능 예산 |
| 텍스처 해상도 · 채널 | 아틀라스 규격 |
| 본 이름 · 계층 · 본 수 | 자동 리깅이 실제로 붙었나 |
| A-pose 여부 · 스케일(1유닛=1m) · 축(Y-up) | 엔진에 그대로 들어가나 |
| 매니폴드 · 뒤집힌 법선 · UV 겹침 | 조사가 경고한 "토폴로지가 안 깨끗함"의 기계 판정 |

이게 `docs/asset-3d-intake-v0-design.md`로 먼저 서야 Box 하나를 뽑아도
**"쓸 만하다"가 취향이 아니라 판정**이 된다. 없으면 우리는 다시 눈으로 본다.

## 3. 아침에 여쭐 것

1. **3D로 가나, 도트로 남나** — 이건 사장님 결정이다. 조사대로 Box 하나만
   뽑아보는 건 싸다(무료 크레딧). 다만 §2-2의 오라클이 먼저다.
2. **Box 레퍼런스 시트**가 있어야 한다. Meshy는 이미지→3D가 리깅 성공률이 제일
   높다는데, 그 이미지는 사장님 창작이다. 내가 지어내지 않는다.
3. **무료 플랜의 "에셋 공개 + CC BY"** 를 받아들일지. 상업 출시를 생각하면
   Pro가 필요하다는 조사의 말은 확인이 필요하다(§ 미검증 표시).
4. 엔진: **Godot 유지**(내 추천) vs Three.js/R3F 전환.

## 4. 지금 상태에서 바뀌지 않는 것

3D로 가든 도트로 남든, 오늘 밤 확정된 것 둘은 그대로 쓰인다:
**세트의 첫 자산이 제일 비싸다**(예시 0개 0.018 → 1개 0.836), 그리고
**심판 없는 축은 사람이 쥔다**. 3D에서도 첫 캐릭터 하나가 파이프라인 전체의
난이도를 결정할 것이다.
