# 실험 7B 설계 — 확장 공간에서의 의미 기반 제안 (사전 등록 초안)

작성: 2026-07-31. 상태: **동결 (2026-07-31, 파일럿·끌개 검증 완료)**.
근거: 사용자 제안서 (2026-07-31) 3절 + 7A 동결 감사 결과. 7A 등록:
[mission7-design.md](mission7-design.md).

핵심 질문:

> 표현 공간이 커져 무작위 탐색이 사실상 어려워졌을 때도, 실패 관측을
> 받은 LLM 제안자가 의미 있는 구조를 효율적으로 발견하는가?

## 1. DSL 확장 (원칙: 독립 추가·기존 비교 가능·자동 검증 유지)

7A DSL에 다음 4기능을 추가한다. 각 기능은 개별 플래그로 끄고 켤 수
있어야 하며(절제 실험 대비), 실행기 의미론은 사전 등록으로 동결한다.

- **A. 상태 유지**: 개체별 정수 모드(0~3, 초기 0) + `SET_MODE k` /
  `CLEAR_MODE` 행동, `my_mode`·`rounds_since_my_action` 지표.
- **B. 역할 한정**: 규칙에 선택적 `role ∈ {0,1,2}` 태그. 역할은
  익명 슬롯(개체 idx mod 3)으로 시작 — 의미는 사람이 부여하지 않는다.
- **C. 규칙 조합(연쇄)**: `THEN` 뒤 최대 2행동 시퀀스 허용
  (예: `SET_MODE 1; PASS`). 실행기는 시퀀스를 같은 턴에 순차 적용,
  공유 행동이 나오면 중단.
- **D. 사회 상태 참조**: 공개 지표 추가 — `total_shares`,
  `consecutive_all_pass`, `mean_recent_gain`(최근 3공유),
  `active_speaker_count`(직전 3사이클 내 공유한 개체 수).

탐색 공간 (자동 산출기 `--space` 실측): 단일 규칙 기준 7A-상당(확장
전부 꺼짐) 342,280 → 7B 전체 **69,058,800 (약 200배)**. 규칙 8개
조합 공간은 그 거듭제곱 차수. 무작위 120후보가 커버 불가능한 규모임을
등록 수치로 명시한다.

## 2. 실험군 (동일 DSL·검증 세트·후보 수·평가 예산)

R / Z / S / T는 7A와 동일 정의. 추가:

- **T-Memory**: T + 과거 제안·채택·롤백 이력의 구조화 요약 (레지스트리
  `history_for_proposer` — 연산·점수·채택 여부만, 해석어 없음).
  7A 감사에서 확인된 두 병목(중복 제안률 0.81~0.94, 연산 편향
  add 96%/remove 0%)을 정보만으로 교정할 수 있는지 검증.
- (선택) Human upper bound: 동일 관측 정보만 받은 인간 제안 소수.

## 3. 사전 등록 가설

- **P32 (표본 효율)**: T 또는 T-Memory가 무작위 중앙값 후보 수의
  ≤50%로 등록 목표 점수 도달, **master seed 5개 중 ≥4**.
- **P33 (성공률)**: 확장 공간에서 LLM 성공률 − 무작위 성공률 ≥ 40%p.
- **P34 (끌개 탈출, 상대 정의 — 7A P30 교훈 반영)**: 의도 구성된
  끌개 2종에서 시작해, "시작 대비 검증 score +0.15 이상 + 해당 개선
  규칙의 실제 채택 + 미관측 시험에서 시작 대비 +0.10 유지"를 탈출
  성공으로 정의. LLM ≥ 4/5 seed, R ≤ 1/5.
- **P35 (궤적의 추가 가치)**: T > S (7A는 천장으로 미분리). 집계값이
  같아도 궤적이 다른 실패 모드를 갖는 과제 구성을 파일럿에서 확인 후
  동결.
- **P36 (누적 기억)**: T-Memory는 T 대비 중복 제안률과 무효율을
  낮추고(각 ≥30% 상대 감소), remove 연산 비율이 0을 벗어난다.
- **P37 (일반화)**: 미관측 seed·slack + {개체 수 4·8, 강제 공유
  유예 4·8} 중 2개 축 이상에서 개선 유지.
- 동률 = 평균 차 < 0.02 (Series 1 규약 유지).

## 4. 통제 (7A에서 계승·강화)

- 예산 통제: 비교 기준은 세대가 아니라 **총 후보 수·총 검증 실행 수**.
- 유출 통제: 금지어 가드 유지 + 신규 개념(모드·역할)에 대한 전략
  해설 금지 — 문법 사실만 기술. 가드 목록은 파일럿 전 동결.
- 문법 통제: 파싱→검증→한도 검사, 무효도 예산 차감 (7A 동일).
  자동 수선 없음 (사전 등록).
- 평가자 독립: 제안자는 검증 seed·개별 인스턴스 성과를 보지 못한다
  (집계·익명 궤적만 — 7A 동일).
- 실행 인프라: genesis/loop의 Runner + Registry (재개 가능, 계보
  감사 자동화). 실행기 rng는 인스턴스 키만 사용 (실험 6 교훈).

## 5. 절차 (동결 확정 사항)

1. ~~DSL 확장 구현 + 실행기 의미론 테스트~~ (완료, 테스트 8종)
2. ~~탐색 공간 산출~~ (342,280 → 69,058,800)
3. ~~끌개 검증~~: 전면 공유(시조) 검증 score **0.3702** / 전면 억제
   (교착 이식) **0.5057** — 억제가 공유를 이기는 함정 구조 성립.
   전면 공유 끌개 탈출은 본실험 시조 출발 런이 겸한다 (7A와 동일
   논리); 별도 탈출 런은 교착 끌개에만 배정.
4. ~~파일럿~~ (목 제공자 5검사 통과) → 본 문서 동결.
5. 본실험: 시조 출발 5군(R/Z/S/T/TM) × master seed {0..4} × 20세대
   + 교착 탈출 3군(R/T/TM) × seed {0..4} × 20세대. T와 TM을 모두
   탈출에 배정하는 이유: 7A 감사의 연산 편향(remove 0%)을 이력
   정보만으로 교정할 수 있는가(P36)가 탈출 문제에서 가장 선명하게
   갈리기 때문.
6. 판정·절제(기능 플래그별)·브리프.

비용 (프롬프트 실측 Z 770 ~ TM 1,041토큰, 실행 중 궤적 증가분 감안
평균 ~1.8k 입력): LLM 호출 = 시조 4군×5×120 + 탈출 2군×5×120 =
**3,600건 ≈ $8~12** (Haiku 4.5). 실측이 $15 초과 시 중단·보고.
예상 소요: 40런, 4~5병렬로 약 20~24시간.

## 5.5 부록: 7C 패딩 통제 (2026-08-01 등록, 실행 전 동결)

부검(브리프 2.5절)의 대안 설명 — "이력 블록의 존재 자체가 표집을
바꿨다" — 를 분리한다.

- **군 TP**: T와 동일 정보(집계+궤적) + TM 이력 블록과 **동일 길이의
  무의미 산문 패딩** (과제·시도·숫자 무관 중립 텍스트, 가드 통과).
  교착 탈출 × master seed {0..4} × 20세대. TM·T의 기존 10런은 재사용.
- **P38a (분포)**: TP의 완화 변형 분포 3지표(gain-조건 포함율, P9
  비율, 무예산-조건 비율)에서 |TP−T| < |TP−TM| 이 3지표 중 2개 이상
  — 즉 패딩은 T처럼 행동한다 → 분포 이동은 정보(점수 궤적) 때문.
  반대면 교란 설명이 이기고 "정보 기반 탐색" 주장을 강등한다.
- **P38b (성과)**: TP의 고원 돌파(최종 score > 0.80) ≤ 1/5.
- 비용: 5런 × 120호출 ≈ $1.3 추정.

## 5.6 부록: 7D 탐색 다양성 3원 비교 (2026-08-01 등록, 실행 전 동결)

7C가 남긴 질문: 고원 돌파를 만드는 것은 무엇인가 — 표집 다양성
(온도), 주의 희석(패딩), 구조적 기억(서명)?

- **군**: 기존 T(온도 1.0)/TM/TP 15런 재사용 + 신규 **T-cold**
  (T와 동일, 온도 0.3) × 5 seed, **TS**(서명-이력: 과거 후보의 변경
  규칙 서명 → 시도 횟수·최고 블라인드 점수·채택 여부 집계, 관측만
  제공) × 5 seed. 전부 교착 탈출 20세대.
- **P39a (온도 방향)**: T-cold는 T 대비 완화 변형의 gain-조건
  포함율이 낮거나 같고 돌파 0/5 — 표집 다양성 축소가 앵커링을
  심화한다는 방향 예측.
- **P39b (서명의 구조 가치, P36 재시험)**: TS는 TP 대비 **중복
  제안률 ≥30% 상대 감소** — 서명이 있어야 구조 회피가 가능하다는
  원래 가설의 공정한 재시험.
- **P39c (성과 해석 등록)**: TS 돌파율 ≥ TP이면 서명 정보는 무해
  이상; TS < TP이면 내용이 앵커를 재도입(점수 고착)한 것으로 해석.
- 길이 한계 명시: TS 블록 길이는 TP 패딩과 다를 수 있음 — 사후
  길이를 보고하고, 길이-매칭 재통제는 결과가 애매할 때만 추가한다.
- 비용: 10런 × 120호출 ≈ $2.6 추정.

## 5.7 부록: 7D-2 온도 게이트 (2026-08-02 등록, 실행 전 동결)

7C·7D가 남긴 질문: TP(무의미 패딩)의 돌파 4/5는 **단순 샘플링
디코릴레이션**으로 재현되는가? 온도 0.3은 다양성을 붕괴시켰다
(P39a) — 반대 방향(온도 상승)이 패딩과 같은 효과를 내는지 확인한다.

- **군**: T 조건 그대로 **T-hot13**(temperature 1.3) / **T-hot15**
  (temperature 1.5) × master seed {0..4} × 20세대 교착 탈출. 비교
  기준은 기존 T(1.0)·TP·T-cold(0.3) 재사용. 다른 변경 없음 (같은
  프롬프트·예산 120후보·모델 Haiku 4.5).
- **돌파 기준**: 최종 검증 score > 0.80 — P38b 정의 그대로 유지.
  기록 사항: 이 임계값은 T·TM 관측 후 등록됐으나 (0.7915, 0.8488)
  전 구간에서 기존 군 판정이 불변임이 감사로 확인됨 (2026-08-02).
- **지표**: 돌파율, 무효 후보율, 중복률, gain/P9/무예산 공동분포,
  score≥0.84 후보 수 — 전부 `report7cd.py`(커밋됨, 브리프 재현
  검증 통과)로 계산. 사후 계산 스크립트 부재 문제의 재발 방지.
- **P40a (필요조건)**: 디코릴레이션 가설이 맞다면 온도 상승은
  중복률을 T(0.885) 대비 유의하게 낮춰야 한다 (TP 0.783 방향).
  중복률이 안 떨어지면 온도는 이 프롬프트에서 표집을 못 흔드는
  것 — 돌파 해석 이전에 조작 실패로 기록.
- **P40b (해석 등록)**: T-hot 돌파율 ≥ 3/5 → TP 효과는 온도만으로
  재현 가능 — "패딩 특수성" 해석 강등, 병목은 순수 표집 다양성.
  T-hot 돌파율 ≤ 1/5 이고 중복률은 하락 → 디코릴레이션만으로는
  부족 — 패딩의 효과는 앵커 희석(프롬프트 구성) 경로로 남는다.
  2/5는 판정 유보 (n=5 한계 명시).
- **무효율 감시**: 온도 1.5에서 문법 붕괴(무효율 급증)가 나면
  해당 군은 "탐색 다양성"이 아니라 "문법 파괴" — 무효율 > 0.3이면
  돌파율 해석에서 제외하고 그 사실 자체를 결과로 보고.
- 비용: 10런 × 120호출 ≈ $2.6 추정. 실행 순서: Rookery §6.12
  이후 병렬 저비용 레인.

**실행 불가 기록 (2026-08-02, 등록 당일)**: 첫 호출에서 API가
`temperature: range: 0..1`로 400 거부 — Anthropic Messages API는
온도 1.0 초과를 지원하지 않는다. 등록 시점에 API 파라미터 범위를
확인하지 않은 것은 설계 오류로 기록한다 (P10·P16·P30 계열의
판정식 오류와 같은 부류 — 실행 전 기계 검증 대상에 API 제약도
포함해야 함). 과금·데이터 없음 (400은 무과금, 레지스트리 잔여물
삭제). **P40은 이 API에서 온도 축으로 검정 불가** — 온도 1.0이
곧 상한이라 "디코릴레이션 강화" 방향의 표집 조작이 존재하지
않는다 (top_p·top_k는 다양성 축소 방향만 가능). 대체 조작의 선택
(예: 후보별 상이 패딩, 이종 모델 혼합)은 새 설계 등록이 필요하므로
보류하고 사용자 판단으로 넘긴다.
