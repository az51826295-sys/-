# 시행착오학습 — 전체 계획 (2026-09-11, 두근도트 출시 전)

한 회차 = 읽기 → 내 생각 → 엔진에 박기 → **같은 일을 다시 시켜 자로 재기** → 확인된 것만 ✅ → 기록.
09-09 이후 두근도트 회차(30~34번, 64~68회차)로 배운 것 셋이 이 계획의 전제다:

1. **형용사는 자를 못 견딘다** — "편하게", "지어내지 마라" 는 안 지켜졌다. 숫자·문·구조로 바꿔야 산다.
2. **회복되는 고장은 오류 자리에 안 남는다** — 라우터가 살려 놓으면 돈에만 남는다. 재는 곳을 비용·원장·표에 둔다.
3. **자도 틀린다** — "..." 를 문장 끝으로, 살색을 스웨터로, 체크무늬를 배경으로 셌다. 자를 먼저 시험하고, 못 잰 것은 못 잼으로 적는다.
