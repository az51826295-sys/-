**판정(이 순서로, 앞이 이기면 끝)**: ① 기계 문법 검사 통과 여부 ② 유니티 검사 통과 수(같으면 무승부) ③ 합격 기준 지킴 수 ④ 값(장부 cost_usd, 캐시 적중 포함) ⑤ 걸린 시간.
**기록**: 모델·토큰(입력/캐시/출력)·값·초·검사 결과·파일 수. 라우터가 gpt-5 로 올라갔으면 그것도 적는다(그러면 A 의 값은 둘의 합).

**결과 (22:33~22:48)**

| | A 딥시크 v4-pro(생각) | B gpt-5 |
|---|---|---|
| ① 기계 문법 검사 | 통과 | 통과 |
| ② 유니티 검사 | 통과 4 · 실패 0 · 해당 없음 2 | 통과 4 · 실패 0 · 해당 없음 2 |

**덤으로 본 병**: 합격 기준이 판마다 누적돼 183개(계획 입력 17k 토큰의 대부분). 이번 주문과 무관한 기준까지 매번 다시 평가한다 → 기준을 **이번 주문에 걸리는 것 + 게임 공통 10개**로 줄이면 계획 값이 1/3 이 된다.
**정직하게 남긴 것**: B 는 실험용 업무 사본으로 돌려 대화에는 안 붙였다(취소로 표시). 한 판씩이라 표본 1 — 같은 결론을 주장하려면 세 판은 더 필요하다.
