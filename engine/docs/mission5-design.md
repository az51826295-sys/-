# 실험 5 설계 — I-v2: 분산 사회의 조정 기능 학습 (사전 등록)

작성일: 2026-07-30. 상태: 사전 등록 완료, 구현 진행.

핵심 질문: *중앙 코디네이터 없이, 개체들이 경험을 통해 E의 조정
기능(전역 최선 선택)을 스스로 획득할 수 있는가?*

전제 (실험 4 확정): C의 실수율은 상수이고 실패는 실수의 비가역성에서
온다. 즉 분산 협력의 개선 지점은 "더 똑똑한 단서 평가"가 아니라
**약한 단서가 발언권을 얻는 것을 막는 것**이다.

## 1. I-v2 프로토콜 — 하강 문턱 양보 (decentralized argmax 근사)

한 번의 발언권(경매 사이클)마다:

1. 각 개체는 로컬 계산: 자기 최선 단서의 상대 이득
   r = 1 − |생존(보드∪단서)| / |생존(보드)|
2. 셔플 순서로 순회하며 **r ≥ τ이면 발언, 아니면 양보**
3. 전원 양보 시 τ ← τ×0.6으로 낮추고 재순회 (최대 6회, 이후 강제 발언)
4. 발언은 공개이므로 모든 개체가 실현 이득 r을 관찰 → 통계 갱신

**학습되는 것** (경험 통계, 프레임워크 없음):
- 실현 이득 분포 (공개 관찰의 경험 분위수)
- 공유 1회당 평균 로그 감소율 → **추정 필수 공유 수** = ln|생존| ÷ 평균
  → **추정 여유율** = 남은 예산 ÷ 추정 필수 수

**문턱 정책**: τ = 이득 분포의 분위수, 분위 레벨은 추정 여유율 버킷으로
결정 — tight(<1.3): 0.75분위(강한 단서만), mid(<2.0): 0.5, loose: 0.25.
"선택권 보존 가치"의 구현: 빠듯할수록 약한 공유가 예산을 태우지 못한다.
미학습(cold start) 문턱: (0.5, 0.25, 0.1) 고정값 + 사전 감소율 0.7.

개체는 여전히 자기 단서만 알고, 관찰은 공개 정보뿐 — 중앙 없음.

## 2. 실험 조건

- 과제: medium 20 seed (실험 4와 동일 인스턴스·최소 증명 집합)
- **고정 slack {1.25, 1.5, 2.0}** — 실험 4의 교훈: 여유율을 통제하지
  않으면 학습 효과와 여유율 효과가 혼입된다. C가 실패하는 구간만 사용
  (2.5+는 전 군 만점이라 무정보)
- 훈련: 인스턴스 30개(seed 1001~1030), slack 3종 순환, 통계 온라인
  갱신. 시험: 통계 동결, 미학습 seed 1~20
- 군: C(기준선), E(천장), **I2_untrained**(프로토콜만), **I2_trained**
  (프로토콜+학습). I-v1은 실험 3에서 충분히 약함이 확인되어 제외

## 3. 사전 등록 가설 (P16~P19)

- **P16 (학습된 사회가 C를 이긴다)**: slack 1.25와 1.5 각각에서
  I2_trained 정확도 > C가 13/20 이상.
- **P17 (격차 봉합)**: slack 1.25~1.5에서 I2_trained가 E−C 격차의
  50% 이상을 봉합 (평균 기준).
- **P18 (천장 유지)**: I2_trained ≤ E (전 slack 평균). 넘으면 그것대로
  보고하나 예측은 미만.
- **P19 (프로토콜 기여와 학습 기여의 분리 — 가짜 창발 통제)**:
  (a) 프로토콜 기여 = I2_untrained − C, (b) 학습 기여 = I2_trained −
  I2_untrained를 각각 보고. **"사회가 조정을 학습으로 획득"** 주장은
  (b) > 0이 tight slack에서 유의(13/20 이상 seed에서 ≥)할 때만 허용.
  (a)만 크면 그것은 설계의 공이다.

## 4. 핵심 기제 지표 — 조정 충실도 (coordination fidelity)

공유마다 실험자 텔레메트리로 전역 최선 감소를 계산(개체는 모름),
**충실도 = 실제 발언이 전역 최선과 같은 감소를 낸 비율**.
E = 1.0 (정의상), C = 낮음 (측정). I2가 C→E 사이 어디까지 오는지가
"argmax를 분산으로 재발명했는가"의 직접 측정치다. 부가: 훈련 곡선,
유일해 도달 공유 수, 강제 발언 비율.
