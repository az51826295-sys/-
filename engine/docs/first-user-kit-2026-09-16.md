# 첫 사용자 한 명 — 건네줄 것 (2026-09-16)

사장님과 정한 다음 한 걸음: **돈 받지 말고, 진짜 사람 한 명에게 진짜 일을 시키게 한다.**
그 사람이 "이건 별로" 라고 말해 주는 순간 지금 막힌 것 셋이 동시에 풀린다 — 예측 진화(사람 판정 0건), 심판자(정답 없음), 모델 배치표(근거 없음).

**정문도 한국어로 바꿨다(140회차).** 그때까지 정문은 영어였다 — 패들 심사자가 보는 페이지였기 때문인데, 패들은 거절했고 지금 이 주소를 볼 사람은 **사장님이 링크를 건넬 한국 학생**이다.

**먼저 확인했다(135회차):** 새 사람이 가입해서 결과물을 받는 길이 **실제로 끝까지 돈다.**
시험 계정으로 진짜 서버에 로그인해 한 문장을 보냈더니 회사 자동 생성 → 체험 크레딧 $1 → Vid 고용 → **4분 20초 뒤 68.8초 영상**이 나왔다. 판값 $0.226.

## 2. 첫 주문서 (그대로 쳐 보라고 하면 됨)

셋 중 그 사람한테 제일 쓸모 있는 것 하나.

**A. 발표·수행평가용 영상**
```
'<주제>' 60초 설명 영상 만들어 줘. 고등학생이 보는 거고, 말투는 해요체로.
```

**B. 유튜브 영상 정리**
```
이 영상 정리해 줘. <유튜브 링크>
말한 사람 말 그대로 인용하고 몇 분에 나온 말인지 같이 적어 줘.
```

**C. 긴 글 요약 + 출처**
```
이 글에서 핵심 주장 다섯 개만 뽑아 줘. <링크 또는 붙여넣기>
각 주장이 원문 어디서 나왔는지 꼭 같이 적어 줘.
```

**A 가 제일 안전하다** — 서버에서 끝까지 돌고, 링크가 막혀 있을 일이 없고, 결과가 눈에 보인다.

## 3. 결과를 받은 뒤 물어볼 것 (이게 진짜 목적)

파일보다 **이 대답**이 우리에게 필요한 것이다. 세 개만 묻는다.

1. **그대로 쓸 수 있나, 손봐야 하나?** (예 / 아니오 — 이 한 글자가 사람 판정 1호다)
2. **제일 이상한 곳 하나만 꼽으면?**
3. **이걸 또 쓸 것 같나?**

2번 답을 그대로 대화창에 치면 로키가 그 부분만 다시 만든다. **그 왕복이 도는지가 진짜 시험이다.**
