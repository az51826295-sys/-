### 오늘 실제로 배운 것 셋

1. **순응은 예시가 만든다.** 예시 0개 0.018 → 1개 0.836 → 3개 0.909.
   첫 예시 하나가 거의 전부다(d01 = +0.82, d13 = +0.07). 스펙 문장도 효과가
   있지만(spec_helps, d=+0.49) **가르치는 것이 다르다** — 문장은 `stroke-width`
   같은 단일 값, 예시는 끝모양·이음새·격자 같은 **습관**.
2. **우리 측정이 정밀도를 부풀리고 있었다.** 한 호출의 후보 6개는 통과·탈락이
   같이 간다. 후보를 표본으로 세면 구간이 2.1배 좁아 보이고, 그 부풀림이 낮의
   0.0077 미달을 만들었다. 이제 호출 단위로 잡는다.
3. **판정식이 구조적으로 못 답하는 영역이 있다.** 다양성의 참값이 문턱 사이
   (0.50~0.80)에 있으면 표본을 아무리 늘려도 판정이 안 선다. 돈으로 못 푼다.

### 정직하게 남긴 것

- **다양성 Q1은 판정 없이 닫는다.** 대신 잰 값: 다시 부를 때 새 구조가 나올
  확률 ≈ 0.5 → **새 아이콘 하나당 생성 후보 약 2개, 약 $0.002.**
  비싼지는 사업 문턱이고 사장님 몫이다(§2-B).
- **회차 간 변동이 크다.** 같은 설정의 통과율이 오늘만 0.385 / 0.018 / 0.491.
  점추정 하나로 제품 이야기를 하면 안 된다.
- **격자·끝모양은 아직 절반이 떨어진다**(with_spec에서도 grid 41, linecap 31).
  스펙도 예시도 다 준 상태에서 남은 실패다.
- 문턱 6건 미동결, 취향 심판 없음(human_gate), 한 달 자율작업 실증 없음 —

## 5. 최종 계획 되새김 (표류 방지)

### 북극성

우리 AI는 pass/fail 심판을 넘어 **연출가**로 간다. 예쁜 걸 *만들지* 않고, 사람의
창작 방향을 받아 생성 AI들을 지휘해 **설계도에 맞는 것만 선별·조립**한다.
심판 질문이 *"절대적으로 좋은가"*(심판 없음)에서 **"사장님이 정한 설계도에
맞나"**(심판 생김)로 바뀌는 것이 이 제품의 전부다.

시작 순서: ① 선택지로 취향 수집 → ② 기간+품질바를 레퍼런스로 고정 →
③ 설계도 승인 → ④ 한 달 자율작업. 첫 산출물은 게임이 아니라 **설계도**.

### 지금 어디까지 왔나

| 층 | 상태 |
|---|---|
| 심판이 심판인가(이빨) | 섰다 — real 11건 전부, 반례 50+ |
| 심판이 설계도를 읽는가 | 섰다 — 채점 10건 전부 1.00 |
| 심판이 스펙을 정확히 집행하는가 | 섰다 — 골든 GO + **두 번째 구현 505표본 일치** + 경계 7축·열거 5축 정확 |
| **무엇이 순응을 만드는가** | **섰다(오늘 밤)** — 예시 D=+0.89, 스펙 d=+0.49 |
| 하드 스펙 자산 심판 | 아이콘·픽셀아트·음악 일부 |
| 계측기 | 오디오 6칸, 이미지 특징 10, 래스터 3칸 — 문턱 6건 **미동결** |
| **취향이 기계 심판이 되는가** | **안 섰다** — 2회차 NO-PROMOTE, 천장 미측정(A) |
| 설계도 엔진 | v0 — 분해기 계약 1.0, 되묻기 사유 선언 계약 추가 |
| 한 달 자율작업 | **아직 없음** |

### 비어 있는 칸

1. **취향 → 기계 심판.** 이 라인의 핵심 베팅. A(천장)를 모르면 판정이 무의미하다.
2. **문턱 6건.** 계측기는 있는데 판정이 없다.
3. **설계도 엔진의 자유 문장 이해.** 지금은 별칭 substring. LLM Proposer가 다음 층.
4. **한 달 자율작업의 실증.** 오늘 것도 전부 계측기·통제·심판이다.

**표류 경고(어제와 같음, 강도는 낮아짐)**: 오늘 밤은 계측기를 늘린 게 아니라
**우리 측정 방식의 결함을 잡고 확정 판정 둘을 세웠다.** 그래도 사장님이 사려는
것은 여전히 **설계도대로 한 달 굴러가는 것**이다. 위 1·2가 계측기보다 먼저다.

# 08-27 오전 갱신 (08:1x) — 밤 계획이 두 군데 바뀌었다

밤에 세운 계획(§2·§3)을 오전 결과로 갱신한다. **바뀐 것 둘**:
티어 질문이 닫혔고, 사장님이 "실험을 끄지 말라"는 상시 규칙을 주셨다.

## A. 오전에 닫힌 것

| 물음 | 답 | 근거 |
|---|---|---|
| 돈을 더 쓰면 규격이 나아지나 | **그렇다** | `tier_helps` — haiku 0.276 → opus 0.972 (예시 0개, 호출 18씩) |
| 통과분당 값도 비싼가 | **거의 같다** | $0.0035 vs $0.0051 — haiku가 4분의 3을 버려서 |
| 눈에도 보이나 | **싼 티어는 보인다** | 블라인드 31선택 중 haiku **0개**(기대 3.66, p=0.025) |
| sonnet vs opus | **구분 안 됨** | p=0.69 |

**그래서 남은 것은 라우팅 결정 하나다**(§B-1). 기계가 답할 부분은 다 답했다.

|---|---|---|---|
