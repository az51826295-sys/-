## 확인된 사실 (전부 실측)
- **DB 는 살아 있다.** 402 는 API 층에만 걸림. 대시보드 **SQL 편집기는 돈다**
- 데이터 크기: `auth.users` **22명** · `dot_messages` **695줄** · 공개 표 **15개**
- 스토리지 `dot-sprites` **151장 · 783 kB** (스토리지 API 는 402 라 못 꺼냄)
- 로컬 그림: 백업 4명(yuna·seoha·rin·doyun) 18장씩 + 시트 3명(nabi·haru·yeonu) 얼굴만
  → **나비·하루·연우의 몸 그림과 멘헤라 몸·피드 사진이 빠진다**(27일에 채울 것)
- **스키마는 저장소에 있다**: `supabase/schema_dot_*.sql` (chat·money·posts·push·turns)
- 무료 프로젝트는 **계정당 2개**가 한도 → 로키를 pause 해야 자리가 난다

## 데이터 꺼내는 법 (통하는 것 확인함)
대시보드 SQL 편집기에서 표마다:
```sql
select json_agg(t)::text as j from <표이름> t;
```
결과 칸 하나에 **전체 JSON 이 다 들어온다**(실측: dot_characters 26,263자를 통째로 읽음).
브라우저에서 `[role=gridcell]` 의 textContent 로 읽으면 잘리지 않는다.
