## 10-24 에 밟을 길 (두근도트에서 실제로 해 본 순서)

1. 대시보드 → **프로덕션 신청** — 비공개 테스트에 관한 질문에 답한다(아래 초안)
2. 승인 뒤 → 비공개 테스트 트랙에서 **버전 승급 → 프로덕션**
3. **국가/지역** 탭 → 전체 선택 → 저장 (두근도트는 178개국이 잡혔다)
4. 출시 탭 → **버전 수정** → 출시 노트 입력 → 다음 → 저장
5. **게시 개요 → 검토를 위해 제출** — 제출 전에 **변경사항 목록을 반드시 읽는다**
   (두근도트 때 내가 모르는 변경 1개가 큐에 있었다. 열어 보니 사장님이 바꾼 앱 아이콘이었다)

막히는 자리: 콘솔이 무겁다. 탭이 멈추면 **탭을 닫고 새로 연다** — 그러면 풀린다.

## 프로덕션 신청 답변 초안 (사장님 확인 뒤 제출)

구글이 비공개 테스트에 대해 묻는다. 사실만 적는다 — 꾸미면 반려된다.

- **테스터를 어떻게 모았나**: 구글 그룹(`az51826295`)에 가입한 지인·커뮤니티 테스터 12명.
  들어오는 길을 안내하는 페이지를 따로 만들어 링크로 돌렸다.
- **무엇을 배웠나 / 피드백**: ← **사장님만 쓸 수 있는 칸.** 테스터가 실제로 한 말을 적어야 한다.
  내가 지어내면 거짓이 된다. 한두 줄이라도 실제 말로 주시면 제가 문장으로 다듬는다.
- **무엇을 고쳤나** (내가 쓸 수 있는 사실):
  - 잿빛: 폰에서 꾹 누르면 그림 메뉴가 게임을 덮던 것을 고침(10-17)
  - 잿빛: 구간마다 전투 배경을 넣음, 그림 없이 돌던 칸 30개를 채움(10-11)
  - 잿빛: **게임 전체를 영어로** 옮김 — 전투 글·기술 설명·가방·대장간까지(10-24).
    자(`ash_전세계화`)로 화면 9곳을 재서 남은 한국어 **0자**를 확인했다(10-24 전엔 5,650자였다)
  - 로키: 전송량 폭주를 잡아 서버가 멈추던 원인을 제거(10-20)
