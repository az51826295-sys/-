# 넷째 조각 "배우는 자" — 계획 (2026-11-27, 사장님 "해")

## 왜

있는 셋: **생성자**(만든다) · **판단자**(잘됐나 본다) · **예측자**(하기 전에 맞혀 본다).
빠진 것: 판단이 틀렸거나 예측이 빗나갔을 때 **생성자의 방식을 실제로 바꾸는 자리**.
지금은 사장님과 Claude 가 손으로 한다 — 11-27 걷기가 그랬다:
사장님 "절뚝거려 · 몸이 사라짐 · 전이 좋아" → Claude 가 원인 찾고 방식 바꿈 → "마법사는 지금 방식, 기사·왕은 전".
이 고리를 기계가 돌게 만드는 게 넷째 조각이다.

사장님 큰 계획: **넷을 합친 뒤 인터넷에 던져 놓고, 사람들의 반응으로 배운다.**
막힌 곳 하나: **쓰는 사람이 0명**(스레드 첫 글에서 고백한 그대로). 배우는 자는 반응을 먹고 자란다 → 반응이 없으면 배울 게 없다.
제네시스 규칙 고리가 씨앗이지만 "굶고 있었다"(규칙 18개 중 11개가 어긴 사례 0건).

## 순서 (앞이 끝나야 다음)

### 1. 작게 — dugeundot.com/pixel 에 먼저 붙인다
이미 인터넷에 있고, 장부(`dot_purchases`, sku `pixel_use`)에 "언제 무엇을 어떤 방식으로 만들었나"가 이미 쌓인다.

**지금 없는 것(만들 것)**
- [ ] **반응 기록**: 받기 단추는 브라우저 안 data URL 이라 서버가 모른다. → 작은 기록 칸(`pixel_events`: 결과 id · 방식(ref) · 사건 = 받음/다시 만듦/그냥 나감 · 시각). 개인정보 없음(계정 id 만).
- [ ] **판정 읽기**: 받음 = 받아들임, 같은 그림으로 바로 다시 = 물림, 아무것도 안 하고 나감 = 모름. (로키 `genesis/implicit.ts` 와 같은 틀 — 사람 말이 아니라 행동에서 읽는다)
- [ ] **고르기**: 그림의 특징(망토 자 · 대칭 · 다리 틈 · 비스듬함) × 방식(머리만+다리 뒤집기 / 4장 그대로 / 꼭두각시 / 8장) 별 받아들임 비율. 판이 쌓이면 **새 그림에 가장 잘 받아들여진 방식을 고른다**.
- [ ] **나란히 시험**: 배우는 자가 고른 방식 vs 지금 기본 방식을 손님에게 반반 — 고른 쪽이 받아들임 비율로 **이길 때만** 기본으로 남긴다.

**잠근 판정식(숫자 보기 전에 얼림)**
- 한 방식이 "낫다" = 같은 특징 묶음에서 받아들임 비율이 기본보다 높고, 양쪽 각 **20판 이상**.
- 20판 안 되면 "모름" — 바꾸지 않는다.
- 사장님 투표(11-27: 마법사=머리만+다리 뒤집기, 기사·왕=전)는 첫 씨앗 3판으로 넣되 출처 `owner` 로 따로 센다.

### 2. 사람을 데려온다 — 로키 엔진이 한다 (사장님 11-27 "홍보도 로키 엔진이 할 수 있어")
홍보도 같은 고리로 돈다: **생성자**가 글·전/후 영상 초안을 만들고 → **판단자**가 규칙(방식·라이벌 이름 노출 X, [[promo-hide-how-its-made]])을 보고
→ **예측자**가 "이 글이 몇 명 데려올까"를 올리기 전에 적고 → 올린 뒤 `?from=` 꼬리표(`dot_from_count.mts`)로 실제로 온 수를 센다
→ **배우는 자**가 예측과 실제의 차이로 다음 글의 방식(무엇을 보여 주나·언제·어디에)을 고른다.
- **올리는 단추는 사장님 손**: 공개 글은 매번 글 내용에 사장님 OK. 엔진은 초안·시각 추천·세기까지.
- 1번이 먹을 게 생기려면 하루 몇 판이라도 손님 판이 있어야 한다. 목표 숫자는 사장님 것.

### 3. 넷을 합친다
생성 → 판단 → 예측 → 배움 이 **도트에서 한 고리로 도는 걸 확인한 뒤** 로키 전체로 넓힌다.
"확인" = 배우는 자가 고른 방식이 나란히 시험에서 한 번 이상 이김.

## 지킬 것 (안전)
- 인터넷 반응으로 스스로 바뀌는 AI 는 엉뚱한 걸 배우기 쉽다.
  → 배우는 자는 처음엔 **방식 고르기·규칙 숫자만** 바꾼다. **코드는 못 건드린다.**
- 스스로 바꾼 건 늘 옛 방식과 나란히 재서 이길 때만 남는다(못 이기면 되돌림).
- 기록에 그림 원본·개인정보를 안 남긴다(방식·특징·사건만).
- 돈 드는 시험은 값을 말하고 OK 받은 뒤 한 판.

## 첫 조각 (돈 0)
`pixel_events` 기록 칸 + 받기 단추·다시 만들기·나감 세 사건 + 매일 세는 도구(`engine/work/realdot/motion/learn_tally.mts`).
