## 사용자가 "시작"이라고 말하면 (7일 무인 본시도 게이트)

2026-08-12 기준 대기 중인 단 하나의 게이트다. 48시간 드라이런은
3차 시도에서 통과했다 (docs/unattended-ops-rules.md §8). 사용자가
**"시작"**이라고 말하면 = **7일 무인 본시도를 이 기계에서 착수**
하라는 뜻이다. 절차:

1. `git pull` (레지스트리 최신화 — 이 파일이 보인다면 이미 됨)
2. `ai-workspace 키 확인`: `C:\Users\az518\Desktop\ai-workforce\.env.local`
   에 `ANTHROPIC_API_KEY=` 줄이 있는지
3. 실행: `wscript tools\soak7d_launch.vbs` (무창, 7일 = 604800초,
   로그 `data/soak7d_console.log`)
4. 시작 배너("실 시작 - 168.0시간")와 첫 틱을 확인하고, 시작
   시각을 docs/unattended-ops-rules.md에 기록·커밋·푸시
5. **이후 사람도 Claude도 관찰만 한다** — 설정·프롬프트 변경 금지,
   개입 = 시도 종료. 승인 큐 항목은 기간 동결 (적체는 관찰 지표).
   매일 자동 기록이 `rookery-dryrun/data/dryrun_daily_*.json`에
   쌓인다.

주의: 이 게이트는 원래 **데스크톱**용이다 (노트북은 WinError
10055 소켓 고갈 기지 결함 — unattended-ops-rules.md §7). 노트북
에서 "시작"이 들어오면 데스크톱 여부를 한 번 확인하라.

- 실험은 사전 등록 후 실행, 숫자 확인 전 판정식 동결
  (docs/의 *-design.md 패턴). 계측기 사고 시 즉시 정지·격리·수정.
- 지출 경로는 `GENESIS_SPEND=i-approve` + 예산 원장 필수.
  새 파이프라인은 목(mock) 파일럿 통과 전 실 API 금지.
- 장부·출처 레코드는 제안기 프롬프트에 주입하지 않는다
  (docs/provenance-contract.md 계약 8항).
- 진행 기록은 docs/progress.md, 커밋·푸시는 작업 단위마다.

## 실험을 끄지 않는다 (2026-08-27 사장님 지시, 상시)

> "절대 실험 같은 거 종료하지 마"

돌고 있는 실험·실행·게이트를 **내 판단으로 중단하지 않는다.** 비용이 예상보다
크든, 계측이 오염돼 보이든, 결과가 뻔해 보이든 마찬가지다.

계측이 잘못된 것을 발견하면 **끄는 대신**:

1. 끝까지 돌린다.
2. 그 회차를 **무효로 기록**한다(무엇이 왜 오염됐는지, 지출까지).
3. 고친 설정으로 **새 회차를 등록**하고 다시 돌린다.
4. 사장님께 둘 다 보고한다.

중단은 **사장님이 "꺼"라고 하실 때만** 한다. 예산 상한에 걸려 API가 스스로
거부하는 것은 중단이 아니다(그건 안전장치가 일한 것이고, 그대로 둔다).

**왜**: 2026-08-27 07:2x에 티어 비교를 sonnet 잘림을 이유로 2분 만에 껐다.
판단 자체는 맞았지만(그대로 뒀으면 결론이 뒤집혔다) **끄는 것은 내 몫이 아니다** —
돌아가는 것을 죽이면 사장님이 볼 수 있었던 자료가 사라진다. 오염은 기록으로
처리할 수 있고, 죽인 실행은 되돌릴 수 없다.

## 매일 마무리 (2026-08-25 사장님 지시, 상시)

사장님이 "오늘 그만"·"마무리" 계열로 하루를 닫으면 **항상 이 셋**을 한다.
기계가 바뀌어도 유지돼야 하므로 여기 둔다.

1. **그날 결산** — 무엇이 바뀌었나(커밋 목록·시각), 숫자 추이(전/후),
   심판이 실제로 잡은 것, **정직하게 남긴 것**(미측정·미동결·미결합).
2. **다음날 계획** — `docs/plan-YYYY-MM-DD.md`로 저장·커밋·푸시(노트북 동기화).
   사장님 결정 대기 항목과 내 착수 가능 작업을 **분리**해 적고, 어느 결정이
   가장 많이 풀어주는지 표시한다.
3. **최종 계획 되새김** — 북극성(docs/director-ai-vision.md)을 다시 적고,
   **지금 어디까지 왔는지와 비어 있는 칸**을 명시한다. 표류 방지용이라
   생략하지 않는다.

보고에는 항상 시각·소요를 붙인다. 오래 걸리는 작업은 "HH:MM 시작, N분 경과".
