# 고사양 — WebGL 3D (228회차 10-01)

사장님 "다른 고사양 게임 만들어봐".

## 왜 WebGL 인가

브라우저에서 "고사양" 은 **2D 캔버스를 벗어나는 것**이다. 지금까지 만든 것은 전부 `getContext('2d')` 였다 —
벽돌깨기·두더지·플랫포머·타워 디펜스 24판이 다 그랬다. 3D 는 **한 번도 없다.**

게다가 **라이브러리를 못 쓴다.** 판은 바깥 요청이 막힌 창에서 돌아서 three.js 를 불러올 수 없다
(꾸러미로 넣을 수도 있지만 600KB 라 프롬프트가 터진다). 그러니 **셰이더와 행렬을 직접 짜야 한다** —
여태 시킨 것 중 가장 어려운 일이다.

— 그리고 고리는 "화면이 안 바뀐다" 만 보고 왜 그런지는 모른다.
