로키 소개

회사: 권혁수

로키를 처음 접하시는 분들께 핵심만 간단히 안내드립니다. 회사명은 권혁수입니다.

로키 한눈에

  • 제품명: 로키
  • 회사: 권혁수
  • 개발 도구: Unity 6
  • 렌더링: URP
로키는 우리 제품 이름입니다. 현재 개발 전반은 Unity 6와 URP 환경을 사용합니다.

글꼴 호환성

  • LegacyRuntime.ttf 사용
  • Arial.ttf는 Unity 6에서 불가
  • 씬 빌드 시 예외 발생
  • 두 차례 중단 사례 있음
Unity 6에서 Arial 내장 폰트가 폐기되어 씬 생성 시 예외가 발생했습니다(2026-08-29 포함, 두 차례). LegacyRuntime.ttf로 교체합니다.

플레이어 교체

  • Vox 사실적 남성 캐릭터
  • 폴더: 20~30대 사실적인 남성 캐릭터
  • 예전 사실적_남성 폴더 미사용
기존 캡슐 대신 Vox의 4K 자산을 사용합니다. 새 폴더만 사용하고 예전 폴더는 쓰지 않습니다.

애니메이션 규칙

  • WASD 걷기
  • Shift 달리기
  • 이동 방향 바라보기
  • 정지 시 서 있기
입력에 따라 걷기·달리기 전환, 방향 정렬, 정지 시 대기 상태를 유지합니다.

임포트·Animator

  • 임포트 설정을 스크립트로
  • Animator 컨트롤러도 스크립트로
  • 재질 생성은 Lit/Tint/Surface 사용
임포트와 Animator 구성은 수동이 아닌 빌더 코드로 일괄 구성합니다. 재질 생성 지점은 도우미 함수를 강제합니다.

재질·파티클

  • forceMatte 금지
  • _Smoothness=1, _GlossMapScale=1
  • 금속·노멀 맵 적용, Metallic 유지
  • 파티클은 적용 전 Stop
기사 재질은 매트 강제 금지, Smoothness/GlossMapScale=1, Metallic 값 유지, 금속·노멀 맵 적용이 원칙입니다. 파티클에는 재질 적용 전에 Stop을 호출합니다.
