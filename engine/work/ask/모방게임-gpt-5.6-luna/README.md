# ORBITAL INTERCEPT

브라우저에서 실행하는 단일 파일 3D 느낌의 1인칭 웨이브 슈팅 프로토타입입니다. 외부 라이브러리나 고유 그래픽/사운드 자산을 사용하지 않고 Canvas로 도형을 그립니다.

## 시작하는 법

1. `index.html`과 같은 폴더에서 로컬 서버를 시작합니다.
   - Python 3: `python -m http.server 8000`
2. 데스크톱 브라우저에서 `http://localhost:8000`을 엽니다.
3. 게임 화면을 클릭해 Pointer Lock을 허용합니다.

## 조작

- WASD: 시야 기준 이동
- SHIFT + WASD: 가속 이동
- 마우스: Pointer Lock 상태에서 시야/조준
- 클릭 또는 SPACE: 중앙 조준 방향 발사
- ESC: 일시정지/재개
- 게임 오버 뒤 클릭: 새 게임

## 장면으로 확인할 수 없었던 부분을 정한 방식

- 격추 점수: 적 1대당 20점. BEST는 이 브라우저의 localStorage에만 저장.
- 무기: 단일 에너지 펄스, 재장전 없음, 짧은 발사 쿨다운(0.09초).
- 피격 판정: 중앙 조준점에서 48px 이내의 가장 가까운 적을 명중. 적이 화면 중앙 근처로 접근해 충돌하면 HULL 12 감소.
- 웨이브: 첫 웨이브 5대, 모두 격추하면 1.3초 뒤 다음 웨이브가 시작되며 적 수가 1대씩 증가(최대 9대).
- 웨이브 연출: 시작 후 2.8초 동안 중앙 알림을 표시하고, 이후 상단 WAVE 패널만 표시.
- 게임 오버: HULL이 0이 되면 조작을 멈추고 결과를 표시하며, 클릭하면 첫 웨이브로 재시작.
- 일시정지: 어두운 오버레이와 PAUSED / ESC TO RESUME만 표시하고 Pointer Lock을 해제.
- 피드백: 발사 시 짧은 중앙 빔, 명중 시 얇은 원형 히트마커, 피격 시 붉은 화면 플래시.
- 이동: 완전 6DOF가 아닌 수평면 이동(x/y)이며 시야 회전은 마우스로 처리. 일반 5 units/s, SHIFT 10 units/s.
- 적 AI/스폰: 적은 깊이 방향으로 접근하고 약간 좌우로 흔들린다. 충돌한 적은 같은 웨이브의 남은 적 수를 유지하도록 뒤쪽에 재배치된다.
- 점수 계산: 보너스/콤보/배율 없음.
