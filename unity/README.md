# 유니티에서 로키 자산 가져오기

1. `unity/Editor/RookeryImporter.cs` 를 유니티 프로젝트의 `Assets/Editor/` 로 복사
2. 유니티 메뉴 → **Window → Rookery → 자산 가져오기**
3. 주소와 열쇠를 넣고 **가져오기**

**열쇠**는 회사마다 하나입니다. 읽기 전용이라 이걸로는 아무것도 만들거나
지울 수 없습니다.

## 무엇이 오는가

**승인된 산출물의 통과 후보만** 옵니다. 검토 중이거나 심판이 떨어뜨린 것은
서버가 보내지 않습니다 — 게임에 들어가는 것과 매니저가 승인한 것이 같아야
하고, 그 둘이 어긋나면 승인이 절차가 아니게 됩니다.

파일마다 `.rookery.json` 이 같이 저장됩니다. 어느 산출물에서 왔고 무엇으로
통과했는지가 거기 있습니다 — 반년 뒤에 "이 그림이 어느 판정을 통과한 것인지"
를 물을 사람은 반드시 생깁니다.

## 픽셀 아트 주의

가져온 뒤 Import 설정에서:
- **Filter Mode: Point (no filter)** — 안 그러면 흐려집니다
- **Compression: None** — 안 그러면 색이 뭉갭니다
- **Pixels Per Unit** — 타일 크기에 맞춰서
