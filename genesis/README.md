# Genesis — 프로토타입 v0.2

```bash
node genesis/verify.ts   # 헌법 검증 — 위반을 시도하고 막히는지 본다
node genesis/run.ts      # 세계 시뮬레이션 — 세 에이전트 비교
node genesis/evolve-run.ts   # 자기진화 — 유전자 후보 경쟁 (약 2분)
```

의존성 없음. **모델 호출 0회. 비용 $0.**

```bash
EPISODES=20000 WINDOW=2000 SEED=7 node genesis/run.ts
REGIME_AT=0 node genesis/run.ts      # 기준이 바뀌지 않는 쉬운 세계
```

## 왜 LLM이 없는가

**세상은 지능이 아니라 법칙이다.** 세계의 물리를 결정론적 코드로 쓰면
시뮬레이션은 공짜가 되고, 시드만 같으면 언제나 재현된다. 모델은
나중에 *에이전트가 생각하는 자리*에만 꽂으면 된다.

v0.1이 증명해야 하는 건 "LLM이 똑똑한가"가 아니라

> **예측 잠금 → 오차 → 규칙 수정 루프가 실제로 도는가.**

그건 모델 없이 검증할 수 있고, 검증한 다음에 모델을 넣는 게 순서다.

`src/llm.ts`에 LLM 에이전트가 준비되어 있지만 **잠겨 있다** —
`GENESIS_SPEND=i-approve` 없이는 실행 즉시 예외를 던진다. 유일하게
돈이 드는 경로이므로 코드에서 막아 두었다.

## 세계

Rookery의 실제 문제와 같은 모양이다. 좌표와 문이 아니라 **업무와 심사**다.

| | |
|---|---|
| 상황 | 업무 종류 / 대상 독자 / 긴급도 |
| 행동 | 깊이 · 분량 · 출처 · 어조 — 4축 16조합 |
| 결과 | 승인 / 수정요청 / 반려 |
| 숨은 상태 | **심사 기준 5개. 에이전트는 절대 볼 수 없다** |
| 상호작용 법칙 | "요약이면서 **동시에** 급할 때"만 적용되는 규칙 1개 |
| 기준 변경 | 절반 지점에서 심사 기준 하나가 **뒤집힌다** |
| 환경 잡음 | 8% — 아무 잘못이 없어도 수정 요청이 온다 |

잡음 8%가 이 세계에서 가장 중요한 장치다. 이것 때문에 **예측 오차는
절대 0이 되지 않는다.** 승인률 천장은 92%이고, 거기서 더 배우려고
비용을 쓰면 그게 노이즈 TV 함정이다.

## 결과

```
                              승인률    Brier
  Blind (기억 없음)            37.6%   0.2351
  Greedy (기억만, 탐색 없음)    42.0%   0.1408
  Genesis (기억 + 호기심)      88.8%   0.1411
  ─────────────────────────────────────────
  세계의 천장                  92.0%   0.0736
```

기준 변경 지점(에피소드 2000)에서:

```
              1501-2000   2001-2500   2501-3000   3001-3500   3501-4000
  Greedy        51.4%       40.2%       41.0%       40.0%       42.0%
  Genesis       88.4%       61.2%       61.0%       85.2%       88.8%
  Genesis LP     0.01       -0.26       +0.15       -0.08       +0.10
```

**Greedy는 영영 못 돌아온다.** 기억은 있는데 탐색이 없어서, 새 기준을
발견할 데이터를 스스로 만들지 못한다. Genesis만 61% → 88.8%로 회복하고,
LP가 충격(-0.26) 직후 재학습(+0.15)으로 튀는 게 그 과정이다.

## 이 프로토타입이 실제로 증명한 것

### 1. 통제 실험이 없으면 인과를 배울 수 없다

첫 실행에서 Genesis는 **54%에서 멈췄고** 이런 규칙을 "발견"했다:

```
urgency=low :: cites=yes     → 승인률 1% (근거 702)
urgency=low :: depth=shallow → 승인률 1% (근거 702)
urgency=low :: length=short  → 승인률 1% (근거 702)
urgency=low :: tone=formal   → 승인률 1% (근거 702)
```

출처를 다는 게 나쁠 리 없다. 근거 수가 **네 축 모두 702로 같은 것**이
원인이다. 한 맥락에서 늘 같은 접근을 고르니 네 축이 항상 함께 등장하고
함께 벌을 받았다. 완전 교란(perfectly confounded)이다.

고친 것은 한 곳 — 탐색할 때 가장 모르는 조합으로 뛰어드는 대신,
**현재 최선에서 한 축만 뒤집는다.** 나머지를 고정했으니 결과의 차이는
그 축의 것이다.

```
54% → 89.6%
```

Phase 4의 "가설을 구분할 수 있는 실험"은 장식이 아니라 **인과를 배우기
위한 최소 조건**이었다.

### 2. 기억만으로는 부족하다

Greedy는 기억을 쓰지만 탐색하지 않는다. 처음 괜찮았던 방식에 갇히고,
세상이 바뀌어도 알아채지 못한다. **호기심은 취향이 아니라 필수 부품이다.**

### 3. 진화는 "더 빨리 잊어라"를 스스로 찾아냈다

29개 후보를 5개 세계에서 경쟁시킨 결과, 1세대에서 채택된 것은
`decay 0.997 → 0.98` (**+16.55%p**)였다. 세계가 도중에 바뀌는 곳에서는
오래된 기억이 자산이 아니라 독이다 — 아무도 가르쳐 주지 않았고,
세계의 구조가 그 유전자를 선택했다.

회귀 검사도 실제로 일했다: `explorationFloor 0.2`는 승인률을 +8.45%p
올렸지만 **적응력 악화로 탈락**했다.

### 4. 파라미터 진화로는 표현력 한계를 못 넘는다

구조 유전자 `pairContexts`(맥락을 쌍으로 기억)는 **채택되지 않았다**
(+2.0%p, 학습 속도 손해). 표현력이 부족해도 승인률 손해가 작으면
승인률 기반 적합도는 그걸 고치지 않는다. **적합도 함수가 재는 것만
진화한다** — 모델의 정확성을 원하면 그걸 직접 재야 한다.

### 5. 모순 큐가 변화의 진원지를 정확히 지목한다

```
audience=client :: length=short   승인률 47%  근거 1119
audience=client :: cites=yes      승인률 59%  근거 1213
audience=client :: depth=deep     승인률 68%  근거 1278
```

상위 항목이 전부 `client`다. 도중에 뒤집힌 그 기준이다. 설명되지 않는
갈림을 추적하는 것만으로 **세상이 어디서 바뀌었는지**를 찾아냈다.

### 6. 가지 않은 길에 대한 예측은 체계적으로 비관적이다

```
상상 64000건 중 채점 가능 14732건
예측 평균 0.34   실제 평균 0.55   Brier 0.1464
```

시도하지 않은 선택지를 실제보다 21%p 낮게 본다. 그리고 이건 탐색을
막는 방향의 편향이다 — 안 해본 것을 나쁘게 보면 계속 안 하게 된다.
호기심 예산이 이 편향을 강제로 뚫는 장치라는 게 여기서 드러난다.

## 헌법 검증 (`verify.ts`)

"예측은 잠긴다", "자기 채점은 불가능하다"는 문서에 적어 두면 지켜지는
게 아니다. 그래서 **실제로 위반을 시도하고 막히는지** 본다. 12/12 통과:

| 영역 | 시도하는 위반 |
|---|---|
| 예측 잠금 | 결과를 본 뒤 예측 수정 / 결과 덮어쓰기 / 유령 결과 삽입 |
| 채점권 분리 | 에이전트에 채점 메서드 존재 / 자기보고 필드 존재 |
| 상상·현실 분리 | 상상이 경험 원장에 유입 / 승격 경로 존재 |
| 진화 경계 | 헌법 수정 / 헌법 항목이 유전자에 포함 |
| 세계 무결성 | 시드 재현성 / 행동이 달라도 같은 상황 순서 |

## 구조

| 파일 | 역할 | Phase |
|---|---|---|
| `src/world.ts` | 세계의 법칙. 에이전트가 볼 수 없는 부분 | — |
| `src/ledger.ts` | **예측 원장 — 커밋 후 동결, 중복 결과 거부** | 1·2 |
| `src/memory.ts` | 의미 기억, 감쇠 망각, 모순 큐, 모름의 지도 | 2·4 |
| `src/imagination.ts` | **상상 저장소. 승격 경로 없음** | 3 |
| `src/agents.ts` | 기준선 2종 + Genesis (통제 실험·호기심 예산) | 4 |
| `src/genome.ts` | 전략 유전자 | 5 |
| `src/evolve.ts` | 샌드박스 · 독립 평가자 · 회귀 검사 · 계보 | 5 |
| `src/constitution.ts` | **동결된 불변 원칙. 유전자와 다른 파일** | 5·6 |
| `verify.ts` | 헌법 위반 시도 테스트 | 6 |
| `src/llm.ts` | LLM 에이전트 — **잠김 (유료)** | — |

`Ledger`와 `constitution.ts`가 이 코드의 헌법이다. 실제 Supabase
구현에서는 예측 불변성이 앱 코드의 약속이 아니라 **DB 제약**이어야
한다. 코드는 언젠가 잊는다.
