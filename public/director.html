Using several AIs and picking one by gut feeling every time?

Rookery Director is a judgment engine that decides which AI gets each task, and how much effort. Before the work runs it writes down and locks the probability of passing; when the result comes in, it scores itself. If the work fails it retries one tier up, and once your ledger proves a kind of task, it answers without paying for judgment at all.

Install

claude mcp add rookery-director -- npx rookery-director

The judge runs on your own OpenAI key (OPENAI_API_KEY). The ledger stays on your computer (~/.rookery/director). The only things that leave it are the judge's AI calls (your key) and, after the free tier, one license check a day with the payment provider (Polar). We run no server.

How it works

  1. Decide — give director_decide a task and a kind; it picks the AI, the effort and a pass probability, and locks them.
  2. Work — the work is done by the AI you already use. The engine never does the work itself.
  3. Record — report pass/fail with director_record. On a failure it opens a new run one tier up.
  4. Scorecard — director_scorecard shows whether the judgments were right and how much was saved.
