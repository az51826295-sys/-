# 로키 콘센트 — 쓰던 AI 를 로키에 붙이기

사장님 말: *"내가 하고 싶은 건 **연결하는 거야**."*
*"로키가 AI를 잘 다루는 AI잖아. 그 사람이 쓰던 클로드·코덱스, 2D·3D 만드는 AI랑
연결이 가능하고 **일관성을 제공**했으면 좋겠어."*

로키는 만드는 쪽이 아니다. **기준을 들고 재는 쪽**이다.
만드는 값은 그쪽 구독으로 나가고, 로키는 자만 댄다.

## 붙는 길 셋

| | 무엇이 붙나 | 값 | 상태 |
|---|---|---|---|
| ① 폴더 | **아무거나** — 웹 전용 그림 AI·블렌더·손그림, 파일로 나오는 것 전부 | 0 | 10-26 됨 |
| ② MCP | 클로드 코드·커서처럼 MCP 를 말하는 것 | 0 | **10-26 됨 (이 글)** |
| ③ BYOK | Meshy·PixelLab 처럼 API 가 있는 것 | 쓰는 사람 열쇠 | 설계 먼저 |

③ 이 막힌 이유는 열쇠가 전부 `process.env` 하나라서다 — **남이 쓰면 사장님 돈이 나간다.**

## ② MCP 가 하는 일

붙은 도구(클로드 코드 등)가 이 셋을 쓸 수 있게 된다.

| 도구 | 언제 | 무엇을 |
|---|---|---|
| `get_standard` | 만들기 **전에** | 기준을 숫자로 내준다 |
| `measure_image` | 그림을 만든 **뒤** | 맞음·어긋남·못 잼 + **잰 숫자** |
| `measure_mesh` | .glb 를 만든 뒤 | 규칙별로 같은 세 값 |

고리는 이렇게 돈다 — **기준 받기 → 만들기 → 재기 → 어긋난 숫자 보고 고치기.**
규칙만 글로 주면 어긴다. **숫자와 까닭**을 주니까 고칠 데가 보인다.

## 기준은 취향이 아니라 계약이다

```
min_colors 16 · min_saturation 25 · min_luma_spread 120 · min_ground_contrast 60
근거: 사장님이 가리킨 레퍼런스 화면 실측 (명암폭 172 · 캐릭터-바닥 대비 99)
```

근거가 **사장님이 고른 화면의 실측**이라서, 어긋남은 의견이 아니고 사실이다.

## 세 값을 끝까지 가른다

맞음(`·`) · 어긋남(`≠`) · **못 잼(`–`)**.
판정 서비스에 못 닿은 것을 "어긋남" 으로 읽으면 **멀쩡한 자산을 고치러 들어간다** —
09-30 에 그래서 세 바퀴를 헛돌았다. 그래서 `JudgeUnavailable` 은 FAIL 이 아니라 못 잼이다.

## 붙이는 법 — 끝이 둘이다

열쇠가 없으면 **문이 닫힌다**(`MCP_TOKEN` 없으면 전부 401). 남이 우리 판정 서비스를
공짜로 쓰지 못하게 하려고 그렇게 했다.

### 서버 끝 — 로키가 어디서 도나

| | 주소 | 필요한 것 |
|---|---|---|
| 지금 당장 | `npm run dev` → `http://127.0.0.1:3000` | 배포 안 기다림. `ROOKERY_URL` 을 그 주소로 |
| 배포 후 | `rookery-web-production.up.railway.app` | 아래 두 환경변수 |

Railway `rookery-web` 에 둘:
- `MCP_TOKEN` — `.keys/mcp.json` 값
- `JUDGE_URL` — `https://judge-production-3d80.up.railway.app`
  (**안 넣으면 `127.0.0.1:8000` 을 찾다가 전부 "못 잼" 이 된다.**)

### 쓰는 끝 — 클로드 코드

`.mcp.json` 을 클로드 코드로 여는 폴더에 두면 된다(이 저장소엔 이미 있다).
앱이 **처음 열 때 "이 MCP 서버 믿어?" 를 묻고**, 예를 누르면 붙는다
(`~/.claude.json` 의 `enabledMcpjsonServers` 에 기록된다).
열쇠는 파일에 안 적고 `${ROOKERY_MCP_TOKEN}` 로 뺀다 — 확인된 문법이다.
주소도 `${ROOKERY_URL:-배포주소}` 라서 그 변수만 놓으면 로컬로 돈다.
