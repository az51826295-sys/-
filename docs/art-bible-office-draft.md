# 로키 아트 바이블 — 밝은 사무실 (초안)

**상태: 초안. 사장님 확인 전에는 한 장도 안 그립니다.**
방향은 사장님이 주신 세 줄에서 나왔습니다 — 옥토패스 트래블러풍, 밝은 배경,
사무실. 아래 숫자와 색은 그 말을 **잴 수 있는 것으로 옮긴 것**이고, 제 취향이
들어간 자리는 그렇다고 적어 뒀습니다.

---

## 한 줄

> 햇빛이 드는 사무실에서, 각자 자기 일을 하는 사람들. 옥토패스처럼 **또렷한
> 픽셀 인물 + 부드러운 빛**, 다만 어둡지 않고 **밝다**.

## 먼저 짚을 것 하나

옥토패스 트래블러의 인상은 상당 부분 **어둠**에서 옵니다 — 어두운 배경에
인물만 빛나고, 블룸과 심도 흐림이 그 대비를 만듭니다. **밝은 배경**을 하시면
그 장치 하나가 빠집니다. 그래서 대비를 다른 데서 만들어야 합니다:

- 인물의 **외곽선을 어둡게** (배경이 밝으니 실루엣이 밝기로는 안 떨어집니다)
- 채도는 인물이 높고 **배경은 낮게** — 밝기 대신 채도로 가릅니다
- 그림자는 인물 아래 **한 덩어리만**, 흐리게

이걸 안 하면 밝은 배경에 밝은 인물이라 다 뭉개집니다. 아래 팔레트는 이 전제로
짰습니다.

---

## 팔레트

| 쓰임 | 색 | 어디에 쓰고, 어디엔 안 쓰나 |
|---|---|---|
| 종이 바닥 | `#F4F1E8` | 화면 바탕. 인물에는 안 씀 |
| 창빛 | `#FFF6D8` | 창가·바닥 반사. 넓게 깔되 인물 위엔 안 얹음 |
| 나무 | `#C9A227` | 책상·바닥재. 채도 있는 유일한 배경색 |
| 사무 회색 | `#B8BFC7` | 모니터·캐비닛·칸막이. 배경의 기본 |
| 잉크 | `#2B2D36` | 인물 외곽선, 글자. **배경 외곽선엔 안 씀**(배경은 선 없이) |
| 강조 | `#E0703A` | 지금 일하는 사람 표시, 버튼. 한 화면에 한 군데 |
| 통과 | `#4E8C5A` | 판정 통과 |
| 미확인 | `#C9922B` | 미측정·사람 몫 |

여덟 색입니다. **인물은 잉크 외곽선 + 3단 명암**으로 제한합니다 — 옥토패스가
그렇게 보이는 이유가 색이 많아서가 아니라 명암 단계가 분명해서입니다.

## 규격

| | 값 | 왜 |
|---|---|---|
| 생성 | 1024×1024 PNG, 투명 배경 | 지금 그림 자리(`gpt-image-2`)가 내는 크기 |
| 표시 | 64~96px, `image-rendering: pixelated` | 축소해서 씁니다. 픽셀이 뭉개지면 픽셀아트가 아닙니다 |
| 비율 | **머리:몸 = 1:1 (2등신)** | 사장님 지정. 아기자기함이 여기서 거의 다 나옵니다 |
| 포즈 | 정면 서 있는 한 자세 | 여러 자세를 한 장에 담으면 시트가 와서 못 씁니다 |
| 배경 | 완전 투명 | 흰 사각형이 따라오면 UI 어디에도 못 얹습니다 |
| 그림자 | 없음 (그림 안에) | 화면에서 CSS로 깝니다. 그림에 넣으면 배경색이 바뀔 때마다 어긋납니다 |

## 캐릭터 — 직함마다 하나

회사 등록부(`employeeDefinitions`)에 실제로 있는 다섯입니다. **없는 직함은 안
만듭니다** — 화면에 있는데 뽑을 수 없는 사람이 생깁니다.

| 파일 | 직함 | 발주 문구에 들어갈 인물 묘사 (제 초안) |
|---|---|---|
| `alex.png` | Alex · 리서치 애널리스트 | 서류 뭉치를 안고 있는 사람, 안경, 남색 카디건, 차분한 표정 |
| `emma.png` | Emma · 세일즈 | 전화기를 어깨에 끼고 손을 든 사람, 밝은 셔츠, 웃는 얼굴 |
| `iris.png` | Iris · 아트 디렉터 | 색 견본을 든 사람, 앞치마, 머리를 묶음, 한쪽 눈썹을 올린 표정 |
| `nova.png` | Nova · 게임 아티스트 | 타블렛과 펜을 든 사람, 후드, 헤드폰을 목에 걸침 |
| `dev.png` | Dev · 앱 개발자 | 노트북을 한 손에 든 사람, 셔츠 소매를 걷음, 머그컵 |

**여기가 제 상상이 들어간 자리입니다.** 사장님이 생각하신 인물이 다르면 이 칸만
고쳐 주십시오 — 나머지(형식·팔레트·규격)는 그대로 갑니다.

## 발주 문구 형식 (다섯 장 공통)

```
Pixel art character sprite for a bright modern office game, HD-2D style
inspired by Octopath Traveler: crisp visible square pixels, dark ink outline,
three-tone shading, warm sunlit lighting, limited palette.
ONE single chibi character alone, centered, full body, facing the viewer,
one standing pose. Two heads tall: the head is as large as the entire body
below it, big round head, small compact body, large expressive eyes. Completely empty transparent background, nothing else:
no ground, no floor shadow, no vignette, no frame, no border, no grid,
no second pose, no text.
<인물 묘사>
```

앞부분은 `skills/gameAssets` 의 형식을 그대로 물려받았습니다. 그 문구는
**실측으로 다듬어진 것**입니다 — `"pixel art game sprite"` 만 보내면 한 장에
20프레임짜리 시트가 옵니다.

## 무엇을 재고 무엇을 못 재나

| 잰다 | 어떻게 |
|---|---|
| PNG 인가, 알파(투명)가 있나 | 서버에서 PNG 머리만 읽어 바로 |
| 폭·높이 | 같은 자리 |
| 색 수·채도·바닥 대비 | 판정 엔진(`judgeCharacter`) |

**못 재는 것: 아기자기한가.** 그건 사장님이 보셔야 합니다. 판정 엔진이 안 붙어
있으면 색 수·대비도 못 재고, 그때는 `UNDEFINED` 로 두고 그렇게 적습니다 —
지금 `JUDGE_URL` 이 설정돼 있지 않아 **배포된 곳에서는 못 잽니다.**

## 값

`gpt-image-2` 는 토큰으로 값이 매겨져 있습니다(입력 $5/M, 출력 $40/M).
한 장에 대략 몇 센트이고, 다섯 직함 × 후보 세 장이면 **1달러 아래**로 봅니다.
정확한 값은 원장(`model_usage`)에 그대로 남습니다 — 지금은 추정입니다.
